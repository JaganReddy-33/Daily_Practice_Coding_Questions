# Input Integer Value

## Description

Write a program that reads an integer value from the user and prints it to the console. The program should use the Scanner class to capture the integer input and then display the value exactly as entered. Ensure that your program correctly handles the input and output as specified.

## Input Format

A single integer value input by the user.

## Output Format

The integer value entered by the user, printed to the console.

## Sample Cases

### Sample Case 1

**Input**
```text
42
```

**Output**
```text
42
```

### Sample Case 2

**Input**
```text
-98765
```

**Output**
```text
-98765
```
