# Input Float Value

## Description

<p>Write a program that reads a floating-point value from the user and prints it to the console. The program should use the Scanner class to capture the float input and then display the value exactly as entered. Ensure that your program correctly handles the input and output as specified.</p>

## Input Format

<p>A single floating-point value input by the user.</p>

## Output Format

<p>The floating-point value entered by the user, printed to the console.</p>

**Input**

**Output**
