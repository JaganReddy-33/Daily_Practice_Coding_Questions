# Input Long Value

## Description

Write a program that reads a long integer value from the user and prints it to the console. The program should use the Scanner class to capture the long integer input and then display the value exactly as entered. Ensure that your program correctly handles the input and output as specified.

## Input Format

A single long integer value input by the user.

## Output Format

The long integer value entered by the user, printed to the console.

## Sample Cases

### Sample Case 1

**Input**
```text
9223372036854775807
```

**Output**
```text
9223372036854775807
```

### Sample Case 2

**Input**
```text
9876543210
```

**Output**
```text
9876543210
```
