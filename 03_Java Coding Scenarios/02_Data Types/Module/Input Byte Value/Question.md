# Input Byte Value

## Description

<p><span style="color: rgb(0, 0, 0);">Write a program that reads a byte value from the user and prints it to the console. The program should use the Scanner class to capture the byte input and then display the value exactly as entered. Ensure that your program correctly handles the input and output as specified.</span></p>

## Input Format

<p><span style="color: rgb(0, 0, 0);">A single byte value input by the user.</span></p>

## Output Format

<p>The byte value entered by the user, printed to the console.</p>

**Input**
