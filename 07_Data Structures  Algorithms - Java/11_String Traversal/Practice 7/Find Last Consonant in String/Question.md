# Find Last Consonant in String

## Description

Find and return the last consonant character (non-vowel and non-space character) present in the string.

## Input Format

A single string `s` containing characters.

## Output Format

Return the last consonant character found in the string `s`, or -1 if no consonants are present.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
d
```


### Sample Case 2

**Input**
```text
Python
```

**Output**
```text
n
```


### Sample Case 3

**Input**
```text
6080f8acdd:1fbe39a02639abfa8760ad3c8928bbbd:467b440fbc4dbd5db1def26a16d72fd6
```

```text

```
