# Calculate Sum of Unicode Characters in String

## Description

Calculate and print the sum of the Unicode code points (integer values) of all characters in the string.

## Input Format

A single string `s` containing characters.

## Output Format

Print an integer representing the sum of Unicode code points of all characters in the string.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World
```

**Output**
```text
1052
```


### Sample Case 2

**Input**
```text
Python is fun!
```

**Output**
```text
1288
```
