# Find First Consonant in String

## Description

Find and return the First consonant character (non-vowel and non-space character) present in the string.

## Input Format

A single string `s` containing characters.

## Output Format

Return the First consonant character found in the string `s`, or -1 if no consonants are present.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
H
```


### Sample Case 2

**Input**
```text
Python
```

**Output**
```text
P
```


### Sample Case 3

**Input**
```text
c52fa5811d:6da0935b63bbe42744d19935a23ee4ba:f01c9de192fc9ca96c027d4647745297
```

```text

```
