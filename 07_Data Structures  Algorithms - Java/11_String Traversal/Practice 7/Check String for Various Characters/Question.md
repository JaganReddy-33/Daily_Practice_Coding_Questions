# Check String for Various Characters

## Description

Check whether the string contains at least one vowel, one consonant, one numeric digit, and one special character (non-alphanumeric).

## Input Format

A single string `s` containing characters.

## Output Format

Print 'yes' if the string contains at least one of each type of character (vowel, consonant, numeric, special), otherwise print 'no'.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello123!
```

**Output**
```text
yes
```


### Sample Case 2

**Input**
```text
abcdef
```

**Output**
```text
no
```
