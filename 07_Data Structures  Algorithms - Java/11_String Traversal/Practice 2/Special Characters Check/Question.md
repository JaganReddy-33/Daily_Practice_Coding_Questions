# Special Characters Check

## Description

Determine whether a given string consists only of special characters (non-alphanumeric characters).

## Input Format

A single string `s` containing characters.

## Output Format

Return `True` if the string contains only special characters, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
!@#$%^
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
Hello123
```

**Output**
```text
False
```
