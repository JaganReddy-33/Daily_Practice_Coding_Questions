# Even Digits Count

## Description

Count the number of even digits present in a given string.

## Input Format

A single string `s` containing characters.

## Output Format

Return an integer representing the count of even digits in the string.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello12345
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
9876543210
```

**Output**
```text
5
```
