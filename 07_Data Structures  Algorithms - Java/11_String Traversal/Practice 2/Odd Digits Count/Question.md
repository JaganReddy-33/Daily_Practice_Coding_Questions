# Odd Digits Count

## Description

Count the number of odd digits present in a given string.

## Input Format

A single string `s` containing characters.

## Output Format

Return an integer representing the count of odd digits in the string.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello12345
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
9876543210
```

**Output**
```text
5
```
