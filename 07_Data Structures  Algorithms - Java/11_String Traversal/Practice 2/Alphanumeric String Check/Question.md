# Alphanumeric String Check

## Description

Determine whether a given string consists only of alphanumeric characters.

## Input Format

A single string `s` containing characters.

## Output Format

Return `True` if the string contains only alphanumeric characters, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello123
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
123!@#
```

**Output**
```text
False
```
