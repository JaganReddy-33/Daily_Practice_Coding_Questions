# Check Vowel Count

## Description

Check if a given string contains more than 3 vowels.

## Input Format

A single string `s` containing characters.

## Output Format

Return `True` if the string contains more than 3 vowels, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
Heello World
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
Python is fun!
```

**Output**
```text
False
```
