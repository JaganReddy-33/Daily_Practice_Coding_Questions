# Characters After Given Character

## Description

Given a string s and character ch. Print all characters from string s that occur after a given character ch. If the character ch occurs more than once in the string s, consider the first occurrence of the character ch.

## Input Format

A single string `s` containing characters. A single character `ch`.

## Output Format

Print all characters from the string `s` that come after `ch`. If no characters occur after `ch`, print an empty line.

## Sample Cases

### Sample Case 1

**Input**
```text
hello
e
```

**Output**
```text
llo
```

### Sample Case 2

**Input**
```text
python
o
```

**Output**
```text
n
```
