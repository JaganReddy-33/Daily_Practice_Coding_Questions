# Vowels After Given Character

**Question ID:** `662f3324c74ee9cf9f4e0a28`

## Description

Print all vowels from a given string that occur after a given character.

## Input Format

A single string `s` containing characters. A single character `ch`.

## Output Format

Print all vowels from the string `s` that come after `ch`. If no vowels occur after `ch`, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
hello
e
```

**Output**
```text
o
```

### Sample Case 2
