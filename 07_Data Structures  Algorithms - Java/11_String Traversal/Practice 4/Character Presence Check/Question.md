# Character Presence Check

## Description

Check whether a given character is present in a given string.

## Input Format

A single string `s` containing characters. A single character `c` to be checked for presence in the string.

## Output Format

Return `True` if the character `c` is present in the string `s`, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World
o
```

**Output**
```text
True
```

### Sample Case 2

**Input**
```text
Python is fun!
x
```

**Output**
```text
False
```
