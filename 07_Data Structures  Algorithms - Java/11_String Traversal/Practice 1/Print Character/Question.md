# Print Character

## Description

Write a program that takes a character input from the user and prints the character.

## Input Format

The input consists of a single character entered by the user.

## Output Format

Print the character entered by the user.

## Sample Cases

### Sample Case 1

**Input**
```text
A
```

**Output**
```text
A
```


### Sample Case 2

**Input**
```text
x
```

**Output**
```text
x
```
