# Character Count

## Description

Given a string, count the number of characters in it.

## Input Format

The input consists of a single line containing a string, S.

## Output Format

Print a single integer representing the number of characters in the given string.

## Sample Cases

### Sample Case 1

**Input**
```text
computer
```

**Output**
```text
8
```

### Sample Case 2

**Input**
```text
programming
```

**Output**
```text
11
```
