# Special Character Printer

## Description

<p>Extracts and prints all the special characters present in a given string in the order of their occurrence.</p>

## Input Format

<p>The program takes a single line of input containing a string.</p>

## Output Format

<p>Print the special characters in the order of their occurrence separated by spaces.</p><p>If no special characters are found, output 'No special characters found.'</p>

## Sample Cases

### Sample Case 1

**Input**
```text
@#$%^&*
```

**Output**
```text
@ # $ % ^ & *
```


### Sample Case 2

**Input**
```text
1234567890
```

**Output**
```text
No special characters found.
```
