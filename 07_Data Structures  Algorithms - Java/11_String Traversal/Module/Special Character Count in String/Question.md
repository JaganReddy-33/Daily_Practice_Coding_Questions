# Special Character Count in String

## Description

<p>Counts the number of special characters in a given string. Do not consider space as special character for this problem.</p>

## Input Format

<p>The program takes a single line of input containing a string.</p>

## Output Format

<p>The program outputs a single line containing the count of special characters in the input string. If no special characters found return 0 in those cases.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
T@p A(adE%m&y Banglore
```

**Output**
```text
4
```


### Sample Case 2

**Input**
```text
@#$%^&*
```

**Output**
```text
7
```
