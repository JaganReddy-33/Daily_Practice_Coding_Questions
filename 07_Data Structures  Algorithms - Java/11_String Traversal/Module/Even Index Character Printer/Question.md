# Even Index Character Printer

## Description

<p>Extracts and prints all the characters present at even indices in a given string in the order of their occurrence.</p>

## Input Format

<p>The program takes a single line of input containing a string.</p>

## Output Format

<p>Print the characters at even indices in the order of their occurrence. If no characters are found at even indices, output 'No characters found at even indices.'</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TapAcad
```

**Output**
```text
T p c d
```


### Sample Case 2

**Input**
```text
12345
```

**Output**
```text
1 3 5
```
