# Count Vowels, Consonants, and Special Characters in a String

## Description

<p>Counts the number of vowels, consonants, and special characters in a given string.</p>

## Input Format

<p>The input consists of a single line containing the input string.</p>

## Output Format

<p>Output three lines, each containing the count of vowels, consonants, and special characters in the given string, respectively.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello, World!
```

**Output**
```text
Vowels: 3
Consonants: 7
Special Characters: 3
```


### Sample Case 2

**Input**
```text
Programming is fun!
```

**Output**
```text

```
