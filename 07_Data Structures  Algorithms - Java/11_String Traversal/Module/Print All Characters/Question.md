# Print All Characters

## Description

<p>Given a string, print each character in a new line.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print N lines, each line containing a single character from the input string.</p>

## Sample Cases

**Input**
```text
TapAcademy
```

**Output**
```text

c
a
d
e
m
y
```
