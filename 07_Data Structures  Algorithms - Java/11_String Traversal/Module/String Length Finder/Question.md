# String Length Finder

## Description

<p>Determines the length of a string, including whitespaces and special characters.</p>

## Input Format

<p>The program takes a single line of input containing a string.</p>

## Output Format

<p>Print the length of the input string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
12
```


### Sample Case 2

**Input**
```text
TapAcademy
```

**Output**
```text
10
```
