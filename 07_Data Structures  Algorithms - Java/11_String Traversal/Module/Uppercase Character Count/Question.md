# Uppercase Character Count

## Description

<p>Given a string, count the number of uppercase characters in it.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single integer representing the number of uppercase characters in the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
World
```

**Output**
```text
1
```
