# Word Count in String

## Description

<p>Counts the number of words in a given string[words might be separated by multiple space].</p>

## Input Format

<p>The input consists of a single line containing the input string.</p>

## Output Format

<p>Output the count of words in the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
Programming is fun
```

**Output**
```text
3
```
