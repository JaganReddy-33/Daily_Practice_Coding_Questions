# Number Printer

## Description

<p>Extracts and prints all the numerical values present in a given string in the order of their occurrence.</p>

## Input Format

<p>The program takes a single line of input containing a string.</p>

## Output Format

<p>Print the distinct numbers in the order of their occurrence. If no numbers are found, output 'No numbers found.'</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TAPacademy2021
```

**Output**
```text
2 0 2 1
```


### Sample Case 2

**Input**
```text
Hello World!
```

**Output**
```text
No numbers found.
```
