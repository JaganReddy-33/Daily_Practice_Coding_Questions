# Prime ASCII Characters

## Description

Construct and return a new string containing only the characters whose ASCII values are prime numbers.

## Input Format

A single string `s` containing characters.

## Output Format

Return a new string containing characters whose ASCII values are prime numbers.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
e
```


### Sample Case 2

**Input**
```text
d6cac4fd30:d52b905766965a08883dce51767b392b:8b1f91facce0b3a9213fd71e1aa181ef
```

**Output**
```text
2910:9e4cfe41f3e507ffaa57c5ec5bf01714:3caee8d43111159fc16e997863726583
```
