# Find First Vowel in String Alphabetically

## Description

Find and return the first vowel character ('a', 'e', 'i', 'o', 'u') present in the string alphabetically.

## Input Format

A single string `s` containing characters.

## Output Format

Return the first vowel character found in the string `s`, or -1 if no vowels are present.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
e
```


### Sample Case 2

**Input**
```text
Python
```

**Output**
```text
o
```


### Sample Case 3

**Input**
```text
8bfe8d2301:728119425533665db96ba4fbea36ee04:7041a8b2cbe471af93a98623173290bb
```

**Output**
```text
4a:7871cfbb0fa880bec6e6d0b6c2669f8e:be2bbfacc778bc50fd8f02dfe76aaee0
```
