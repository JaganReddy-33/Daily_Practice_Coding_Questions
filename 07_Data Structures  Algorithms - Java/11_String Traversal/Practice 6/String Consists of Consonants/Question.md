# String Consists of Consonants

## Description

Check whether the string consists entirely of consonant characters (non-vowel and non-space characters).

## Input Format

A single string `s` containing characters.

## Output Format

Return `True` if the string consists only of consonant characters, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
hello
```

**Output**
```text
False
```


### Sample Case 2

**Input**
```text
bcd
```

**Output**
```text
True
```
