# String Consists of Numeric Characters

## Description

Check whether the string consists entirely of numeric characters (digits).

## Input Format

A single string `s` containing characters.

## Output Format

Return `True` if the string consists only of numeric characters, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
12345
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
abc123
```

**Output**
```text
False
```
