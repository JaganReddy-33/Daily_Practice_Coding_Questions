# String Consists of All Vowels

## Description

Check whether the string consists of all the vowel characters ('a', 'e', 'i', 'o', 'u').

## Input Format

A single string `s` containing characters.

## Output Format

Return `True` if the string consists of all vowels, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
aeiou
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
hello
```

**Output**
```text
False
```
