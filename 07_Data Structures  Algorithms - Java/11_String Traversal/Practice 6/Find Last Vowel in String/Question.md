# Find Last Vowel in String

## Description

Find and return the last vowel character ('a', 'e', 'i', 'o', 'u') present in the string.

## Input Format

A single string `s` containing characters.

## Output Format

Return the last vowel character found in the string `s`, or -1 if no vowels are present.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
o
```


### Sample Case 2

**Input**
```text
Python
```

**Output**
```text
o
```
