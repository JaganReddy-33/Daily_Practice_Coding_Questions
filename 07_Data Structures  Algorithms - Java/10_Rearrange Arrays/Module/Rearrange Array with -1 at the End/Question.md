# Rearrange Array with -1 at the End

## Description

<p>Rearrange the array by moving -1 elements to the end while maintaining the relative order of positive integers.</p>

## Input Format

<p>First line contains size of the array n.</p><p>Next line contains n space separated integer values.</p>

## Output Format

<p>A line containing space-separated integers representing the rearranged array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
3 5 -1 2 8 -1 7
```

**Output**
```text
3 5 2 8 7 -1 -1
```


### Sample Case 2

**Input**
```text
7
1 -1 4 2 -1 9 -1
```

**Output**
```text
1 4 2 9 -1 -1 -1
```
