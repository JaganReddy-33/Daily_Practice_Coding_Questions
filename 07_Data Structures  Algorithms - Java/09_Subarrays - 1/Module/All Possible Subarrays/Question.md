# All Possible Subarrays

## Description

<p>Print all possible subarrays of a given array.</p>

## Input Format

<p>First line contains size of the array (integer).</p><p>Second line contains elements of the array (space-separated integers)</p>

## Output Format

<p>The program should output each subarray on a new line.</p><p>Each subarray should be displayed as a space-separated sequence of elements.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
1 2 3
```

**Output**
```text
1
2
3
1 2
2 3
1 2 3
```


### Sample Case 2

**Input**
```text
4
10 20 30 40
```

**Output**
```text
10
20
30
40
10 20
20 30
30 40
10 20 30
20 30 40
10 20 30 40
```
