# Smallest Word

## Description

<p>Given a string, find the smallest word from it.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print the smallest word from the given string.If there are multiple such words print the first occurance</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Work is Worship
```

**Output**
```text
is
```


### Sample Case 2

**Input**
```text
Hello World
```

**Output**
```text
Hello
```
