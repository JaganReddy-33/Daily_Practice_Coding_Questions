# Reverse Words in a String

## Description

<p>Reverse all the words in a given string while maintaining the order of the words.</p>

## Input Format

<p>A single line containing a string of words.</p>

## Output Format

<p>Print each word of the reversed string on the same line separated by space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Tap academy
```

**Output**
```text
paT ymedaca
```


### Sample Case 2

**Input**
```text
India is my country
```

**Output**
```text
aidnI si ym yrtnuoc
```
