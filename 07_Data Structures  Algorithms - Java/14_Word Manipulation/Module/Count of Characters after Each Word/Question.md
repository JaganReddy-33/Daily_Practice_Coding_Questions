# Count of Characters after Each Word

## Description

<p>Find the count of characters after each word in a given string.</p>

## Input Format

<p>A single line containing a string of words.</p>

## Output Format

<p>A single line containing the count of characters after each word, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Tap academy
```

**Output**
```text
Tap3 academy7
```


### Sample Case 2

**Input**
```text
India is my country
```

**Output**
```text
India5  is2 my2 country7
```
