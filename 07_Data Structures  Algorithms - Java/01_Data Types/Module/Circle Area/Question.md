# Circle Area

## Description

<p>Write a program to find the area of the circle. Formula: area = pi*r*r. Consider pi = 3.142</p><p>NOTE:</p><p>4 decimal points has to printed.</p><p>Consider data type of pi value to be double</p>

## Input Format

<p>First line contains an Integer, radius of a circle</p>

## Output Format

<p>Print the area of the circle. The area of the circle should have four decimal places only.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
18
```

**Output**
```text
1018.0080
```
