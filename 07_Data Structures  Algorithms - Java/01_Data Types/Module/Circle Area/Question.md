# Circle Area

## Description

Write a program to find the area of the circle. Formula: area = pi*r*r. Consider pi = 3.142

NOTE:

4 decimal points has to printed.

Consider data type of pi value to be double

## Input Format

First line contains an Integer, radius of a circle

## Output Format

Print the area of the circle. The area of the circle should have four decimal places only.

## Sample Cases

### Sample Case 1

**Input**
```text
18
```

**Output**
```text
1018.0080
```

### Sample Case 2

**Input**
```text
10
```

**Output**
```text
314.2000
```
