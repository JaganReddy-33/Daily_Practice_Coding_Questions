# Cylinder Surface Area

## Description

<p>Write a program to calculate total surface area of a cylinder. Formula: 2 * pi* r*(r+h)</p><p>NOTE: take pi = 3.142</p>

## Input Format

<p>First line contains an Integer, radius of a cylinder Second line contains an Integer, height of a cylinder</p>

## Output Format

<p>Print the area of the cylinder. The area of the cylinder should have four decimal places only. [use `double` for area]</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
13
```

**Output**
```text
879.7600
```
