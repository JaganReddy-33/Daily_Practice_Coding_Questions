# Product of Three

## Description

<p>Write a program to find the product of 3 numbers.</p>

## Input Format

<p>The input consists of three lines, each line contains a long integer number.</p>

## Output Format

<p>Print the product of the three numbers.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
10
10
```

**Output**
```text
1000
```


### Sample Case 2

**Input**
```text
100
1000
10000
```

**Output**
```text
1000000000
```
