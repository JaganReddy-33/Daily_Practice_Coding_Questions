# Circle Circumference

## Description

Write a program to calculate the circumference of a circle. Formula: Circumference = 2*pi*radius, where pi=3.142

## Input Format

First line contains an Integer, radius of a circle

## Output Format

Print the circumference of the circle. The circumference should have four decimal places only.

## Sample Cases

### Sample Case 1

**Input**
```text
10
```

**Output**
```text
62.8400
```


### Sample Case 2

**Input**
```text
50
```

**Output**
```text
314.2000
```
