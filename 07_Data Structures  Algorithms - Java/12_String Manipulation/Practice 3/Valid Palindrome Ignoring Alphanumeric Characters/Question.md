# Valid Palindrome Ignoring Alphanumeric Characters

## Description

<p>Write a Java program to check if a given string is a valid palindrome ignoring alphanumeric characters.</p>

## Input Format

<p>A single line containing a string s with alphanumeric characters and special characters, without spaces.</p>

## Output Format

<p>Print 'True' if the string is a valid palindrome after ignoring alphanumeric characters, otherwise print 'False'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
aman#a$plan%a$canal#panama
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
#t$e!n!e$t#
```

**Output**
```text
True
```
