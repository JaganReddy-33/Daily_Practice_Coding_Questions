# Valid Palindrome Ignoring Alphanumeric Characters

## Description

Write a Java program to check if a given string is a valid palindrome ignoring alphanumeric characters.

## Input Format

A single line containing a string s with alphanumeric characters and special characters, without spaces.

## Output Format

Print 'True' if the string is a valid palindrome after ignoring alphanumeric characters, otherwise print 'False'.

## Sample Cases

### Sample Case 1

**Input**
```text
aman#a$plan%a$canal#panama
```

**Output**
```text
True
```

### Sample Case 2

**Input**
```text
#t$e!n!e$t#
```

**Output**
```text
True
```
