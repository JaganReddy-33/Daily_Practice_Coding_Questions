# Remove Characters

## Description

Write a Java program to remove 'b' and 'ac' from a given string.

## Input Format

The input consists of a single string containing lowercase English letters.

## Output Format

Print the modified string after removing occurrences of 'b' and 'ac'. If no string after removing occurrences of 'b' and 'ac' print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
abac
```

**Output**
```text
a
```


### Sample Case 2

**Input**
```text
bacc
```

**Output**
```text
c
```
