# Valid Palindrome (Ignore Special Characters and Spaces)

## Description

<p>Given a string, check if it is a valid palindrome ignoring special characters and spaces.</p>

## Input Format

<p>A single string containing lowercase alphabets, numbers, and special characters.</p>

## Output Format

<p>Print "True" if the string is a valid palindrome after ignoring Special Characters and Spaces otherwise "False".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
t#e$n$e#t
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
$raceacar$
```

**Output**
```text
False
```
