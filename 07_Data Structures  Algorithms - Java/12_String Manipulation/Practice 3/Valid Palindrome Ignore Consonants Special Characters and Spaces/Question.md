# Valid Palindrome (Ignore Consonants, Special Characters and Spaces)

## Description

<p>Given a string, check if it is a valid palindrome ignoring consonant characters.</p>

## Input Format

<p>A single string containing lowercase alphabets, numbers, and special characters.</p>

## Output Format

<p>True if the string is a valid palindrome after ignoring consonant characters, Special Characters and Spaces otherwise False.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
a man, a plan, a canal, panama!
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
race a car
```

**Output**
```text
False
```
