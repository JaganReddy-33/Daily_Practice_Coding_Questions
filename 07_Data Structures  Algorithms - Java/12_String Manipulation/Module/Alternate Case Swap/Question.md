# Alternate Case Swap

## Description

<p>Given a string, swap the case of each character in an alternate manner means uppercase to lowercase and lowercase to uppercase</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single string with the case of each character swapped in an alternate manner.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
STRinG PrOGRam
```

**Output**
```text
strINg pRogrAM
```


### Sample Case 2

**Input**
```text
HeLLo WoRLd
```

**Output**
```text
hEllO wOrlD
```
