# Uppercase to Lowercase Converter

## Description

<p>Converts a given string from uppercase to lowercase.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output the converted string in lowercase.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
HELLO WORLD!
```

**Output**
```text
hello world!
```


### Sample Case 2

**Input**
```text
TapACADemy
```

**Output**
```text
tapacademy
```
