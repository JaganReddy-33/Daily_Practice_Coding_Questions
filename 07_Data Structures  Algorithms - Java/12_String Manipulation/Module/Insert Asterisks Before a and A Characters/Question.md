# Insert Asterisks Before 'a' and 'A' Characters

## Description

<p>Insert an asterisk (*) before each occurrence of the characters 'a' and 'A' in a given string.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output a single line containing the modified string with asterisks inserted before 'a' and 'A' characters.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TaapAAcaademy
```

**Output**
```text
T*a*ap*A*Ac*a*ademy
```


### Sample Case 2

**Input**
```text
programming
```

**Output**
```text
progr*amming
```
