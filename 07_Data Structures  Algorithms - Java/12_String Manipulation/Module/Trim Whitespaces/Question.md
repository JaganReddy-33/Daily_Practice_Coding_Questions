# Trim Whitespaces

## Description

Given a string, trim the leading and trailing whitespaces.

## Input Format

The input consists of a single line containing a string, S.

## Output Format

Print a single string with no leading and trailing whitespaces.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello
```

**Output**
```text
Hello
```

### Sample Case 2

**Input**
```text
Trim
```

**Output**
```text
Trim
```
