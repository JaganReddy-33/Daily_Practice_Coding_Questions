# Remove Special Characters

## Description

<p>Remove all special characters from a given string.</p>

## Input Format

<p>The input consists of a single line containing a string that may contain special characters.</p>

## Output Format

<p>Output a single line containing the modified string after removing all the special characters.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Tap$@Acad123
```

**Output**
```text
TapAcad123
```


### Sample Case 2

**Input**
```text
P@r!o$g#r^a&m*m*i(n)g~
```

**Output**
```text
Programming
```
