# Remove Vowels

## Description

Remove all vowels from a given string.

## Input Format

The input consists of a single line containing a string that may contain vowels.

## Output Format

Output a single line containing the modified string after removing all vowels.

## Sample Cases

### Sample Case 1

**Input**
```text
TapAcademyBTM
```

**Output**
```text
TpcdmyBTM
```

**Input**
