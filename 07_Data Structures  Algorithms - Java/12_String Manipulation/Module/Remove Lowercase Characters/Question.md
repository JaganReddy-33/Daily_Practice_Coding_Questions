# Remove Lowercase Characters

## Description

<p>Remove all lowercase characters from a given string.</p>

## Input Format

<p>The input consists of a single line containing a string that may contain lowercase characters.</p>

## Output Format

<p>Output a single line containing the modified string after removing all lowercase characters.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TtAaPpAaCcAaDdEeMmYy
```

**Output**
```text
TAPACADEMY
```


### Sample Case 2

**Input**
```text

```

**Output**
```text

```
