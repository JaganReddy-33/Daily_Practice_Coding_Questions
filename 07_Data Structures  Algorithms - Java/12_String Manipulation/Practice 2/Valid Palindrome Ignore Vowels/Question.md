# Valid Palindrome (Ignore Vowels)

## Description

<p>Given a string, check if it is a valid palindrome ignoring vowel characters and spaces.</p>

## Input Format

<p>A single string containing lowercase alphabets, numbers, and special characters.</p>

## Output Format

<p>True if the string is a valid palindrome after ignoring vowel characters, otherwise False.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
321a man a plan a canal panama123
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
$raceacar$
```

**Output**
```text
True
```
