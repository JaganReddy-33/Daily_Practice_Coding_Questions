# Replace Characters with '*'

## Description

<p>Given a string and a character, replace all occurrences of the character in the string with '*'.</p>

## Input Format

<p>Two inputs - a string containing alphabets, numbers, and special characters, and a single character.</p>

## Output Format

<p>A string with all occurrences of the character replaced by '*'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello world
o
```

**Output**
```text
hell* w*rld
```


### Sample Case 2

**Input**
```text
programming is fun
i
```

**Output**
```text
programm*ng *s fun
```
