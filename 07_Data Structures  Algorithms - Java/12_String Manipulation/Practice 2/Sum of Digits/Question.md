# Sum of Digits

## Description

Given a string, calculate the sum of all digits and concatenate it to the beginning of the string.

## Input Format

The input consists of a single string containing alphanumeric characters.

## Output Format

Print the modified string after calculating the sum of digits and concatenating it to the beginning.

## Sample Cases

### Sample Case 1

**Input**
```text
abc123
```

**Output**
```text
6abc123
```


### Sample Case 2

**Input**
```text
1a2b3c
```

**Output**
```text
61a2b3c
```
