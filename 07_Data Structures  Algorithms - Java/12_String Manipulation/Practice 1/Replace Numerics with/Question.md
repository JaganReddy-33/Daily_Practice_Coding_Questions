# Replace Numerics with '#'

## Description

Given a string, replace all numeric characters with '#'.

## Input Format

A single string containing alphabets, numbers, and special characters.

## Output Format

A string with all numeric characters replaced by '#'.

## Sample Cases

### Sample Case 1

**Input**
```text
hello123
```

**Output**
```text
hello###
```


### Sample Case 2

**Input**
```text
world456
```

**Output**
```text
world###
```
