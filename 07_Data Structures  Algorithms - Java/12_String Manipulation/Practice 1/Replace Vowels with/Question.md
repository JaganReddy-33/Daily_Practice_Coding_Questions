# Replace Vowels with '#'

## Description

Given a string, replace all vowels with '#'.

## Input Format

A single string containing alphabets.

## Output Format

A string with all vowels replaced by '#'.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello
```

**Output**
```text
H#ll#
```


### Sample Case 2

**Input**
```text
world
```

**Output**
```text
w#rld
```
