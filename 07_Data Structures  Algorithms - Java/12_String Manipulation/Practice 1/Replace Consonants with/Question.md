# Replace Consonants with '#'

## Description

<p>Given a string, replace all consonants with '#'.</p>

## Input Format

<p>A single string containing alphabets.</p>

## Output Format

<p>A string with all consonants replaced by '#'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello
```

**Output**
```text
#e##o
```


### Sample Case 2

**Input**
```text
world
```

**Output**
```text
#o###
```
