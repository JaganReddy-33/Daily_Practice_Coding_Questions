# Pairs with Sum as Prime Number

## Description

<p>Print all pairs of numbers from a given array where the sum of the pair is a prime number.</p>

## Input Format

<p>The input consists of a single line containing space-separated integers.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 5 7 9
```

**Output**
```text
2 3
2 5
2 9
```


### Sample Case 2

**Input**
```text
3
1 2 3
```

**Output**
```text
1 2
2 3
```
