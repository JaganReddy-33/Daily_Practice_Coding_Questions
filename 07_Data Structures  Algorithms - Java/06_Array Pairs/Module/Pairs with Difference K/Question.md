# Pairs with Difference K

## Description

<p>Find pairs of numbers in an array with a given target difference.</p>

## Input Format

<p>The first line contains N the length of the array.</p><p>The second line contains space-separated integers representing the array elements.</p><p>The third line contains a single integer, 'k', representing the target difference.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
3 1 5 4 2
2
```

**Output**
```text
3 1
3 5
4 2
```


### Sample Case 2

**Input**
```text
6
8 12 5 9 15 6
3
```

**Output**
```text
8 5
12 9
12 15
9 6
```
