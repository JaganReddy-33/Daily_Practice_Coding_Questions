# Pairs with Sum K

## Description

<p>Print all pairs of numbers from a given array whose sum is equal to a target sum.</p>

## Input Format

<p>The first line contains the length of the array N.</p><p>The second line contains n space-separated integers representing the array elements.</p><p>The third line contains a single integer, 'k', representing the target sum.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
6
```

**Output**
```text
1 5
2 4
```


### Sample Case 2

**Input**
```text
5
4 2 3 5 7
7
```

**Output**
```text
4 3
2 5
```
