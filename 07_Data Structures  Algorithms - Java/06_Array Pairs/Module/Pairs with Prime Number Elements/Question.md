# Pairs with Prime Number Elements

## Description

<p>Print all pairs of numbers from a given array where at least one of the elements is a prime number.</p>

## Input Format

<p>The input consists of two lines. The first line contains the size of the array. The second line contains space-separated integers.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 5 7 9
```

**Output**
```text
2 3
2 5
2 7
2 9
3 5
3 7
3 9
5 7
5 9
7 9
```


### Sample Case 2

**Input**
```text
3

```

**Output**
```text

2 3
```
