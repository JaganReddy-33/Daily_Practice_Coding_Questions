# Pairs with Second Value Smaller than First Value

## Description

<p>Print all pairs of numbers from a given array where the second value is strictly smaller than the first value.</p>

## Input Format

<p>The input consists of two lines. The first line contains the size of the array. The second line contains space-separated integers.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
3 1 5 4 2
```

**Output**
```text
3 1
3 2
5 4
5 2
4 2
```


### Sample Case 2

**Input**
```text
3
4 2 3
```

**Output**
```text
4 2
4 3
```
