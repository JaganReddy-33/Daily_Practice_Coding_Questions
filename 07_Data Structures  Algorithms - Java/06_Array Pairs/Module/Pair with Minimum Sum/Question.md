# Pair with Minimum Sum

## Description

<p>Print the pair of numbers from the input array whose sum is minimum.</p>

## Input Format

<p>A single line containing space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the pair of numbers on a single line in the same order as array, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
2 4 6 3 8 9
```

**Output**
```text
2 3
```


### Sample Case 2

**Input**
```text
4
1 2 3 4
```

**Output**
```text
1 2
```
