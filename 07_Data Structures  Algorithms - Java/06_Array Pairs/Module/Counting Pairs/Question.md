# Counting Pairs

## Description

<p>Count the number of all possible pairs that can be formed from the given array.</p>

## Input Format

<p>The first line contains an integer N, representing the size of the array. </p><p>The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>A single line containing the count of all possible pairs.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
10
```


### Sample Case 2

**Input**
```text
3
-1 0 1
```

**Output**
```text
3
```
