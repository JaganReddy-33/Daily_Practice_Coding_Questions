# Minimum Product of Pairs in an Array

## Description

<p>Write a program that finds the minimum product among all the pairs of elements in a given array of integers.</p>

## Input Format

<p>The first line contains a single integer, N, representing the size of the array.</p><p>The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the minimum product among all the pairs of elements in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
5 9 2 8 3 7
```

**Output**
```text
6
```


### Sample Case 2

**Input**
```text
7

```

**Output**
```text

```
