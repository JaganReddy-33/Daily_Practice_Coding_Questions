# All Pairs in Array

## Description

<p>Given an array of size N, print all the pairs present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print all pairs present in the array. Each pair should be printed in a separate line with two space-separated integers representing the pair. If no pairs present print “None”.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 2
1 3
1 4
1 5
2 3
2 4
2 5
3 4
3 5
4 5
```


### Sample Case 2

**Input**
```text
4
10 -5 8 3
```

**Output**
```text

10 8
10 3
-5 8
-5 3
8 3
```
