# Pairs Greater than K

## Description

Given an array of size N, print all the pairs whose first value is greater than K.

## Input Format

The first line contains an integer N, the size of the array.
The second line contains N space-separated integers, representing the elements of the array.
The third line contains an integer K.

## Output Format

Print all pairs whose first value is greater than K. Each pair should be printed in a separate line with two space-separated integers representing the pair. If no pairs are found, print “None”.

## Sample Cases

### Sample Case 1

**Input**
```text
5
3 1 5 7 9
4
```

**Output**
```text
5 7
5 9
7 9
```


### Sample Case 2

**Input**
```text
4
10 -5 8 3
2
```

**Output**
```text
10 -5
10 8
10 3
8 3
```
