# Diff of Pairs

## Description

<p>Given an array of size N, print the difference of each pair present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the difference of each pair present in the array. Each difference should be printed in a separate line. If no pairs are present, print "None".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 7 9
```

**Output**
```text
2
4
6
8
2
4
6
2
4
2
```
