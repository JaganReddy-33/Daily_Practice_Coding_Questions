# Pairs Less Than K

## Description

<p>Given an array of integers with a size of N, print all the pairs whose sum is less than K.</p>

## Input Format

<p>The input consists of: - The first line contains an integer N, the size of the array. - The second line contains N space-separated integers, representing the elements of the array. - The third line contains an integer K.</p>

## Output Format

<p>Print all the pairs whose sum is less than K, each pair in a separate line.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
7
```

**Output**
```text
1 2
1 3
1 4
1 5
2 3
2 4
```


### Sample Case 2
