# Sum of Pairs

**Question ID:** `6621fe4aae2286cdf8e41f1b`

## Description

Given an array of size N, print the sum of each pair present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print the sum of each pair present in the array. Each sum should be printed in a separate line. If no pairs present print "None".
