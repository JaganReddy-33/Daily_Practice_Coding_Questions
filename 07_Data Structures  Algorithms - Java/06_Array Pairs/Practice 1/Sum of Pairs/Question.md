# Sum of Pairs

## Description

<p>Given an array of size N, print the sum of each pair present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the sum of each pair present in the array. Each sum should be printed in a separate line. If no pairs present print "None".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3
4
5
6
5
6
7
7
8
9
```
