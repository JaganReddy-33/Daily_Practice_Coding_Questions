# Positive-Negative Pairs

## Description

<p>Given an array of integers with a size of N, find and print all the pairs having positive and negative values of a number that exists in the array.</p>

## Input Format

<p>The input consists of: - The first line contains an integer N, the size of the array. - The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print all the pairs having positive and negative values of a number that exists in the array, each pair in a separate line. If there are no such pairs, print "No pairs found".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
2 -3 4 -5 6 -4
```

**Output**
```text
4 -4
```
