# Even Digits Count

## Description

Given a positive integer N, print the number of even digits present in the number.

## Input Format

A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

Print the number of even digits present in the number.

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
2
```

### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
2
```
