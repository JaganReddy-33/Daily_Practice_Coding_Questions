# Odd Digits Count

## Description

<p>Given a positive integer N, print the number of odd digits present in the number.</p>

## Input Format

<p>An integer N (1 &lt;= N &lt;= 10^9) representing the input number.</p>

## Output Format

<p>Print the count of odd digits present in N.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
24681357
```

**Output**
```text
4
```


### Sample Case 2

**Input**
```text
24682468
```

**Output**
```text

```
