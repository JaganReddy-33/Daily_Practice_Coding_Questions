# Multiples of 3 and 5 Between N1 and N2 Descending

**Question ID:** `661acf445028dc4e9d178a36`

## Description

Print all multiples of 3 and 5 from N1 to N2 in descending order.

## Input Format

Two integers N1 and N2 (1 <= N1 <= 10^5, 1 <= N2 <= 10^5) representing the starting and ending natural numbers.

## Output Format

Print all multiples of 3 and 5 between N2 and N1 in descending order, each separated by a space.
