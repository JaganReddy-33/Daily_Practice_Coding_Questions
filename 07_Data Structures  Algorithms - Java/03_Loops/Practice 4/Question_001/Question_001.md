# Multiples of 3 Between N1 and N2 Descending

**Question ID:** `661acf0e5028dc4e9d177924`

## Description

Print all multiples of 3 from N1 to N2 in descending order.

## Input Format

Two integers N1 and N2 (1 <= N1 <= 10^5, 1 <= N2 <= 10^5) representing the starting and ending natural numbers.

## Output Format

Print all multiples of 3 between N2 and N1 in descending order, each separated by a space. If no multiples print "-1"

## Sample Cases

### Sample Case 1

**Input**
```text
15 5
```

**Output**
```text
15 12 9 6
```
