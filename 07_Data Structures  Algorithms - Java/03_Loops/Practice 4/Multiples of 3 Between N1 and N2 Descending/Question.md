# Multiples of 3 Between N1 and N2 Descending

## Description

<p>Print all multiples of 3 from N1 to N2 in descending order.</p>

## Input Format

<p>Two integers N1 and N2 (1 &lt;= N1 &lt;= 10^5, 1 &lt;= N2 &lt;= 10^5) representing the starting and ending natural numbers.</p>

## Output Format

<p>Print all multiples of 3 between N2 and N1 in descending order, each separated by a space. If no multiples print "-1"</p>

## Sample Cases

### Sample Case 1

**Input**
```text
15 5
```

**Output**
```text
15 12 9 6
```


### Sample Case 2

**Input**
```text
20 10
```

**Output**
```text
18 15 12
```
