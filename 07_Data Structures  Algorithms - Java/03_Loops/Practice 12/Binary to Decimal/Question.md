# Binary to Decimal

## Description

Given a binary number N, convert it to its decimal representation.

## Input Format

A string N representing the binary number.

## Output Format

Print the decimal representation of the binary number.

## Sample Cases

### Sample Case 1

**Input**
```text
1010
```

**Output**
```text
10
```

### Sample Case 2

**Input**
```text
1101
```

**Output**
```text
13
```
