# Strong Numbers

## Description

Given a positive integer N, print all the strong numbers from 1 to N. A number is called a strong number if the sum of the factorial of its digits is equal to the number itself.

## Input Format

An integer N (1 <= N <= 10^5) representing the upper limit.

## Output Format

Print all the strong numbers from 1 to N, each separated by a space. If no strong numbers are found, print 'No strong numbers'.

## Sample Cases

### Sample Case 1

**Input**
```text
145
```

**Output**
```text
1 2 145
```


### Sample Case 2

**Input**
```text

```
