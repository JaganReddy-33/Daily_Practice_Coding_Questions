# Sum Even Digits

## Description

Given a positive integer N, print the sum of even digits present in the number.

## Input Format

A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

Print the sum of even digits present in the number.

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
6
```


### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
14
```
