# Prime Digits

**Question ID:** `661ad39f5028dc4e9d1872a4`

## Description

Given a positive integer N, print all the prime digits present in the number.

## Input Format

A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

Print all the prime digits present in the number, each separated by a space. If no prime digits are present, print "No prime digits".

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
3 2
```

### Sample Case 2

**Input**

```text
98765
```

**Output**
