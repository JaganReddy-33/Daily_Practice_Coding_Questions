# Product of Prime Digits

**Question ID:** `661ad3bcf51c6d596b093803`

## Description

Given a positive integer N, print the product of prime digits present in the number.

## Input Format

A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

Print the product of prime digits present in the number. If no prime digits are present, print 'No prime digits'.
