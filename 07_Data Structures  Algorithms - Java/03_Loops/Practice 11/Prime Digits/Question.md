# Prime Digits

## Description

<p>Given a positive integer N, print all the prime digits present in the number.</p>

## Input Format

<p>A single integer N (1 &lt;= N &lt;= 10^9) representing the number.</p>

## Output Format

<p>Print all the prime digits present in the number, each separated by a space. If no prime digits are present, print "No prime digits".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
3 2
```


### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
5 7
```
