# Odd Multiples of N Descending

**Question ID:** `661ad040f51c6d596b08a1e3`

## Description

Given two positive integers N and M, print all the multiples of N from M to 1 in descending order which are odd.

## Input Format

Two integers N and M (1 <= N, M <= 10^5) representing the base number and the starting natural number.

## Output Format

Print all the odd multiples of N from M to 1 in descending order, each separated by a space. If no multiples exist, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
3 15
```

**Output**
```text
15 9 3
```

### Sample Case 2

**Input**
```text
5 25
```

**Output**
```text
25 15 5
```
