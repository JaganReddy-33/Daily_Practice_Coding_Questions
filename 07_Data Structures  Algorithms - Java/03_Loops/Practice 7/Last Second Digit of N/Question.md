# Last Second Digit of N

## Description

Given a positive integer N, print the last second digit of N.

## Input Format

A single integer N (1 <= N <= 10^9) representing the input number.

## Output Format

Print the last second digit of N.

## Sample Cases

### Sample Case 1

**Input**
```text
123456
```

**Output**
```text
5
```


### Sample Case 2

**Input**
```text
987654321
```

**Output**
```text
2
```


### Sample Case 3

**Input**
```text
854d7d:eee791d311dea459b1fa336d9e32b6bf:a33577953b6d6c542c2fc0e4c07d0946
```

```text
e5:9c8e13424e0531fd2160a556cc5e6760:fb33a682bbab7de8e0f859bc30208784
```
