# Product of Digits

## Description

<p>Given a positive integer N, print the product of all digits present in N.</p>

## Input Format

<p>- A single integer N (1 &lt;= N &lt;= 10^9) representing the number.</p>

## Output Format

<p>- Print the product of all digits present in N.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
24
```


### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
15120
```
