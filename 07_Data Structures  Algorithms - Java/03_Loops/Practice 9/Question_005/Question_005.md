# Digits in Words

**Question ID:** `661ad15f5028dc4e9d182421`

## Description

Given a positive integer N, print each digit of the number in words.

## Input Format

- A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

- Print each digit of the number in words, separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
one two three four
```

### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
nine eight seven six five
```
