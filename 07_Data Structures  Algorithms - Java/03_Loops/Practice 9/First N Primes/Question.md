# First N Primes

## Description

<p>Given two positive integers N and M, print the first N prime numbers greater than M.</p>

## Input Format

<p>- Two integers N and M (1 &lt;= N, M &lt;= 10^5) representing the number of prime numbers to print and the starting point.</p>

## Output Format

<p>- Print the first N prime numbers greater than M, each separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5 10
```

**Output**
```text
11 13 17 19 23
```


### Sample Case 2

**Input**
```text
3 20
```

**Output**
```text
23 29 31
```
