# Multiples of 3 or 5 Descending

## Description

<p>Print numbers from N to 1 which are multiples of either 3 or 5 in descending order.</p>

## Input Format

<p>A single integer N (1 &lt;= N &lt;= 10^5) representing the starting natural number.</p>

## Output Format

<p>Print all numbers from N to 1 in descending order which are multiples of either 3 or 5, each separated by a space. If no common multiples print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
20
```

**Output**
```text
20 18 15 12 10 9 6 5 3
```


### Sample Case 2

**Input**

**Output**
```text

```
