# Multiples of 3 or 5 Till N

## Description

Print numbers from 1 to N which are multiples of either 3 or 5.

## Input Format

A single integer N (1 <= N <= 10^5) representing the maximum natural number.

## Output Format

Print all numbers from 1 to N which are multiples of either 3 or 5, each separated by a space. If no common multiples print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
20
```

**Output**
```text
3 5 6 9 10 12 15 18 20
```


### Sample Case 2

**Input**


**Output**
