# First N Multiples of 5

## Description

Print the first N multiples of 5.

## Input Format

A single integer N (1 <= N <= 10^5) representing the number of multiples to print.

## Output Format

Print the first N multiples of 5, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
5 10 15 20 25
```


### Sample Case 2

**Input**
```text
3
```

**Output**
```text

```
