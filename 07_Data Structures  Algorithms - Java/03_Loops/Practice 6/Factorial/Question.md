# Factorial

## Description

<p>Given a non-negative integer N, find its factorial.</p>

## Input Format

<p>- An integer N (0 &lt;= N &lt;= 100) representing the input number.</p>

## Output Format

<p>- Print the factorial of N.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
e0:0e7cb327c2f111d152e47fe03f004cad:b07a300166c7ea58cc13fabed665f682
```

**Output**
```text
74d8a3:182ae85178e17e7331b86eb6b8d9e072:cd11a16569a3dc2c173bbd84f6ed8dff
```
