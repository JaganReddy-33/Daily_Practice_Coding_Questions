# Fibonacci Series

## Description

<p>Given a positive integer N, print the Fibonacci series of N terms.</p>

## Input Format

<p>A single integer N (1 &lt;= N &lt;= 50) representing the number of terms in the Fibonacci series.</p>

## Output Format

<p>- Print the Fibonacci series of N terms, each separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
0 1 1 2 3
```


### Sample Case 2

**Input**
```text
10
```

**Output**

