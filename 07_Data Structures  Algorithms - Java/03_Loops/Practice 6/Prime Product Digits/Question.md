# Prime Product Digits

## Description

<p>Given a positive integer N, print "Prime" if the product of all digits is prime, and print "Not Prime" if the product of all digits is not prime.</p>

## Input Format

<p>- A single integer N (1 &lt;= N &lt;= 10^9) representing the number.</p>

## Output Format

<p>- Print "Prime" if the product of all digits is prime, otherwise print "Not Prime".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
Not Prime
```


### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
Not Prime
```
