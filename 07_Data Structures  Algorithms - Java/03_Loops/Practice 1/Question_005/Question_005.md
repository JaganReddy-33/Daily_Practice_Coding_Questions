# Multiples of 3 and 5 Descending

**Question ID:** `661acdc9f51c6d596b08163a`

## Description

Print numbers from N to 1 which are multiples of both 3 and 5.

## Input Format

A single integer N (1 <= N <= 10^5) representing the starting natural number.

## Output Format

Print all numbers from N to 1 which are multiples of both 3 and 5, each separated by a space. If no common multiples print -1.
