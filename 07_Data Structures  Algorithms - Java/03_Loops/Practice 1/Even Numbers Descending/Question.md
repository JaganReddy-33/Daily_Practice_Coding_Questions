# Even Numbers Descending

## Description

Print even numbers from N to 1 in descending order.

## Input Format

A single integer N (1 <= N <= 10^5) representing the starting natural number.

## Output Format

Print all even numbers from N to 1 in descending order, each separated by a space. If no element to be printed, Print “None”.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
4 2
```

### Sample Case 2

**Input**
```text
10
```

**Output**
```text
10 8 6 4 2
```
