# Last Digit of N

## Description

Given a positive integer N, print the last digit of N.

## Input Format

A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

Print the last digit of N.

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
4
```


### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
5
```


### Sample Case 3

**Input**
```text
ace91720c7c6f3c901:35731175ff8efd6906f744b43a242bb8:24ffeb0c04a94653498a85dd937074c0
```

**Output**
```text
a3:278295af1ff648b0ec6b27d8e0696847:774c55673174a91ebe8c3dc822041edb
```
