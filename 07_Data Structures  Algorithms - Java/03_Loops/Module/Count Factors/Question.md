# Count Factors

## Description

Write a program to count factors of a given number.

## Input Format

First line consists of a positive integer n

## Output Format

Print the integer count.

## Sample Cases

### Sample Case 1

**Input**
```text
20
```

**Output**
```text
6
```

**Input**
```text
15
```
