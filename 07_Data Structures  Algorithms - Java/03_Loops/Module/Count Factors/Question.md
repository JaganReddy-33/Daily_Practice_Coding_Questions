# Count Factors

## Description

<p>Write a program to count factors of a given number.</p>

## Input Format

<p>First line consists of a positive integer n</p>

## Output Format

<p>Print the integer count.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
20
```

**Output**
```text
6
```


### Sample Case 2

**Input**
```text
15
```

**Output**
```text
4
```
