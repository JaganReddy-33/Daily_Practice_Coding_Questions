# Count Digits in Integer

## Description

<p>Count the number of digits in a positive integer.</p>

## Input Format

<p>A single positive integer num.</p>

## Output Format

<p>A single integer representing the count of digits.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
123456789
```

**Output**
```text
9
```


### Sample Case 2

**Input**
```text
987654
```

**Output**
```text
6
```
