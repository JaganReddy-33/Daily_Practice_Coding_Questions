# Count Digits in Integer

## Description

Count the number of digits in a positive integer.

## Input Format

A single positive integer num.

## Output Format

A single integer representing the count of digits.

## Sample Cases

### Sample Case 1

**Input**
```text
123456789
```

**Output**
```text
9
```

### Sample Case 2

**Input**
```text
987654
```

**Output**
```text
6
```
