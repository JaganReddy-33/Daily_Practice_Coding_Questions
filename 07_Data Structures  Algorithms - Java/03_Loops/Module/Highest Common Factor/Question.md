# Highest Common Factor

## Description

Write a program to find the greatest common factor of given 2 integers.

## Input Format

First line contains space separated three integer input n, m.

## Output Format

Print greatest common factor of 2 numbers.

## Sample Cases

### Sample Case 1

**Input**
```text
10 20
```

**Output**
```text
10
```

### Sample Case 2

**Input**
```text
15 30
```

**Output**
```text
15
```
