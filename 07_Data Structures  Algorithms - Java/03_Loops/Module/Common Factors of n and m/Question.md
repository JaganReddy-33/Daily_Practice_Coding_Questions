# Common Factors of n and m

## Description

Print the common factors of two positive integers n and m.

## Input Format

Two positive integers n and m separated by a space.

## Output Format

Common factors separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
10 25
```

**Output**
```text
1 5
```

### Sample Case 2

**Input**
```text
8 12
```

**Output**
```text
1 2 4
```
