# Multiples of 3 Between N1 and N2

## Description

Print all multiples of 3 from N1 to N2 in ascending order.

## Input Format

Two integers N1 and N2 (1 <= N1 <= 10^5, 1 <= N2 <= 10^5) representing the starting and ending natural numbers.

## Output Format

Print all multiples of 3 between N1 and N2 in ascending order, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5 15
```

**Output**
```text
6 9 12 15
```


### Sample Case 2

**Input**
```text
10 20
```

**Output**
```text
12 15 18
```
