# Multiples of N Till M

## Description

Print all multiples of N from 1 to M.

## Input Format

Two integers N and M (1 <= N <= 10^5, 1 <= M <= 10^5) representing the base number and the maximum natural number.

## Output Format

Print all multiples of N from 1 to M, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
3 10
```

**Output**
```text
3 6 9
```

### Sample Case 2

**Input**
```text
5 15
```

**Output**
```text
5 10 15
```
