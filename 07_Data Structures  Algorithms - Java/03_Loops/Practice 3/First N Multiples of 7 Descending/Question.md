# First N Multiples of 7 Descending

## Description

Print the first N multiples of 7 in descending order.

## Input Format

A single integer N (1 <= N <= 10^5) representing the number of multiples to print.

## Output Format

Print the first N multiples of 7 in descending order, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
35 28 21 14 7
```


### Sample Case 2

**Input**
```text
3
```

**Output**
```text
21 14 7
```
