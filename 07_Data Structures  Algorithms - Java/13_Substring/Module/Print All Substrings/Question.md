# Print All Substrings

## Description

<p>Print all possible substrings of a given string.</p>

## Input Format

<p>The input consists of a single line containing a string, `str`.</p>

## Output Format

<p>Multiple lines, each containing a substring of the input string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
abc
```

**Output**
```text
a
b
c
ab
bc
abc
```


### Sample Case 2

**Input**
```text
tap
```

**Output**
```text
t
a
p
ta
ap
tap
```
