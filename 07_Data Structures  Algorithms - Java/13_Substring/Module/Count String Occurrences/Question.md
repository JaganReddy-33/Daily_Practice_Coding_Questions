# Count String Occurrences

## Description

<p>Count the occurrences of a smaller string in a larger string.</p>

## Input Format

<p>The input consists of two lines.</p><p>The first line contains the larger string `str1`.</p><p>Second line contains the smaller string `str2`.</p>

## Output Format

<p>A single line containing an integer, representing the count of occurrences of `str2` in `str1`.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
abababab
aba
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
tapacademytapacademy
tap
```

**Output**
```text
2
```
