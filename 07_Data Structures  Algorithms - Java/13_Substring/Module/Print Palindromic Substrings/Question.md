# Print Palindromic Substrings

## Description

<p>Print all palindromic substrings of a given string.</p>

## Input Format

<p>The input consists of a single line containing a string, `str`.</p>

## Output Format

<p>Multiple lines, each containing a palindromic substring of the input string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
abccba
```

**Output**
```text
a
b
c
c
b
a
cc
bccb
abccba
```


### Sample Case 2

**Input**
```text
tapa
```

**Output**
```text

a
p
a
apa
```
