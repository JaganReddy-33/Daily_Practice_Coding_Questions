# Check characters in a string

## Description

<p>Check whether characters in the second string are present in the first string . There is no need for the characters to be consecutive.</p>

## Input Format

<p>The input consists of two lines.</p><p>- The first line contains the first string, 'str1'.</p><p>- The second line contains the second string, 'str2'.</p>

## Output Format

<p>Output 'Yes' if the characters in 'str2' are present in 'str1' in the same order, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Academy
Tap
```

**Output**
```text
No
```


### Sample Case 2

**Input**
```text
Programming
graming
```

**Output**
```text
Yes
```
