# Palindromic Substrings of Length 4

## Description

<p>Print all palindromic substrings of length 4 from a given string.</p>

## Input Format

<p>The input consists of a single line containing a string, `str`.</p>

## Output Format

<p>Multiple lines, each containing a palindromic substring of length 4.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
abcbxyzzyy
```

**Output**
```text
yzzy
```


### Sample Case 2

**Input**
```text
mississippi
```

**Output**
```text
issi
issi
ippi
```
