# Kth Largest Element

## Description

<p>Given an array of integers, find and print the Kth largest element in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer K.</p>

## Output Format

<p>Print the Kth largest element in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
2
```

**Output**
```text
4
```


### Sample Case 2

**Input**
```text
7
3 7 1 5 6 4 2
3
```

**Output**
```text
5
```
