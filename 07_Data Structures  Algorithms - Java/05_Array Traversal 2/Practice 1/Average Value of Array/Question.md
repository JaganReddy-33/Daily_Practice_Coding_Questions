# Average Value of Array

## Description

<p>Given an array of integers, find the average value of the array excluding the largest and smallest numbers.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the average value of the array excluding the largest and smallest numbers. Print the result with 2 decimal places.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3.00
```


### Sample Case 2

**Input**
```text
7
3 7 1 5 6 4 2
```

**Output**
```text
4.00
```
