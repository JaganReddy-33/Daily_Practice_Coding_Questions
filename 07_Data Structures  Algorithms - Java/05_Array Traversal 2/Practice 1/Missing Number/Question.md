# Missing Number

## Description

<p>Given an array of integers, print the missing number in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array.</p><p>The second line contains N space-separated integers representing the array elements (integers are in the range [1, N]).</p>

## Output Format

<p>Print the missing number in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 2 4 5
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
6
4 2 3 1 7 6
```

**Output**
```text
5
```

```

d9:e15267f478a3914be867d713502c03cc:3a754eeedf498326d40e02590ca037a0
```
