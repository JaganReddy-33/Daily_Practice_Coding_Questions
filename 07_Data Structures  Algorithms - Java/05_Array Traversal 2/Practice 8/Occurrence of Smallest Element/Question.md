# Occurrence of Smallest Element

## Description

<p>Given an array of integers of size N, find and display the occurrence of the smallest element present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the occurrence of the smallest element present in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 4 14 4
```

**Output**
```text
3
```

```text
ed:7047679fa549c3a570a6da3e812c0b9b:ff8986514a68510fa172426819d8dad8
```
