# Occurrence of Largest Element

## Description

Given an array of integers of size N, find and display the occurrence of the largest element present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the occurrence of the largest element present in the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
1
```


### Sample Case 3

**Input**


```text
a3:9b543cfc7ad624a10169455b7e2c715f:b88ecbed058be9816751f30ceba31293
```
