# Odd Numbers Array

## Description

<p>Write a program to print odd numbers present in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print space separated odd integer values stored in an array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
1 3
```


### Sample Case 2

**Input**
```text
4
21 31 41 51
```

**Output**
```text

```
