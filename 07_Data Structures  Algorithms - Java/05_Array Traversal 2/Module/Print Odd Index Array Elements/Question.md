# Print Odd Index Array Elements

## Description

<p>Print elements of the array located at odd indices.</p>

## Input Format

<p>The function should prompt the user to enter the size of the array and the array elements.</p>

## Output Format

<p>Print the odd-indexed array elements on a single line, each element separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
2
7 8
```

**Output**
```text
8
```


### Sample Case 2

**Input**
```text
8
10 20 30 40 50 60 70 80
```

**Output**
```text
20 40 60 80
```
