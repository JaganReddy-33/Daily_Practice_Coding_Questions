# Missing Element

## Description

<p>Find the missing element in an unsorted array without using sorting.</p>

## Input Format

<p>The first line consists of the size of the array, followed by a line containing space-separated integers representing the elements of the array.</p>

## Output Format

<p>Output a single integer representing the missing element.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 4 2 7 5 3
```

**Output**
```text
6
```


### Sample Case 2

**Input**
```text
10
1 2 3 6 8 7 4 5 10 11
```

**Output**
```text
9
```
