# Even, Odd and Negative Elements in Array

## Description

<p>Write a program to print negative elements, even elements and odd elements present in an array separately.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>First line prints space separated negative elements in an array. </p><p>Second line prints space separated odd elements in an array. </p><p>Third line prints space separated even elements in an array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 -4 -6 3 10 -20
```

**Output**
```text
-4 -6 -20
1 3
10
```


### Sample Case 2

**Input**
```text
5
5 -10 -15 20 -25
```

**Output**
```text
-10 -15 -25
5
20
```
