# Second Smallest Number

## Description

<p>Write a program that finds the second smallest number in a given array of integers.</p>

## Input Format

<p>The first line contains a single integer, N, representing the size of the array. The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the second smallest number in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
5 9 2 8 3 7
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
7
10 5 8 2 6 1 4
```

**Output**
```text
2
```
