# Sum Divisible Elements

## Description

<p>Write a program to find the sum of elements which are divisible by 3 and 5 in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print sum of elements which are divisible by 3 and 5 in an array</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
0
```


### Sample Case 2

**Input**
```text
5
15 30 35 40 45
```

**Output**
```text

```
