# Occurrence of Smallest Element in an Array

## Description

<p>Write a program to find the occurrence of the smallest element in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print the occurrence of smallest element</p>

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 2 3 1
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
7
1 2 3 4 5 6 1
```

**Output**
```text
2
```


### Sample Case 3

**Input**
```text
0e25508c80a2b4392604cf749f1f6c:f6f19cb4461e8f9d86717d969a645cea:74c04b7b6cd2ab44b9385a53f5fad8e8
```

**Output**
```text
68:9e918e24821e56fee5d532ea6d6dffae:ec8059e5442249b253ed322d65574768
```


### Sample Case 4

**Input**
```text
fe2336510985a6bf2d8854:c2186199e1ab7635cb1189a03a9b2617:1357d8c76e710a6ec2ad1fd124ae24ca
```

**Output**
```text
90:c3d9e2fda73a7ce8fea491f0fa7e2179:96425f861623be84edea5d08d6de80f4
```
