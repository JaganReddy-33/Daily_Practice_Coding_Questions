# Index of K Value in Array

## Description

<p>The goal of this task is to write a Java program that finds the index of a given value K in a given array. If K is not found in the array, the program should print -1.</p>

## Input Format

<p>The first line contains a single integer, N, representing the size of the array. </p><p>The second line contains N space-separated integers, representing the elements of the array. </p><p>The third line contains a single integer, K, representing the value to be found.</p>

## Output Format

<p>Print the index of the first occurrence of K in the array. If K is not found, print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
5 9 2 8 3 7 2
2
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text

5
```

**Output**
```text

```
