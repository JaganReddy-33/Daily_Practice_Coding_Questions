# Index of Largest Element

## Description

<p>Find the index of the largest element in an array.</p>

## Input Format

<p>The first line contains an integer 'n' (1 &lt;= n &lt;= 100), representing the size of the array.</p><p>The second line contains 'n' space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the index of the largest element in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 7 15 4 8
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
4
1 8 3 9
```

**Output**
```text
3
```


**Output**
```text
b5:43e2d294b84aea7e162b8718cdb24d20:0c91966da055241ea5c7c393a224da4b
```
