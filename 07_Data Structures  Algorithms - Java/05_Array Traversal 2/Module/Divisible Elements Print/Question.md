# Divisible Elements Print

## Description

<p>Write a program to print the elements which are divisible by 2 and 3 in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print elements which are divisible by 2 and 3 in an array</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
6
```


### Sample Case 2

**Input**
```text
5

```

**Output**
