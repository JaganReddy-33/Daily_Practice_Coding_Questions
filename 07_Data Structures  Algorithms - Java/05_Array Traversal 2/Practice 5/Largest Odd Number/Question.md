# Largest Odd Number

## Description

Given an array of integers, find and display the largest odd number present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the largest odd number present in the array. If no odd number is present, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 2 4
```

**Output**
```text
5
```


### Sample Case 2

**Input**
```text
4
-2 -1 -3 -4
```

**Output**
```text
-1
```
