# Second Largest Odd Number

## Description

<p>Given an array of integers, find and display the second-largest odd number present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the second-largest odd number present in the array. If less than two odd numbers are present, print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 3 5 7 9 11
```

**Output**
```text
9
```


### Sample Case 2

**Input**
```text
5
2 4 6 8 10
```

**Output**
```text
-1
```


### Sample Case 3

**Input**
```text

```

**Output**
```text
c042:e2a65c9684ae3c4b786b5328a334a161:9f99ab6c81ffaaee3665bc4608bd1dae
```
