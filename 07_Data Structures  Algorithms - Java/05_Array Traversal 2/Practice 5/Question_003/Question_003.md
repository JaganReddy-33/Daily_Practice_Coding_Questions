# Second Largest Odd Number

**Question ID:** `661e0883f51c6d596bb7c05e`

## Description

Given an array of integers, find and display the second-largest odd number present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the second-largest odd number present in the array. If less than two odd numbers are present, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 3 5 7 9 11
```

**Output**
```text
9
```

### Sample Case 2

**Input**
```text
5
2 4 6 8 10
```

**Output**
```text
-1
```
