# Replace Even Elements with -1

## Description

<p>Given an array of integers, replace all even elements with -1.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the modified array where all even elements are replaced with -1, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 -1 3 -1 5
```


### Sample Case 2

**Input**
```text
6
6 4 2 1 3 5
```

**Output**
```text
-1 -1 -1 1 3 5
```
