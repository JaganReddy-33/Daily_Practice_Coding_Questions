# Replace Divisible Elements

## Description

<p>Given an array of integers, replace all elements divisible by k with k.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer k.</p>

## Output Format

<p>Print the modified array where all elements divisible by k are replaced with k, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 5 20 7 12
5
```

**Output**
```text
5 5 5 7 12
```


### Sample Case 2

**Input**
```text
6
-12 24 15 10 -20 36
6
```

**Output**
```text
-6 6 15 10 -20 6
```
