# Replace Odd Elements with -1

## Description

Given an array of integers, replace all odd elements with -1.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the modified array where all odd elements are replaced with -1, separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
-1 2 -1 4 -1
```

### Sample Case 2

**Input**
```text
6
-3 -2 -1 0 1 2
```

**Output**
```text
-1 -2 -1 0 -1 2
```
