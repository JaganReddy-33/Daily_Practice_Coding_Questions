# Average of Pair Sum

**Question ID:** `661e0828f51c6d596bb7b04d`

## Description

Given an array of integers of size N, find and display the average of the minimum and maximum pair sum of the elements present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the average of the minimum and maximum pair sum of the elements present in the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 2 4
```

**Output**
```text
6.0
```

### Sample Case 2

**Input**
```text
4
-2 -1 -3 -4
```
