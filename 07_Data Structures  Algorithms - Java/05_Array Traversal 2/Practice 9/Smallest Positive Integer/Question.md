# Smallest Positive Integer

## Description

<p>Given an array of integers of size N, find and display the smallest positive integer present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the smallest positive integer present in the array. If there are no positive integers, print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
-1 -2 -3 -4 -5
```

**Output**
```text
-1
```


### Sample Case 2

**Input**
```text
4
-4 6 -8 9
```

**Output**
```text
6
```


### Sample Case 3

**Input**


```text
ac:e6a6dcc0ff31e8a87257359135e1d9d1:6690bb4faa75fca6effde0c633f01585
```
