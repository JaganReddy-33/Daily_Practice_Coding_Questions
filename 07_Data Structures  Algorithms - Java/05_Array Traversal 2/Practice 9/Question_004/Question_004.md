# Smallest Element in Array

**Question ID:** `661e0769f51c6d596bb7896a`

## Description

Given an array of integers of size N, find and display the smallest element present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the smallest element present in the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1
```

### Sample Case 2

**Input**
```text
7
12 14 16 4 6 8 10
```

**Output**
```text
4
```
