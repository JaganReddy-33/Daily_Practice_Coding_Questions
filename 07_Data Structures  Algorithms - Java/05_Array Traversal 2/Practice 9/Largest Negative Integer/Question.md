# Largest Negative Integer

## Description

<p>Given an array of integers of size N, find and display the largest negative integer present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the largest negative integer present in the array. If there are no negative integers, print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
4
-4 6 -8 9
```

**Output**
```text
-4
```


### Sample Case 2

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
-1
```

```text
006e:907f6532b103c9f69cd368a4bd7eca6f:7dc18ce3a0c8e83e03bb5d9e3c8c6f35
```
