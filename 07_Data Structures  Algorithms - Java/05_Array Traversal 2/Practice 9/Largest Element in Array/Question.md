# Largest Element in Array

## Description

<p>Given an array of integers of size N, find and display the largest element present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the largest element present in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
5
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
16
```


### Sample Case 3

**Input**


```text
a894:3570315acdfdf66e2b2551d24956868e:e62002fd066fb6d72cab49a0ddce6b73
```
