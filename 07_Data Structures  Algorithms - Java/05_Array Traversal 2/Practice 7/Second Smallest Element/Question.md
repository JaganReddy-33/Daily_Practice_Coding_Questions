# Second Smallest Element

## Description

<p>Given an array of integers of size N, find and display the second smallest element present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the second smallest element present in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
6
```


### Sample Case 3

**Input**
```text
2a8b6420e628f84d11af0f994a0a:b0c8b24c3779895ad57a307d375a6522:2ea659111d9cd1821982bc99607d1cfe
```

**Output**
```text
fb:4650961efb0f9c7a9d1a2fe5f04bce0a:6fca4417ea7f75fe146f3c30d2083796
```
