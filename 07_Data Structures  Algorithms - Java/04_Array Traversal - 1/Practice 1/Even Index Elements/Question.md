# Even Index Elements

## Description

<p>Given an array of integers of size N, print all the elements present at even indices.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print all the elements present at even indices of the array, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 3 5
```


### Sample Case 2

**Input**
