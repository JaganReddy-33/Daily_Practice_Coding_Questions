# Sum of Even Index Elements

## Description

Given an array of integers of size N, print the sum of all elements present in the even indices of the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the sum of all elements present in the even indices of the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
9
```

### Sample Case 2

**Input**
```text
4
-2 0 3 6
```

**Output**
```text
1
```
