# Odd Index Elements from Middle to End

## Description

<p>Given an array of integers of size N, print all the elements present in the odd indices of the array from the middle to the end of the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print all the elements present in the odd indices of the array from the middle to the end of the array, separated by a space. If no elements found print “None”</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
4
```


### Sample Case 2

**Input**
```text
6

```

**Output**
```text
6 9
```
