# Odd Index Elements from Start to Middle

## Description

<p>Given an array of integers of size N, print all the elements present in the odd indices of the array from the start to the middle of the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print all the elements present in the odd indices of the array from the start to the middle of the array, separated by a space. If no odd index element print "None".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 9
```

**Output**
```text
0 6
```
