# Sum of Array Elements from Start to Middle

## Description

<p>Calculate and print the sum of elements of the array from the starting to the middle.</p>

## Input Format

<p>The function should prompt the user to enter the size of the array and the array elements.</p>

## Output Format

<p>Print a single integer, representing the sum of the elements.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
2
7 8
```

**Output**
```text
7
```


### Sample Case 2

**Input**
```text
7
10 20 30 40 50 60 70
```

**Output**
```text
60
```
