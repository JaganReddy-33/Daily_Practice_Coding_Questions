# Largest Element in an Array

## Description

<p>Write a program to find the largest element in a given array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print largest element in an array</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 5 7 3 2
```

**Output**
```text
7
```


### Sample Case 2

**Input**
```text
6
0 -1 -2 -3 -4 -5
```

**Output**
```text
0
```


### Sample Case 3

**Output**
```text
4923:68be92cc0117d2a297d3c9ee8b0fd2d7:e2a0acf53ded4d2c42705448b8a8efb4
```
