# Product of Array Elements from Middle Index to End

## Description

<p>Calculate and print the product of elements of the array from the middle to the end.</p>

## Input Format

<p>The function should prompt the user to enter the size of the array and the array elements.</p>

## Output Format

<p>Print a single integer, representing the product of the elements.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
2
7 8
```

**Output**
```text
8
```


### Sample Case 2

**Input**
```text
7
10 20 30 40 50 60 70
```

**Output**
```text
8400000
```
