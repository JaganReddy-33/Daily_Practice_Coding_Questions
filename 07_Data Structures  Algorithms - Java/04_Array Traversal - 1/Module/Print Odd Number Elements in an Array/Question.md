# Print Odd Number Elements in an Array

## Description

<p>Print odd number elements of the array.</p>

## Input Format

<p>The function should prompt the user to enter the size of the array and the array elements.</p>

## Output Format

<p>Print the odd number elements on a single line, each element separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
2 1 6
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
7
1 2 3 4 5 6 7
```

**Output**
```text
1 3 5 7
```
