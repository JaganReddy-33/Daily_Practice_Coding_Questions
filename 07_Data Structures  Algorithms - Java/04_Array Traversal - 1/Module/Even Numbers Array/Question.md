# Even Numbers Array

## Description

<p>Write a program to print even numbers present in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print space separated even integer values in an array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
4 6 10
```


### Sample Case 2

**Input**
```text
4
20 30 40 50
```

**Output**
```text
20 30 40 50
```
