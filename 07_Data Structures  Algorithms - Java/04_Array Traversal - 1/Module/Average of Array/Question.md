# Average of Array

## Description

<p>Write a program to find the average of all elements present in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print float value of average of all elements in an array. [it has to print 2 decimal points]</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
4.80
```


### Sample Case 2

**Input**
```text
5
5 -10 -15 20 -25
```

**Output**
```text
-5.00
```
