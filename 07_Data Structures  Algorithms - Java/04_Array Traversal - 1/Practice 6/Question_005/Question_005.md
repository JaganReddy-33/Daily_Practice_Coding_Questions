# Sum of Negative Elements

**Question ID:** `661d68a2f51c6d596ba5b1fe`

## Description

Given an array of integers of size N, print the sum of all the negative integers present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the sum of all negative integers present in the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 -2 3 -4 5
```

**Output**
```text
-6
```

### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 -9
```
