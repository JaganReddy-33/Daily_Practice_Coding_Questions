# Count of True and False Values

## Description

<p>Given an array of boolean values of size N, print the number of true and false values.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated boolean values (true or false) representing the array elements.</p>

## Output Format

<p>Print two integers separated by a space, representing the count of true values and false values respectively.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
true false true false true
```

**Output**
```text
3 2
```


### Sample Case 2

**Input**
```text
7
false false true true false true true
```

**Output**
```text
4 3
```
