# Difference in Average of Positive and Negative Double Values

**Question ID:** `661d68d35028dc4e9db20305`

## Description

Given an array of double values of size N, print the difference between the average of all positive real number values and the average of all negative real number values present in the array.

## Input Format

The first line contains an integer N, the size of the array.

The second line contains N space-separated real number values representing the double array elements.

## Output Format

Print the difference between the average of all positive real number values and the average of all negative real number values present in the array. Print the result rounded to two decimal places.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1.5 -2.0 3.5 -4.2 5.3
```

**Output**
```text
6.53
```

### Sample Case 2

**Input**
```text
6
-2.5 0.0 3.2 6.5 8.1 -9.7
```

**Output**
```text
12.03
```
