# Product of Float Values

## Description

<p>Given an array of real number values of size N, print the product of all values present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated real number values representing the array elements.</p>

## Output Format

<p>Print the product of all values present in the array. Print the result rounded to two decimal places.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1.5 2.0 3.5 4.2 5.3
```

**Output**
```text
233.73
```


### Sample Case 2

**Input**
```text
6
-2.5 0.0 3.2 6.5 8.1 -9.7
```

**Output**
```text
0.00
```
