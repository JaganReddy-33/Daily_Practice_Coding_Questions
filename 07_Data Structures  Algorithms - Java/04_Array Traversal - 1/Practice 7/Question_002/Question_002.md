# Difference in Average of Positive and Negative Integers

**Question ID:** `661d68c35028dc4e9db1fe56`

## Description

Given an array of integers of size N, print the difference between the average of all positive integers and the average of all negative integers present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the difference between the average of all positive integers and the average of all negative integers present in the array. Print the result rounded to two decimal places.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 -2 3 -4 5
```

**Output**
```text
6.00
```

### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 -9
```

**Output**
```text
11.17
```
