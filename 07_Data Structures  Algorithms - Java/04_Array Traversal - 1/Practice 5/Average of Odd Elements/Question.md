# Average of Odd Elements

## Description

<p>Given an array of integers of size N, print the average of all the odd elements present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the average of all the odd elements present in the array. Print the result rounded to two decimal places. If no elements found print “None”</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3.00
```


### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 9
```

**Output**
```text
6.00
```
