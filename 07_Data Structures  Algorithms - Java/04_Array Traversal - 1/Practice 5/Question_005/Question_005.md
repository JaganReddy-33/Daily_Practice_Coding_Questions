# Average of Odd Elements

**Question ID:** `661d683d5028dc4e9db1d0ec`

## Description

Given an array of integers of size N, print the average of all the odd elements present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the average of all the odd elements present in the array. Print the result rounded to two decimal places. If no elements found print “None”

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3.00
```

### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 9
```

**Output**
```text
6.00
```
