# Product of Even Index Elements from Start to Middle

## Description

<p>Given an array of integers of size N, print the product of all the elements present in the even indices of the array from the start to the middle of the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the product of all the elements present in the even indices of the array from the start to the middle of the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text

```

**Output**
```text
-6
```
