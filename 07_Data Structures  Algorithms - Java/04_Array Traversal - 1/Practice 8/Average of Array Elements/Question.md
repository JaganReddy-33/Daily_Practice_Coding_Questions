# Average of Array Elements

## Description

Given an array of integers of size N, print the average of all array elements.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the average of all array elements as a floating-point number.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3.0
```

### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
10.0
```
