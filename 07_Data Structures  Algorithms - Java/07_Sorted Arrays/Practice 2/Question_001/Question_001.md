# Odd Unique Elements

**Question ID:** `662a0d11ae2286cdf8e15470`

## Description

Given a sorted array of integers, print all the odd unique elements present in the array.

## Input Format

First line contains an integer n representing the size of the array. Second line contains n space separated integers values.

## Output Format

Print all the odd unique elements present in the array separated by space. If the odd unique element is not present, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
```

**Output**
```text
1
```

### Sample Case 2

**Input**
```text
10
-3 -3 -2 -2 -1 -1 0 0 1 1
```

**Output**
```text
-1
```
