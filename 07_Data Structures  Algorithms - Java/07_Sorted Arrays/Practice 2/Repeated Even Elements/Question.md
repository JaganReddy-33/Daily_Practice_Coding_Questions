# Repeated Even Elements

## Description

<p>Given a sorted array of integers, print all the repeated even elements.</p>

## Input Format

<p>First line contains an integer n representing the size of the array. Second line contains n space separated integers values.</p>

## Output Format

<p>Print all the repeated even elements separated by space. If there are no even repeated elements, print “None”.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
9
1 2 2 3 4 4 5 6 6
```

**Output**
```text
2 4 6
```


### Sample Case 2

**Input**
```text
10
-4 -3 -3 -2 -2 -1 -1 0 0 1
```

**Output**
```text
-2 0
```
