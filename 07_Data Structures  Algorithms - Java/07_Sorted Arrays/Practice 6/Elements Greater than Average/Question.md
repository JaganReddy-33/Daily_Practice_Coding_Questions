# Elements Greater than Average

## Description

Given a sorted array of integers, print all the elements of the array that are greater than the average of the array.

## Input Format

First line contains an integer n representing the size of the array
The second line consists of space-separated integers representing the sorted array.

## Output Format

Print all the elements of the array that are greater than the average of the array, separated by space. If there are no such elements, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
4 5
```


### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
```

**Output**
```text
1 2 3
```
