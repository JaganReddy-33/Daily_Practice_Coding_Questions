# Perfect Square Elements

## Description

Given a sorted array of integers, print all the elements of the array that are perfect squares.

## Input Format

First line contains an integer n representing the size of the array The second line consists of space-separated integers representing the sorted array.

## Output Format

Print all the elements of the array that are perfect squares, separated by space. If there are no such elements, print "-1".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 4
```

### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
```

**Output**
```text
0 1
```
