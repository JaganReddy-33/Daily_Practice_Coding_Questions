# K Smallest Elements

## Description

Given a sorted array of integers, print the k smallest elements in the array.

## Input Format

The input consists of three lines:
First line contains an integer n representing the size of the array
- The second line contains space-separated integers representing the sorted array.
- The third line contains a single integer k.

## Output Format

Print the k smallest elements of the array, separated by space.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
3
```

**Output**
```text
1 2 3
```


### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3

```

**Output**
```text
-3 -2 -1 0
```
