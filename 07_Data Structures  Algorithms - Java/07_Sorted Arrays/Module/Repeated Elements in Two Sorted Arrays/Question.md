# Repeated Elements in Two Sorted Arrays

## Description

<p>Find and print the elements that are repeated in both given sorted arrays.</p>

## Input Format

<p>The input consists of four lines:</p><p>An integer N (1 ≤ N ≤ 10^5), representing the number of elements in array A.</p><p>N space-separated integers, denoting the elements of array A </p><p>An integer M (1 ≤ M ≤ 10^5), representing the number of elements in array B</p><p>M space-separated integers, denoting the elements of array B.</p>

## Output Format

<p>Print the repeated elements from both arrays in ascending order, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
2 4 5 5 7 8
7
2 3 5 5 6 7 8
```

**Output**
```text
2 5 5 7 8
```

**Input**

