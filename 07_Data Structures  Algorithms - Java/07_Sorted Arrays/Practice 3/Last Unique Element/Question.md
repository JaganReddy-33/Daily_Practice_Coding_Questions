# Last Unique Element

## Description

<p>Given a sorted array of integers, print the last unique element.</p>

## Input Format

<p>First line contains an integer n representing the size of the array. The input consists of a single line containing space-separated integers.</p>

## Output Format

<p>Print the last unique element. If there are no unique elements, print "-1".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
```

**Output**
```text
6
```


### Sample Case 2

**Input**
```text
10
-3 -3 -2 -2 -1 -1 0 0 1 1
```

**Output**
```text
-1
```
