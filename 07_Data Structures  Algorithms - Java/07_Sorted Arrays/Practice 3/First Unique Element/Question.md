# First Unique Element

## Description

Given a sorted array of integers, print the first unique element.

## Input Format

First line contains an integer n representing the size of the array. The input consists of a single line containing space-separated integers.

## Output Format

Print the first unique element. If there are no unique elements, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
10
-3 -3 -2 -2 -1 -1 0 0 1 1
```

**Output**
```text
None
```
