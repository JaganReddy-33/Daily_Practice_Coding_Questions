# Last Repeating Element

## Description

Given a sorted array of integers, print the last repeating element.

## Input Format

First line contains an integer n representing the size of the array. The input consists of a single line containing space-separated integers.

## Output Format

Print the last repeating element. If there are no repeating elements, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
```

**Output**
```text
5
```


### Sample Case 2

**Input**
```text
10
-3 -3 -2 -2 -1 -1 0 0 1 1
```

**Output**
```text
1
```


### Sample Case 3

**Input**
```text
e2324701946b1c9bb0b580:b92b33ae5fc561f3a9c420246c57d0ea:5d21d34aae21e2a3aa24594782c63128
```

**Output**
```text
7d:9bb6d2c2c4d2b9147c25dbc4584b8511:579ccdaf4238dffcec2431d0805e52dd
```
