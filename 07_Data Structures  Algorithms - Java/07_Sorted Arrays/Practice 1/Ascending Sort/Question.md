# Ascending Sort

## Description

<p>Given an array of integers, sort the given array in ascending order.</p>

## Input Format

<p>First line contains an integer n representing the size of the array. Second line contains n space separated integers values.</p>

## Output Format

<p>Print the sorted array in ascending order separated by space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
5 2 7 1 3
```

**Output**
```text
1 2 3 5 7
```


### Sample Case 2

**Input**
```text
6
9 4 6 2 8 3
```

**Output**
```text
2 3 4 6 8 9
```
