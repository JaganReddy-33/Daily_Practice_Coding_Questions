# Unique Elements

## Description

<p>Given a sorted array of integers, print all the unique elements present in the array.</p>

## Input Format

<p>First line contains an integer n representing the size of the array. Second line contains n space separated integers values.</p>

## Output Format

<p>Print all the unique elements present in the array separated by space. If there are no unique elements print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
```

**Output**
```text
1 4 6
```


### Sample Case 2

**Input**
```text
10
-3 -3 -2 -2 -1 -1 0 0 1 1
```

**Output**
```text
-1
```
