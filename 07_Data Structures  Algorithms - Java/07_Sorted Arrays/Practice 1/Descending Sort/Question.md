# Descending Sort

## Description

<p><span style="background-color: rgb(245, 245, 245);">Given an array of integers, sort the given array in d</span>escending<span style="background-color: rgb(245, 245, 245);"> order.</span></p>

## Input Format

<p>The first line contains an integer N, the size of the array.</p><p>The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p><span style="background-color: rgb(245, 245, 245);">Print the sorted array in descending order separated by space.</span></p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
5 2 7 1 3
```

**Output**
```text
7 5 3 2 1
```


### Sample Case 2

**Input**
```text
6
9 4 6 2 8 3
```

**Output**
```text
9 8 6 4 3 2
```
