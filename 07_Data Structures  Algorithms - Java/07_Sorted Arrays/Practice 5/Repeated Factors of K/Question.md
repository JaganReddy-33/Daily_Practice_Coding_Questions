# Repeated Factors of K

## Description

Given a sorted array of integers and an integer K, print only the repeated values once which are factors of K.

## Input Format

The input consists of two lines:
First line contains an integer n representing the size of the array
- The Second line contains space-separated integers representing the sorted array.
- The Third line contains a single integer K.

## Output Format

Print only the repeated values once which are factors of K, separated by space. If there are no such values, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
12
```

**Output**
```text
2 3
```

### Sample Case 2

**Input**
```text
5
1 1 1 1 1
1
```

**Output**
```text
1
```
