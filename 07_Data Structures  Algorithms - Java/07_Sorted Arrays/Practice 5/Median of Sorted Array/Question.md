# Median of Sorted Array

## Description

<p>Given a sorted array of integers, print the median of the array.</p>

## Input Format

<p>First line contains an integer n representing the size of the array The Second line consists of a single line containing space-separated integers.</p>

## Output Format

<p>Print the median of the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
```

**Output**
```text
0
```
