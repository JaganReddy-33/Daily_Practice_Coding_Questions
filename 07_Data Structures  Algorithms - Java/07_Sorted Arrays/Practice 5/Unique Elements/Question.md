# Unique Elements

## Description

Given a sorted array of integers, print all the elements of the array without repeating.

## Input Format

First line contains an integer n representing the size of the array
The  second line  consists of a single line containing space-separated integers.

## Output Format

Print all the unique elements of the array separated by space.

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
```

**Output**
```text
1 2 3 4 5 6
```


### Sample Case 2

**Input**
```text
10
-3 -3 -2 -2 -1 -1 0 0 1 1
```

**Output**
```text
-3 -2 -1 0 1
```
