# Elements Within Range

## Description

Given a sorted array of integers and a range [L, R], print all the elements of the array that are within the given range.

## Input Format

The input consists of three lines:
First line contains an integer n representing the size of the array
- The second line contains space-separated integers representing the sorted array.
- The Third line contains two integers L and R, representing the range.

## Output Format

Print all the elements of the array that are within the range [L, R], separated by space. If there are no such elements, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
2 4
```

**Output**
```text
2 3 4
```

### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
-1 1
```

**Output**
```text
-1 0 1
```
