# Unique Factors of K

## Description

<p>Given a sorted array of integers and an integer K, print the unique elements from the array that are factors of K.</p>

## Input Format

<p>The input consists of three lines: - First line contains an integer n representing the size of the array - The second line contains space-separated integers representing the sorted array. - The third line contains a single integer K.</p>

## Output Format

<p>Print the unique factors of K from the array separated by space. If there are no such factors, print 'None'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 2 3 4 5 6
12
```

**Output**
```text
1 2 3 4 6
```


### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
6
```

**Output**
```text
-3 -2 -1 1 2 3
```
