# Prime Unique Elements

## Description

<p>Given a sorted array of integers, print the unique elements which are prime.</p>

## Input Format

<p>First line contains an integer n representing the size of the array. The second line consists of a single line containing space-separated integers.</p>

## Output Format

<p>Print the unique prime elements separated by space. If there are no prime elements, print 'None'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 4 4 5 6 6 6
```

**Output**
```text
3 5
```


### Sample Case 2

**Input**
```text
10
-3 -3 -2 -2 -1 -1 0 0 1 1
```

**Output**
```text
None
```
