# Three Digit Number

## Description

<p>Check whether the given number is a three-digit number or not.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output 'Yes' if the number is a three-digit number, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
145
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
1000
```

**Output**
```text
No
```


### Sample Case 3

**Input**
```text
7d7f5c:37eb5a4f8892386b0ee813f63a55ce15:ea59cc666efbee18aa283881d935e586

```
