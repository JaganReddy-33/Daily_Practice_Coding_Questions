# Number ASCII Check

## Description

<p>Check if a given number is the ASCII value of a numeric character or not.</p>

## Input Format

<p>The input consists of a single line containing an integer, n.</p>

## Output Format

<p>Print 'Yes' if the number is an ASCII value of a numeric character, and 'No' otherwise.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
50
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
88
```

**Output**
```text
No
```
