# Multiple of 5 and 3

## Description

<p>Check whether the given number is a multiple of both 5 and 3.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output 'Yes' if the number is a multiple of both 5 and 3, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
15
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
30
```

**Output**
```text
Yes
```
