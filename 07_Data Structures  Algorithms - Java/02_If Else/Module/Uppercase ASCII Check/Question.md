# Uppercase ASCII Check

## Description

<p>Check if a given number is the ASCII value of an uppercase alphabet or not.</p>

## Input Format

<p>The input consists of a single line containing an integer, n.</p>

## Output Format

<p>Print 'Yes' if the number is an ASCII value of an uppercase alphabet, and 'No' otherwise.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
78
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
88
```

**Output**
```text
Yes
```
