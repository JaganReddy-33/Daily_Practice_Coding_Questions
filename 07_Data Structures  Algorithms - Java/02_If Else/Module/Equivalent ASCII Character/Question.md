# Equivalent ASCII Character

## Description

<p>Print the equivalent ASCII character of a given number.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output the equivalent ASCII character.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
98
```

**Output**
```text
b
```


### Sample Case 2

**Input**
```text
72
```

**Output**
```text
H
```


### Sample Case 3

**Input**
```text
65f4:d7637ee9a8dfec2ab8e92ef50a8a0b91:bc0b5c0091eb41a2563c1bc5d8c9f390
```

```text

```
