# ASCII Value of Character

## Description

<p>Print the ASCII value of a character.</p>

## Input Format

<p>The input consists of a single character 'c' on a single line.</p>

## Output Format

<p>Output the ASCII value of the character as an integer.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
A
```

**Output**
```text
65
```


### Sample Case 2

**Input**
```text
a
```

**Output**
```text
97
```

**Input**

01:2c304b5c4de5a88a133644e32cc3a96e:21497aaf27c20a39908c930f108de0a2
