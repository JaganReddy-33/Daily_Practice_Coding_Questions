# Multiple of 5, 3, and 7

## Description

<p>Check whether the given number is a multiple of 5, 3, and 7.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output 'Yes' if the number is a multiple of 5, 3, and 7, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
14
```

**Output**
```text
No
```


### Sample Case 2

**Input**
```text
105
```

**Output**
```text
Yes
```
