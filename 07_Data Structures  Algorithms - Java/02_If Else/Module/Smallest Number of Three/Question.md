# Smallest Number of Three

## Description

<p>Find the smallest number among three integers.</p>

## Input Format

<p>The input consists of three space-separated integers 'n', 'm', and 'l'.</p>

## Output Format

<p>Output the smallest number among the three.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10 25 5
```

**Output**
```text
5
```


### Sample Case 2

**Input**
```text
-3 0 -7
```

**Output**
```text
-7
```
