# Multiplication or Addition

## Description

<p>Check the given two integer inputs. If both numbers are even, find their product. Otherwise, find their sum.</p>

## Input Format

<p>The input consists of two lines. The first line contains the first integer, n. The second line contains the second integer, m.</p>

## Output Format

<p>Print the product of the two numbers if both numbers are even. Otherwise, print their sum.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
20
```

**Output**
```text
200
```


### Sample Case 2

**Input**
```text

15
```
