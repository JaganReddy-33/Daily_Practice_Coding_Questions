# Three Digit Number and Multiple of 2, 5, and 10

## Description

<p>Check if a given number is a three-digit number and also a multiple of 2, 5, and 10.</p>

## Input Format

<p>The input consists of a single integer 'n' on a single line.</p>

## Output Format

<p>Output 'Yes' if the number is a three-digit number and a multiple of 2, 5, and 10, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
140
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
145
```

**Output**
```text
No
```
