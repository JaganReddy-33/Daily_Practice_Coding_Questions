# Lowercase ASCII Value

## Description

<p>Check if a given number is the ASCII value of a lowercase alphabet.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output 'Yes' if the number is the ASCII value of a lowercase alphabet, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
100
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
108
```

**Output**
```text
Yes
```
