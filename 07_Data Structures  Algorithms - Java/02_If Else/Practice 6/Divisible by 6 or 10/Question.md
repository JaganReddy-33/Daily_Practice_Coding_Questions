# Divisible by 6 or 10

## Description

Check if a number is divisible by 6 or 10.

## Input Format

The first line contains a single integer num, representing the number to be checked.

## Output Format

Print 'Yes' if the number is divisible by either 6 or 10, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
12
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
20
```

**Output**
```text
Yes
```
