# Even Non-Divisible by 3

## Description

Determine if a two-digit number is even and not divisible by 3.

## Input Format

A single integer num (10 <= num <= 99) representing the two-digit number to be checked.

## Output Format

Print 'Yes' if the number is even and not divisible by 3, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
24
```

**Output**
```text
No
```


### Sample Case 2

**Input**
```text
36
```

**Output**
```text
No
```
