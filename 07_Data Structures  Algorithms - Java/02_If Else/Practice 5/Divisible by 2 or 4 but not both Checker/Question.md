# Divisible by 2 or 4 but not both Checker

## Description

Check if a given number is a multiple of 2 or 4 but not both.

## Input Format

A single integer num (-100000 <= num <= 100000) representing the number to be checked.

## Output Format

Print 'Yes' if the number is a multiple of 2 or 4 but not both, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
6
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
8
```

**Output**
```text
No
```
