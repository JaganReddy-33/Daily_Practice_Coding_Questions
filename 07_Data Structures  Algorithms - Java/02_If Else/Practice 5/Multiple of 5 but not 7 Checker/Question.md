# Multiple of 5 but not 7 Checker

## Description

Check if a given number is a multiple of 5 but not 7.

## Input Format

A single integer num (-1000 <= num <= 1000) representing the number to be checked.

## Output Format

Print 'Yes' if the number is a multiple of 5 but not 7, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
25
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
35
```

**Output**
```text
No
```
