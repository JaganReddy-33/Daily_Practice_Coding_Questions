# Divisible by 8 and 9 Checker

## Description

Check if a given three-digit number is divisible by both 8 and 9.

## Input Format

A single integer num (100 <= num <= 999) representing the three-digit number to be checked.

## Output Format

Print 'Yes' if the number is divisible by both 8 and 9, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
288
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
360
```

**Output**
```text
Yes
```
