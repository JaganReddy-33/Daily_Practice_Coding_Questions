# Divisible by 3 or 5 but not both Checker

## Description

<p>Check if a given number is a multiple of 3 or 5 but not both.</p>

## Input Format

<p>A single integer num (-1000 &lt;= num &lt;= 1000) representing the number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is a multiple of 3 or 5 but not both, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
9
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
10
```

**Output**
```text
Yes
```
