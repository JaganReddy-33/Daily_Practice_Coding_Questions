# Divisible by 3 or 5 but not both Checker

## Description

Check if a given number is a multiple of 3 or 5 but not both.

## Input Format

A single integer num (-1000 <= num <= 1000) representing the number to be checked.

## Output Format

Print 'Yes' if the number is a multiple of 3 or 5 but not both, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
9
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
10
```

**Output**
```text
Yes
```
