# Divisible by 2 and 3 Checker

## Description

Check if a given three-digit number is divisible by both 2 and 3.

## Input Format

A single integer num (100 <= num <= 999) representing the three-digit number to be checked.

## Output Format

Print 'Yes' if the number is divisible by both 2 and 3, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
126
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
333
```

**Output**
```text
No
```
