# Number Range Checker

## Description

Check if a given number is greater than 75 and less than 100.

## Input Format

A single integer num (-1000 <= num <= 1000) representing the number to be checked.

## Output Format

Print 'Yes' if the number is greater than 75 and less than 100, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
80
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
75
```

**Output**
```text
No
```
