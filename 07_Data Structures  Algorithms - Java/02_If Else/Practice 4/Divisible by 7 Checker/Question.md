# Divisible by 7 Checker

## Description

Determine if a given two-digit number is divisible by 7.

## Input Format

A single integer num (10 <= num <= 99) representing the two-digit number to be checked.

## Output Format

Print 'Yes' if the number is divisible by 7, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
14
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
21
```

**Output**
```text
Yes
```
