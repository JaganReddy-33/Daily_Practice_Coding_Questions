# Multiple of 7 or 11 Checker

## Description

<p>Determine if a given number is a multiple of 7 or 11.</p>

## Input Format

<p>A single integer num (-10^9 &lt;= num &lt;= 10^9) representing the number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is a multiple of 7 or 11, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
14
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
23
```

**Output**
```text
No
```
