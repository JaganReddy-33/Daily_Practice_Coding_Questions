# Multiple of 7 or 11 Checker

## Description

Determine if a given number is a multiple of 7 or 11.

## Input Format

A single integer num (-10^9 <= num <= 10^9) representing the number to be checked.

## Output Format

Print 'Yes' if the number is a multiple of 7 or 11, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
14
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
23
```

**Output**
```text
No
```
