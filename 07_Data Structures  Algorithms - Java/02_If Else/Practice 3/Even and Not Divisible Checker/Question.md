# Even and Not Divisible Checker

## Description

Check if a given number is even and not divisible by 5.

## Input Format

A single integer num (-10^18 <= num <= 10^18) representing the number to be checked.

## Output Format

Print 'Yes' if the number is even and not divisible by 5, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
12
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
200
```

**Output**
```text
No
```
