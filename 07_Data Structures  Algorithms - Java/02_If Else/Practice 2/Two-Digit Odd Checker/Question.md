# Two-Digit Odd Checker

## Description

Determine if a given two-digit number is odd.

## Input Format

A single integer num (10 <= num <= 99) representing the two-digit number to be checked.

## Output Format

Print 'Yes' if the number is odd, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
37
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
50
```

**Output**
```text
No
```
