# Two-Digit Even Checker

## Description

Determine if a given two-digit number is even.

## Input Format

A single integer num (10 <= num <= 99) representing the two-digit number to be checked.

## Output Format

Print 'Yes' if the number is even, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
37
```

**Output**
```text
No
```

### Sample Case 2

**Input**
```text
50
```

**Output**
```text
Yes
```
