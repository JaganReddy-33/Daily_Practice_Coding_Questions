# Two-Digit Even Checker

## Description

<p>Determine if a given two-digit number is even.</p>

## Input Format

<p>A single integer num (10 &lt;= num &lt;= 99) representing the two-digit number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is even, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
37
```

**Output**
```text
No
```


### Sample Case 2

**Input**
```text
50
```

**Output**
```text
Yes
```
