# University Admission Eligibility

## Description

<p>Check the eligibility of students for university admissions based on age and completion of high school.</p>

## Input Format

<p>The first line contains a single integer representing the age of the student. The second line contains a string 'Yes' or 'No', indicating whether the student has completed high school.</p>

## Output Format

<p>Print the eligibility status of the student as per the given conditions.</p><p><br></p><p>If the student's age is 18 or above and has completed high school, print 'Eligible to Apply'.</p><p>If the student is below 18, output 'Not Eligible to Apply'.</p><p>If the student is 18 or above but has not completed high school, prompt them to 'Complete High School'.</p>

**Input**
```text

Yes
```

**Output**
```text
Eligible to Apply
```


### Sample Case 2
