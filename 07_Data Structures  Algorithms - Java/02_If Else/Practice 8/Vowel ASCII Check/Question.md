# Vowel ASCII Check

## Description

<p>Check whether a given number is the ASCII code of a vowel or not.</p>

## Input Format

<p>The first line contains a single integer num, representing the ASCII code to be checked.</p>

## Output Format

<p>Print 'Yes' if the ASCII code corresponds to a vowel, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
65
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
69
```

**Output**
```text
Yes
```
