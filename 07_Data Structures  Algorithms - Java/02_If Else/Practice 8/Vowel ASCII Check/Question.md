# Vowel ASCII Check

## Description

Check whether a given number is the ASCII code of a vowel or not.

## Input Format

The first line contains a single integer num, representing the ASCII code to be checked.

## Output Format

Print 'Yes' if the ASCII code corresponds to a vowel, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
65
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
69
```

**Output**
```text
Yes
```
