# Factor and Odd Check

**Question ID:** `66067189f51c6d596b429daa`

## Description

Check whether a given number M is a factor of N and is also odd.

## Input Format

The first line contains two integers M and N separated by a space, where M represents the number to be checked as a factor and N represents the number to be checked for divisibility.

## Output Format

Print 'Yes' if M is a factor of N and M is odd, otherwise print 'No'.
