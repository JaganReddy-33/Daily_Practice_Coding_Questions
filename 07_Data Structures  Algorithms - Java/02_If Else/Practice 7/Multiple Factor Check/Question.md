# Multiple Factor Check

## Description

Check whether two given numbers, M and K, are factors of N.

## Input Format

The first line contains three integers M, K, and N separated by a space, where M and K represent the numbers to be checked as factors, and N represents the number to be checked for divisibility.

## Output Format

Print 'Yes' if both M and K are factors of N, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
3 4 12
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
5 6 18
```

**Output**
```text
No
```
