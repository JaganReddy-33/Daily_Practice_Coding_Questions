# Number Sign Checker

## Description

<p>Check whether a given number is positive, negative, or zero.</p>

## Input Format

<p>A single long num (-10^18 &lt;= num &lt;= 10^18) representing the number to be checked.</p>

## Output Format

<p>Print 'Positive' if the number is positive, 'Negative' if the number is negative, and 'Zero' if the number is zero.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
Positive
```


### Sample Case 2

**Input**
```text
-8
```

**Output**
```text
Negative
```
