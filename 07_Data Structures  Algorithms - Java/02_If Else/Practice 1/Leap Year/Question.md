# Leap Year

## Description

<p>Determine whether a given year is a leap year or not.</p><p>A year is a leap year if:</p><p>The year is multiple of 4 and not a multiple of 100</p><p>The year is a multiple of 400</p>

## Input Format

<p>A single integer year (1000 &lt;= year &lt;= 3000) representing the year to be checked.</p>

## Output Format

<p>Print 'Leap year' if the year is a leap year, otherwise print 'Not a leap year'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
2020
```

**Output**
```text
Leap year
```


### Sample Case 2

**Input**
```text
1900
```

**Output**
```text

```
