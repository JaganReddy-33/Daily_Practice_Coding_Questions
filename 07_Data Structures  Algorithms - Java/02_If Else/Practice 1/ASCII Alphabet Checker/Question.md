# ASCII Alphabet Checker

## Description

Determine if a given ASCII value represents an alphabet or not.

## Input Format

A single integer ascii_val (0 <= ascii_val <= 127) representing the ASCII value to be checked.

## Output Format

Print 'Alphabet' if the ASCII value represents an alphabet (either uppercase or lowercase), otherwise print 'Not an alphabet'.

## Sample Cases

### Sample Case 1

**Input**
```text
65
```

**Output**
```text
Alphabet
```

### Sample Case 2

**Input**
```text
48
```

**Output**
```text
Not an alphabet
```
