# Greater Than 100 Checker

## Description

Check if a given number is greater than 100.

## Input Format

A single integer num (-1000 <= num <= 1000) representing the number to be checked.

## Output Format

Print 'Greater than 100' if the number is greater than 100, otherwise print 'Not greater than 100'.

## Sample Cases

### Sample Case 1

**Input**
```text
105
```

**Output**
```text
Greater than 100
```

### Sample Case 2

**Input**
```text
99
```

**Output**
```text
Not greater than 100
```
