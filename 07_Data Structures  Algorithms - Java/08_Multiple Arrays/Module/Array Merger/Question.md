# Array Merger

## Description

<p>Given two sorted array of integers, merge these two arrays and print it as the output.</p>

## Input Format

<p>First line contains an integer n representing the size of the array The Second line consists of a single line containing space-separated integers. <span style="background-color: rgb(245, 245, 245);">Third line contains an integer n representing the size of the array The Fourth line consists of a single line containing space-separated integers.</span></p>

## Output Format

<p>Print the merged array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
1 2 3
4
4 5 6 7
```

**Output**
```text
Merged array: 1 2 3 4 5 6 7
```


### Sample Case 2

**Input**
```text
4
1 2 3 4
5

```

**Output**
```text

```
