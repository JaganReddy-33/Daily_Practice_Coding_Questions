# Longest Numeric Substring

**Question ID:** `663c6ec27adf49367628ee43`

## Description

Given a string, find the longest substring that consists of only numeric characters. If no such substring exists, print 'No numeric substring found'.

## Input Format

A single string containing alphanumeric characters.

## Output Format

Print the longest substring that consists of only numeric characters. If no such substring exists, print 'No numeric substring found'.
