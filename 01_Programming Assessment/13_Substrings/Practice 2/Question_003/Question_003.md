# Longest Consonant Substring

**Question ID:** `663c6eb67adf49367628eda1`

## Description

Given a string, find the longest substring that consists of only consonants. If no such substring exists, print 'No consonant substring found'.

## Input Format

A single string containing only lowercase alphabets.

## Output Format

Print the longest substring that consists of only consonants. If no such substring exists, print 'No consonant substring found'.

## Sample Cases

### Sample Case 1

**Input**
```text
abcd
```

**Output**
```text
bcd
```
