# String Concatenation with Length Adjustment

**Question ID:** `663c6f1ebc427c696edacba7`

## Description

Write a Java program that reads two strings, appends them together, and returns the result. If the strings are of different lengths, remove characters from the beginning of the longer string to make them equal lengths before concatenation.

## Input Format

The input consists of two strings, each on a separate line.

## Output Format

Print the concatenated string after adjusting the lengths of the input strings if necessary.

## Sample Cases

### Sample Case 1

**Input**
```text
hello
world
```

**Output**
```text
helloworld
```
