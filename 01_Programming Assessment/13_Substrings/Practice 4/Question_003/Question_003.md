# Extract Characters from First and Last Positions

**Question ID:** `663c6f2f7adf493676290e1f`

## Description

Create a new string by taking a specified number of characters from the first and last positions of a given string.

## Input Format

The input consists of two lines:
1. The original string.
2. An integer specifying the number of characters to extract from the first and last positions.

## Output Format

Print the new string created by extracting characters from the specified positions.

## Sample Cases

### Sample Case 1

**Input**
```text
programming
3
```

**Output**
```text
proing
```

### Sample Case 2

**Input**
```text

```

**Output**
