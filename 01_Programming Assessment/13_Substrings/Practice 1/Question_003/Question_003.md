# Numeric Substrings

**Question ID:** `663c6e707adf49367628e5be`

## Description

Print all substrings that consist of only numeric characters.

## Input Format

A single string containing alphanumeric characters.

## Output Format

Print all substrings that consist of only numeric characters, separated by a space. If no such substring exists, print "No numeric substrings".

## Sample Cases

### Sample Case 1

**Input**
```text
abc123def456ghi
```

**Output**
```text
1 2 3 4 5 6 12 23 45 56 123 456
```

### Sample Case 2

**Input**
```text
abcdef
```

**Output**
```text
No numeric substrings
```
