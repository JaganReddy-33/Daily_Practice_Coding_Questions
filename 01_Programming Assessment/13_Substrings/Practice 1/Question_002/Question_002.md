# Consonant Substrings

**Question ID:** `663c6e66bc427c696edaaae4`

## Description

Print all substrings that consist of only consonants.

## Input Format

A single string containing only lowercase alphabets.

## Output Format

Print all substrings that consist of only consonants, separated by a space. If no such substring exists, print "No consonant substrings".

## Sample Cases

**Input**
```text
aeiou
```

**Output**
```text
No consonant substrings
```
