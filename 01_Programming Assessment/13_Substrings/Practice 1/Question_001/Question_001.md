# Vowel Substrings

**Question ID:** `663c6e5abc427c696edaa67a`

## Description

## Input Format

A single string containing only lowercase alphabets.

## Output Format

Print all substrings that consist of only vowels, separated by a space. If no such substring exists, print "No vowel substrings".
