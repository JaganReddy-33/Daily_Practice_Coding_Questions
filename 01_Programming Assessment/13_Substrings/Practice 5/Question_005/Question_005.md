# Count of Substrings with Same Characters

**Question ID:** `663c6f87bc427c696edae42e`

## Description

Count the number of substrings of length K in a given string that consist of the same characters.

## Input Format

The input consists of two lines:
1. The original string.
2. An integer K, representing the length of substrings to consider.

## Output Format

Print the count of substrings of length K consisting of the same characters.

## Sample Cases

### Sample Case 1

**Input**
```text
aabbaabbaabbaabb
2
```

**Output**
```text
8
```
