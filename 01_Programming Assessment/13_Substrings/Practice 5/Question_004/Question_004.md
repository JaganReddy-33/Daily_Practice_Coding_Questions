# Longest Substring with K Unique Characters

**Question ID:** `663c6f7d7adf4936762916a5`

## Description

Find the length of the longest substring in a given string that contains exactly k unique characters.

## Input Format

The input consists of two lines:
1. The original string.
2. An integer k.

## Output Format

Print the length of the longest substring with exactly k unique characters.

## Sample Cases

### Sample Case 1

**Input**
```text
aabacbebebe
3
```

**Output**
```text
7
```
