# Replace Substrings

**Question ID:** `663c6f737adf4936762915bc`

## Description

Modify a given string by replacing all occurrences of a substring S1 with another string S2.

## Input Format

The input consists of three lines:
1. The original string S.
2. The substring S1 to be replaced.
3. The replacement string S2.

## Output Format

Print the modified string after replacing all occurrences of S1 with S2.

## Sample Cases

### Sample Case 1

**Input**
```text
hello world hello
hello
hi
```

**Output**
```text
hi world hi
```
