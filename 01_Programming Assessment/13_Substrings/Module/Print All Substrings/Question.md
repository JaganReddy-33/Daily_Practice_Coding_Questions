# Print All Substrings

## Description

Print all possible substrings of a given string.

## Input Format

The input consists of a single line containing a string, `str`.

## Output Format

Multiple lines, each containing a substring of the input string.

## Sample Cases

### Sample Case 1

**Input**
```text
abc
```

**Output**
```text
a
b
c
ab
bc
abc
```

### Sample Case 2

**Input**
```text
tap
```

**Output**
```text
t
a
p
ta
ap
tap
```
