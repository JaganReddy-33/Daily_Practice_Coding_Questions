# Substring Frequency

## Description

<p>Given a string and a substring, find the frequency of the substring in the string.</p>

## Input Format

<p>The input consists of two lines:</p><p>First line containing a string, S.</p><p>Second line containing a substring, SS.</p>

## Output Format

<p>Print the frequency of the substring in the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TimadmgfdiTimsvsTim
Tim
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
HelloWorldHello

```

**Output**
