# Substrings Greater Than K

**Question ID:** `663c70357adf493676292b31`

## Description

Print all substrings of a given string whose size is greater than k.

## Input Format

The input consists of two lines:
- The first line contains a string S.
- The second line contains an integer k.

## Output Format

Print all substrings of S whose size is greater than k, separated by newline.

