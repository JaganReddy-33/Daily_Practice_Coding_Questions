# String Rotation Check

**Question ID:** `663c6f0cbc427c696edacb79`

## Description

Determine whether two given strings are rotations of each other or not. Two strings are considered rotations of each other if they can be obtained by rotating the characters of one string any number of times.

## Input Format

The input consists of two strings, each on a separate line.

## Output Format

Print 'YES' if the two strings are rotations of each other, otherwise print 'NO'.

## Sample Cases

### Sample Case 1

**Input**
```text
abcd
cdab
```

**Output**
```text
YES
```

### Sample Case 2

**Input**
```text
hello
world
```

**Output**
```text
NO
```
