# Maximum Length Palindromic Substring with Given Characters

**Question ID:** `663c6f937adf493676291ab2`

## Description

Find the maximum length of a palindromic substring in a given string such that it starts and ends with the given characters.

## Input Format

The input consists of two lines:

1. The original string.

2. A single character, representing the given character to start and end the palindromic substring.

## Output Format

Print the maximum length of the palindromic substring that starts and ends with the given character. If no such substring exists, print 0.

## Sample Cases

### Sample Case 1

**Input**
```text
abcbab
a
```

**Output**
```text
5
```

### Sample Case 2

**Input**
```text
racecar
r
```

**Output**
```text
7
```
