# Pairs Even First

**Question ID:** `6621ff94ae2286cdf8e4657e`

## Description

Given an array of integers with a size of N, print all the pairs whose first value is even.

## Input Format

The input consists of:
- The first line contains an integer N, the size of the array.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all the pairs whose first value is even, each pair in a separate line.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 -3 4 -5
```

**Output**
```text
2 -3
2 4
2 -5
4 -5
```
