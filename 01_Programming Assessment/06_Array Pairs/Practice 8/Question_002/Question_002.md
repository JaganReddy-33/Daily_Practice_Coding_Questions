# Even Second Pairs

**Question ID:** `6621ffa2ae2286cdf8e46f36`

## Description

Given an array of integers, print all pairs whose second value is even.

## Input Format

The input consists of:

- The first line contains an integer N, the size of the array.

- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all the pairs whose second value is even, each pair in a separate line.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 -3 4 -5
```

**Output**
```text
1 2
1 4
2 4
-3 4
```
