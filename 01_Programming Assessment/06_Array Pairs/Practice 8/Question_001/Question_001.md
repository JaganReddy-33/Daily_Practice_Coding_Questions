# Odd First Pairs

**Question ID:** `6621ffacae2286cdf8e47e8f`

## Description

Given an array of integers, print all pairs whose first value is odd.

## Input Format

The input consists of:
- The first line contains an integer N, the size of the array.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all pairs whose first value is odd, each pair in a separate line. If no pairs are found, print “None”.

## Sample Cases

**Input**
```text
5
1 2 -3 4 -5
```

**Output**

-3 1

-3 4
-3 -5
