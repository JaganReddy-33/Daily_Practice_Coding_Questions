# Negative First Value Pairs

**Question ID:** `6621ff63c74ee9cf9f4195ff`

## Description

Given an array of integers with a size of N, print all the pairs whose first value is negative.

## Input Format

The input consists of:
- The first line contains an integer N, the size of the array.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all the pairs whose first value is negative, each pair in a separate line.
