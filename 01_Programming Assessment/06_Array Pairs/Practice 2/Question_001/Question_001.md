# Positive-Negative Pairs

**Question ID:** `66220179ae2286cdf8e51942`

## Description

Given an array of integers with a size of N, find and print all the pairs having positive and negative values of a number that exists in the array.

## Input Format

The input consists of: - The first line contains an integer N, the size of the array. - The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all the pairs having positive and negative values of a number that exists in the array, each pair in a separate line. If there are no such pairs, print "No pairs found".

## Sample Cases

### Sample Case 1

**Input**
```text
6
2 -3 4 -5 6 -4
```

**Output**
```text
4 -4
```
