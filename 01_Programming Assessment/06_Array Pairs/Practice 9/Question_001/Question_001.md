# Pairs Prime Sum

**Question ID:** `6621ff0eae2286cdf8e449c5`

## Description

Given an array of integers with a size of N, print all the pairs whose sum is a prime number.

## Input Format

The input consists of: - The first line contains an integer N, the size of the array. - The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all the pairs whose sum is a prime number, each pair in a separate line. If no pairs are found, print “None”.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 2
1 4
2 3
2 5
3 4
```
