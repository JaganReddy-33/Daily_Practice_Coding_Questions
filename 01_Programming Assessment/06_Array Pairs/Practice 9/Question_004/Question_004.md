# Pairs Second Greater K

**Question ID:** `6621fee1c74ee9cf9f418128`

## Description

Given an array of integers with a size of N, print all the pairs whose second value is greater than K.

## Input Format

The input consists of: - The first line contains an integer N, the size of the array. - The second line contains N space-separated integers, representing the elements of the array. - The third line contains an integer K.

## Output Format

Print all the pairs whose second value is greater than K, each pair in a separate line. If no such pairs print 'None'

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
2
```

**Output**
```text
1 3
1 4
1 5
2 3
2 4
2 5
3 4
3 5
4 5
```
