# Pairs Prime First

**Question ID:** `6621fef0ae2286cdf8e43ca1`

## Description

Given an array of integers with a size of N, print all the pairs whose first value is a prime number.

## Input Format

The input consists of: - The first line contains an integer N, the size of the array. - The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all the pairs whose first value is a prime number, each pair in a separate line. If no pairs are found, print “None”.
