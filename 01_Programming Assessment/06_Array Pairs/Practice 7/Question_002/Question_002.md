# Pairs with Difference K

**Question ID:** `66220017c74ee9cf9f41cf9f`

## Description

Given an array of integers and an integer K, print all pairs whose difference is equal to K.

## Input Format

The input consists of:
- The first line contains two integers separated by a space: N (the size of the array) and K.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all pairs whose difference is equal to K, each pair in a separate line. If there are no such pairs, print "No pairs found".

## Sample Cases

### Sample Case 1

**Input**
```text
5 3
1 5 3 4 2
```

**Output**
```text
1 4
5 2
```
