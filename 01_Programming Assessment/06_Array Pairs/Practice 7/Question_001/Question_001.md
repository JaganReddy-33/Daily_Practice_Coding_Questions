# Product of Pairs

**Question ID:** `6622002ac74ee9cf9f41d3be`

## Description

Given an array of integers, print the product of each pair of values present in the array.

## Input Format

The input consists of:
- The first line contains an integer N, the size of the array.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print the product of all pairs of values present in the array, each product in a separate line.

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 2 3 4
```

**Output**
```text
2
3
4
6
8
12
```
