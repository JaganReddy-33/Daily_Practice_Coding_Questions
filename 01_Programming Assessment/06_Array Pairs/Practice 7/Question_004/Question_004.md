# Odd Pair Count

**Question ID:** `6621ffd5c74ee9cf9f41ca4a`

## Description

Given an array of integers, determine if there are an odd number of pairs in the array.

## Input Format

The input consists of: - The first line contains an integer N, the size of the array. - The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print "odd" if there are an odd number of pairs in the array, otherwise print "even".
