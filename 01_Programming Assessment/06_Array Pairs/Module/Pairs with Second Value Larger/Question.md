# Pairs with Second Value Larger

## Description

<p>Print all pairs of numbers from a given array where the second value is strictly larger than the first value.</p>

## Input Format

<p>The input consists of a single line containing space-separated integers.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
4 9 2 7 5
```

**Output**
```text
4 9
4 7
4 5
2 7
2 5
```


### Sample Case 2

**Input**
```text
3
1 2 3
```

**Output**
```text
1 2
1 3
2 3
```
