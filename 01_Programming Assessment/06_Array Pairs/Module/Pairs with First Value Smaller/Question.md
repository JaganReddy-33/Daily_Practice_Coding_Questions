# Pairs with First Value Smaller

## Description

<p>Print all pairs of numbers from a given array where the first value is strictly smaller than the second value.</p>

## Input Format

<p>The input consists of a single line containing the length of the array, followed by a second line containing space-separated integers.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
3 1 5 4 2
```

**Output**
```text
3 5
3 4
1 5
1 4
1 2
```


### Sample Case 2

**Input**
```text
3
1 2 3
```

**Output**
```text
1 2
1 3
2 3
```
