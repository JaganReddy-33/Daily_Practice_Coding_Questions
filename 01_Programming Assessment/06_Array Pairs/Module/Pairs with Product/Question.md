# Pairs with Product

## Description

<p>Find pairs of numbers from the array whose product is equal to a given target value.</p>

## Input Format

<p>The first line contains an integer N, representing the size of the array. </p><p>The second line contains N space-separated integers, representing the elements of the array. </p><p>The third line contains a single integer k, representing the desired product value.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
2 4 6 3 8 9
12
```

**Output**
```text
2 6
4 3
```


### Sample Case 2

**Input**
```text
4
2 1 4 3
12
```

**Output**
```text
4 3
```
