# Pairs with Sum Less than k

## Description

<p>Print all pairs of numbers from the input array whose sum is less than the target value k.</p>

## Input Format

<p>The first line contains an integer N, representing the size of the array.</p><p>The second line contains N space-separated integers, representing the elements of the array.</p><p>The third line contains a single integer k, representing the target value.</p>

## Output Format

<p>Print each pair of numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
2 4 6 3 8 9
10
```

**Output**
```text
2 4
2 6
2 3
4 3
6 3
```


### Sample Case 2

**Input**
```text
5
1 2 3 4 5
7
```

**Output**
```text

1 3
1 4
1 5
2 3
2 4
```
