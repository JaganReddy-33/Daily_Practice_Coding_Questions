# Odd Pairs

## Description

<p>Find pairs of odd numbers from the given array. Both the number in a pair should be odd numbers.</p>

## Input Format

<p>The first line contains an integer N, representing the size of the array.</p><p>The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print each pair of odd numbers on a new line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
2 4 6 3 8 9
```

**Output**
```text
3 9
```


### Sample Case 2

**Input**
```text
4
1 2 3 4
```

**Output**
```text
1 3
```
