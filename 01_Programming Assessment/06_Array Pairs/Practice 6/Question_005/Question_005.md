# Pairs with Product K

**Question ID:** `66220038ae2286cdf8e4a8da`

## Description

Given an array of integers and an integer K, print all pairs whose product is equal to K.

## Input Format

The input consists of:
- The first line contains two integers separated by a space: N (the size of the array) and K.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all pairs whose product is equal to K, each pair in a separate line. If there are no such pairs, print "No pairs found".

## Sample Cases

### Sample Case 1

**Input**
```text
5 8
1 2 3 4 5
```

**Output**
```text
2 4
```
