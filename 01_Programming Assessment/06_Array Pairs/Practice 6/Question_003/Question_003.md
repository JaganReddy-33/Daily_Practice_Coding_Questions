# Pairs with Product > K

**Question ID:** `6622004fc74ee9cf9f41e1c0`

## Description

Given an array of integers and an integer K, print all pairs whose product is greater than K.

## Input Format

The input consists of:
- The first line contains two integers separated by a space: N (the size of the array) and K.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all pairs whose product is greater than K, each pair in a separate line. If there are no such pairs, print "No pairs found".

## Sample Cases

### Sample Case 1

**Input**
```text
5 8
1 2 3 4 5
```

**Output**
```text
2 5
3 4
3 5
4 5
```
