# Pairs with Even Product

**Question ID:** `6622005eae2286cdf8e4b3b2`

## Description

Given an array of integers, print all pairs whose product is even.

## Input Format

The input consists of:
- The first line contains an integer N, the size of the array.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all pairs whose product is even, each pair in a separate line. If there are no such pairs, print "No pairs found".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 2
1 4
2 3
2 4
2 5
3 4
4 5
```
