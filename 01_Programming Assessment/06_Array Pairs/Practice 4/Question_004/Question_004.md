# Pairs with Sum as Factor

**Question ID:** `662200c6ae2286cdf8e4cee4`

## Description

Given an array of integers with a size of N, print all the pairs whose sum is a factor of K.

## Input Format

The input consists of:
- The first line contains an integer N, the size of the array.
- The second line contains N space-separated integers, representing the elements of the array.
- The third line contains an integer K.

## Output Format

Print all the pairs whose sum is a factor of K, each pair in a separate line. If there are no such pairs, print "No pairs found".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
10
```

**Output**
```text
1 4
2 3
```
