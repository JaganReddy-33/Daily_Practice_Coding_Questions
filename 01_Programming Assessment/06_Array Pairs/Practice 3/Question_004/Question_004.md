# Pairs with Second Value as Factor

**Question ID:** `662200fbae2286cdf8e4e217`

## Description

Given an array of integers with a size of N, print all the pairs whose second value is a factor of the first value.

## Input Format

The input consists of:
- The first line contains an integer N, the size of the array.
- The second line contains N space-separated integers, representing the elements of the array.

## Output Format

Print all the pairs whose second value is a factor of the first value, each pair in a separate line. If there are no such pairs, print "No pairs found".

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 4 5 6
```

**Output**
```text
No pairs found
```
