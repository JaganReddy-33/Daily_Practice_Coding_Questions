# Divisible by 7 Checker

## Description

<p>Determine if a given two-digit number is divisible by 7.</p>

## Input Format

<p>A single integer num (10 &lt;= num &lt;= 99) representing the two-digit number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is divisible by 7, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
14
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
21
```

**Output**
```text
Yes
```
