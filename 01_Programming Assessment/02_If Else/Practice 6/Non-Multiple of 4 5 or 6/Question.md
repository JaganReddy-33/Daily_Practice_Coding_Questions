# Non-Multiple of 4, 5, or 6

## Description

Determine if a number is not a multiple of 4, 5, or 6.

## Input Format

A single integer num (-100000 <= num <= 100000) representing the number to be checked.

## Output Format

Print 'Yes' if the number is not a multiple of 4, 5, or 6, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
11
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
20
```

**Output**
```text
No
```
