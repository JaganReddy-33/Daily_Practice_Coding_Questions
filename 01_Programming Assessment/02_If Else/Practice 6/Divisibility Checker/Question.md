# Divisibility Checker

## Description

<p>Check if a given number is not divisible by 2, 3, or 7.</p>

## Input Format

<p>A single integer num (-1000 &lt;= num &lt;= 1000) representing the number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is not divisible by 2, 3, or 7, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
11
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
18
```

**Output**
```text
No
```
