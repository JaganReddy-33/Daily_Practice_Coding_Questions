# Divisibility Checker

## Description

Check if a given number is not divisible by 2, 3, or 7.

## Input Format

A single integer num (-1000 <= num <= 1000) representing the number to be checked.

## Output Format

Print 'Yes' if the number is not divisible by 2, 3, or 7, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
11
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
18
```

**Output**
```text
No
```
