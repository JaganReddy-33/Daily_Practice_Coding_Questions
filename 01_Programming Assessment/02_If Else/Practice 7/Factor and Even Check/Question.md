# Factor and Even Check

## Description

Check whether a given number M is a factor of N and is also even.

## Input Format

The first line contains two integers M and N separated by a space, where M represents the number to be checked as a factor and N represents the number to be checked for divisibility.

## Output Format

Print 'Yes' if M is a factor of N and M is even, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
3 12
```

**Output**
```text
No
```

### Sample Case 2

**Input**
```text
5 18
```

**Output**
```text
No
```
