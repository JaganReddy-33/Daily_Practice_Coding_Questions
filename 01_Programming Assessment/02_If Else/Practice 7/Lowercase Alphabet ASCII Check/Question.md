# Lowercase Alphabet ASCII Check

## Description

Check whether a given number is the ASCII code of a lowercase alphabet or not.

## Input Format

A single integer num (0 <= num <= 127) representing the ASCII code to be checked.

## Output Format

Print 'Yes' if the ASCII code corresponds to a lowercase alphabet, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
97
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
65
```

**Output**
```text
No
```
