# Multiple of 2 and 8 Checker

## Description

<p>Determine if a given number is a multiple of both 2 and 8.</p>

## Input Format

<p>A single integer num (-1000 &lt;= num &lt;= 1000) representing the number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is a multiple of both 2 and 8, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
16
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
24
```

**Output**
```text
Yes
```
