# Multiple of 5 but not 7 Checker

## Description

<p>Check if a given number is a multiple of 5 but not 7.</p>

## Input Format

<p>A single integer num (-1000 &lt;= num &lt;= 1000) representing the number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is a multiple of 5 but not 7, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
25
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
35
```

**Output**
```text
No
```
