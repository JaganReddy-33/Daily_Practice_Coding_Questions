# Even or Odd

## Description

Check if a given number is even number or odd number

## Input Format

First line contains single integer n

## Output Format

Print Yes if it is even number, else No

## Sample Cases

### Sample Case 1

**Input**
```text
12
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
15
```

**Output**
```text
No
```
