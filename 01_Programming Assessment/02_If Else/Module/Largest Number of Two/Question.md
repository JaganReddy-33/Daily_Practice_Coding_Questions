# Largest Number of Two

## Description

<p>Write a Java program to find the largest number among two given integers.</p>

## Input Format

<p>The first line contains the first integer n. The second line contains the second integer m.</p>

## Output Format

<p>Print the largest number among the two input numbers.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
30
```

**Output**
```text
30
```


### Sample Case 2

**Input**
```text
5
5
```

**Output**
```text
5
```
