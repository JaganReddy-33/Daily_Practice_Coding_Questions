# Multiple of 10

## Description

<p>Determine whether the given number is a multiple of 10 or not.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output 'Yes' if the number is a multiple of 10, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
50
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
30
```

**Output**
```text
Yes
```
