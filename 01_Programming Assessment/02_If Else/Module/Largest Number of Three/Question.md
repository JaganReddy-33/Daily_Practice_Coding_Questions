# Largest Number of Three

## Description

<p>Find the largest number among three integers.</p>

## Input Format

<p>The input consists of three space-separated integers 'n', 'm', and 'l'.</p>

## Output Format

<p>Output the largest number among the three.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10 25 5
```

**Output**
```text
25
```


### Sample Case 2

**Input**
```text
-3 0 -7
```

**Output**
```text
0
```
