# Smallest Number of Two

## Description

<p>Write a Java program to find the smallest number among two given integers.</p>

## Input Format

<p>The first line contains the first integer n. The second line contains the second integer m.</p>

## Output Format

<p>Print the smallest number among the two input numbers.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
30
```

**Output**
```text
10
```


### Sample Case 2

**Input**
```text
5
5
```

**Output**
```text
5
```


### Sample Case 3

```text
12c6f3f6b9:e0bd579e6b5ed989bfee0b4df11f791e:7d0aa60febba19d46dff5d999af28051
```

```text
db8f:4cb2733a88f325b73a03cc1ec426ab7c:1e980d830643fccc6733c21ced7eb640
```
