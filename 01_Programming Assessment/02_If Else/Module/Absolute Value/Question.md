# Absolute Value

## Description

<p>Write a program to find the absolute value of a given integer.</p>

## Input Format

<p>The input consists of a single integer, n.</p>

## Output Format

<p>Print the absolute value of the integer.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
-5
```

**Output**
```text
5
```


### Sample Case 2

**Input**
```text
12
```

**Output**
```text
12
```
