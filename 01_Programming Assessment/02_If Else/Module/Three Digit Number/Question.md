# Three Digit Number

## Description

Check whether the given number is a three-digit number or not.

## Input Format

The input consists of a single integer 'n'.

## Output Format

Output 'Yes' if the number is a three-digit number, otherwise output 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
145
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
1000
```

**Output**
```text
No
```
