# Number Ends with Zero

## Description

<p>Check if a given number ends with zero or not.</p>

## Input Format

<p>The input consists of a single integer 'n' on a single line.</p>

## Output Format

<p>Output 'Yes' if the number ends with zero, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
140
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
145
```

**Output**
```text
No
```
