# Equivalent ASCII Character

## Description

Print the equivalent ASCII character of a given number.

## Input Format

The input consists of a single integer 'n'.

## Output Format

Output the equivalent ASCII character.

## Sample Cases

### Sample Case 1

**Input**
```text
98
```

**Output**
```text
b
```

### Sample Case 2

**Input**
```text
72
```

**Output**
```text
H
```
