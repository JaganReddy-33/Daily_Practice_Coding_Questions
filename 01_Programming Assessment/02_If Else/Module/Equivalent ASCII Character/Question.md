# Equivalent ASCII Character

## Description

<p>Print the equivalent ASCII character of a given number.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output the equivalent ASCII character.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
98
```

**Output**
```text
b
```


### Sample Case 2

**Input**
```text
72
```

**Output**
```text
H
```


### Sample Case 3

**Input**
```text
71a2:28a097a08a29da9c0de893c58b6f6b76:5233c198e7ede24cbc533e26eb8d9661
```

```text
2d:ce0828974599efcaa92b8f8328728bcc:59aac3bbee1cccd50c0344c8caa77718
```
