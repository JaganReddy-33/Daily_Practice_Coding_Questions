# Two Digit Number

## Description

<p>Check whether the given number is a two-digit number or not.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output 'Yes' if the number is a two-digit number, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
14
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
30
```

**Output**
```text
Yes
```
