# Multiple of 5

## Description

<p>Determine whether the given number is a multiple of 5 or not.</p>

## Input Format

<p>The input consists of a single integer 'n'.</p>

## Output Format

<p>Output 'Yes' if the number is a multiple of 5, otherwise output 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
24
```

**Output**
```text
No
```


### Sample Case 2

**Input**
```text
30
```

**Output**
```text
Yes
```
