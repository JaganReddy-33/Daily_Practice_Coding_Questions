# Positive or Negative Number

## Description

<p>Check if a given number is greater than 0, if yes then print 'Positive'. If the given number is lesser than 0, then print 'Negative'. If the given number is exactly equal to 0, then print 'Zero'.</p>

## Input Format

<p>The input consists of a single integer, n.</p>

## Output Format

<p>Print 'Positive' if n &gt; 0. Print 'Negative' if n &lt; 0. Print 'Zero' if n = 0.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
30
```

**Output**
```text
Positive
```


### Sample Case 2

**Input**
```text
-25
```

**Output**
```text
Negative
```
