# ASCII Value of Character

## Description

Print the ASCII value of a character.

## Input Format

The input consists of a single character 'c' on a single line.

## Output Format

Output the ASCII value of the character as an integer.

## Sample Cases

### Sample Case 1

**Input**
```text
A
```

**Output**
```text
65
```

### Sample Case 2

**Input**
```text
a
```

**Output**
```text
97
```
