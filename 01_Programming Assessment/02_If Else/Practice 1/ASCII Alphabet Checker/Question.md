# ASCII Alphabet Checker

## Description

<p>Determine if a given ASCII value represents an alphabet or not.</p>

## Input Format

<p>A single integer ascii_val (0 &lt;= ascii_val &lt;= 127) representing the ASCII value to be checked.</p>

## Output Format

<p>Print 'Alphabet' if the ASCII value represents an alphabet (either uppercase or lowercase), otherwise print 'Not an alphabet'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
65
```

**Output**
```text
Alphabet
```


### Sample Case 2

**Input**
```text
48
```

**Output**
```text
Not an alphabet
```
