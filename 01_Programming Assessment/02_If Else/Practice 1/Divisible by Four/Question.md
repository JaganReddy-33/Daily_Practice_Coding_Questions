# Divisible by Four

## Description

Check if a given number is divisible by 4.

## Input Format

The first line contains a single integer n, representing the number to be checked.

## Output Format

Print "Yes" if the number is divisible by 4, otherwise print "No".

## Sample Cases

### Sample Case 1

**Input**
```text
8
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
15
```

**Output**
```text
No
```
