# University Admission Eligibility

## Description

Check the eligibility of students for university admissions based on age and completion of high school.

## Input Format

The first line contains a single integer representing the age of the student. The second line contains a string 'Yes' or 'No', indicating whether the student has completed high school.

## Output Format

Print the eligibility status of the student as per the given conditions.

If the student's age is 18 or above and has completed high school, print 'Eligible to Apply'.

If the student is below 18, output 'Not Eligible to Apply'.

If the student is 18 or above but has not completed high school, prompt them to 'Complete High School'.

## Sample Cases

### Sample Case 1

**Input**
```text
20
Yes
```

**Output**
```text
Eligible to Apply
```

### Sample Case 2

**Input**
```text
17
Yes
```

**Output**
```text
Not Eligible to Apply
```
