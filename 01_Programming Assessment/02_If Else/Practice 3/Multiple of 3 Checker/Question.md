# Multiple of 3 Checker

## Description

Determine if a given number is a multiple of 3 but not 6.

## Input Format

A single integer num (-1000 <= num <= 1000) representing the number to be checked.

## Output Format

Print 'Yes' if the number is a multiple of 3 but not 6, otherwise print 'No'.

## Sample Cases

### Sample Case 1

**Input**
```text
9
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
12
```

**Output**
```text
No
```
