# Multiple of 3 Checker

## Description

<p>Determine if a given number is a multiple of 3 but not 6.</p>

## Input Format

<p>A single integer num (-1000 &lt;= num &lt;= 1000) representing the number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is a multiple of 3 but not 6, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
9
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
12
```

**Output**
```text
No
```
