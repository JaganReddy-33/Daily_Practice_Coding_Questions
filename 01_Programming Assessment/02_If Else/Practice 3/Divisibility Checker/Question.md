# Divisibility Checker

## Description

<p>Check if a given three-digit number is divisible by both 4 and 5.</p>

## Input Format

<p>A single integer num (100 &lt;= num &lt;= 999) representing the three-digit number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is divisible by both 4 and 5, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
120
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
225
```

**Output**
```text
No
```
