# Odd and Multiple of 7 Checker

## Description

<p>Check if a given three-digit number is odd and a multiple of 7.</p>

## Input Format

<p>A single integer num (100 &lt;= num &lt;= 999) representing the three-digit number to be checked.</p>

## Output Format

<p>Print 'Yes' if the number is odd and a multiple of 7, otherwise print 'No'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
357
```

**Output**
```text
Yes
```


### Sample Case 2

**Input**
```text
420
```

**Output**
```text
No
```
