# Multiples of 5

## Description

Write a program to print first N multiples of 5.

## Input Format

First line consists of a positive integer n

## Output Format

Print the required space separated number series

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
5 10 15 20 25
```


### Sample Case 2

**Input**
```text
3
```

**Output**
```text
5 10 15
```
