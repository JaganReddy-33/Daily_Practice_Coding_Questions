# Lowest Common Factor

## Description

<p>Write a program to find the lowest common factor of given 2 integers.</p>

## Input Format

<p>First line contains space separated two integer input n, m.</p>

## Output Format

<p>Print lowest common factor of 2 numbers.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10 20
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
15 30
```

**Output**
```text
1
```
