# Multiples of 3

## Description

<p>Write a program to print first N multiples of 3.</p>

## Input Format

<p>First line consists of a positive integer n</p>

## Output Format

<p>Print the required space separated number series</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
```

**Output**
```text
3 6 9 12 15 18 21
```


### Sample Case 2

**Input**
```text
3
```

**Output**
```text
3 6 9
```
