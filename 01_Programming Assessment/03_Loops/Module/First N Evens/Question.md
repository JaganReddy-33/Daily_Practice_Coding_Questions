# First N Evens

## Description

Write a program to print the first N even natural numbers.

## Input Format

First line consists of a positive integer n

## Output Format

Print the number from 1 to n space separated even integer.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
2 4 6 8 10
```


### Sample Case 2

**Input**
```text
3
```

**Output**
```text
2 4 6
```
