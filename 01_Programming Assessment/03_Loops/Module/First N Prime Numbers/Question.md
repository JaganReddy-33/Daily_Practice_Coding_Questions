# First N Prime Numbers

## Description

<p>Print the first 'n' prime numbers.</p>

## Input Format

<p>The input is provided as a single integer 'n'.</p>

## Output Format

<p>The function should print the first 'n' prime numbers on a single line, each number separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
1
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
8
```

**Output**
```text

```
