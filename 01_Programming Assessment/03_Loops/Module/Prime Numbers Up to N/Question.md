# Prime Numbers Up to N

## Description

<p>Print all prime numbers from 2 up to and including 'n'.</p>

## Input Format

<p>The input is provided as a single integer 'n'.</p>

## Output Format

<p>The function should print the prime numbers on a single line, each number separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
2
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
15
```

**Output**
```text

```
