# Prime Check

## Description

<p>Write a program to find whether the given number is a prime number or not.</p>

## Input Format

<p>First line consists of a positive integer n</p>

## Output Format

<p>Print Yes if the number is prime, else print No</p>

## Sample Cases

### Sample Case 1

**Input**
```text
4b29:833949565e2b3af04a1e91aa60eea61f:506e8d0fa9df131432c9a2ebcbd0551f
```

**Output**
```text
09f9c7:b902a6962e2e426f2cab9734c571e403:fe588b021b0fb089fd5d8c4006b4f2b4
```
