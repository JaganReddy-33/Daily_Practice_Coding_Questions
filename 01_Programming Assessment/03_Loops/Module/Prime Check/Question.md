# Prime Check

## Description

Write a program to find whether the given number is a prime number or not.

## Input Format

First line consists of a positive integer n

## Output Format

Print Yes if the number is prime, else print No

## Sample Cases

### Sample Case 1

**Input**
```text
11
```

**Output**
```text
Yes
```

### Sample Case 2

**Input**
```text
15
```

**Output**
```text
No
```
