# Factors

## Description

<p>Write a program to find factors of a given number.</p>

## Input Format

<p>First line consists of a positive integer n</p>

## Output Format

<p>Print the space separated integer factors of given number.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
20
```

**Output**
```text
1 2 4 5 10 20
```


### Sample Case 2

**Input**
```text
15
```

**Output**
```text
1 3 5 15
```


### Sample Case 3

**Input**
```text
1
```

**Output**
```text
1
```


### Sample Case 4

**Input**
```text
10
```

**Output**
```text
1 2 5 10
```


### Sample Case 5



### Sample Case 6
