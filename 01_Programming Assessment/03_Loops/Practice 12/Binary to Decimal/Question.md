# Binary to Decimal

## Description

<p>Given a binary number N, convert it to its decimal representation.</p>

## Input Format

<p>A string N representing the binary number.</p>

## Output Format

<p>Print the decimal representation of the binary number.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
1010
```

**Output**
```text
10
```


### Sample Case 2

**Input**
```text
1101
```

**Output**
```text
13
```
