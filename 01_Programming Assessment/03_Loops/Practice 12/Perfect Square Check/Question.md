# Perfect Square Check

## Description

Given a positive integer N, print whether the number is a perfect square or not.

## Input Format

An integer N (1 <= N <= 10^9) representing the input number.

## Output Format

Print 'Perfect Square' if N is a perfect square, and 'Not Perfect Square' otherwise.

## Sample Cases

### Sample Case 1

**Input**
```text
25
```

**Output**
```text
Perfect Square
```

### Sample Case 2

**Input**
```text
30
```

**Output**
```text
Not Perfect Square
```
