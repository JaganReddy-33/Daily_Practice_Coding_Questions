# Perfect Square Check

## Description

<p>Given a positive integer N, print whether the number is a perfect square or not.</p>

## Input Format

<p>An integer N (1 &lt;= N &lt;= 10^9) representing the input number.</p>

## Output Format

<p>Print 'Perfect Square' if N is a perfect square, and 'Not Perfect Square' otherwise.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
25
```

**Output**
```text
Perfect Square
```


### Sample Case 2

**Input**
```text
30
```

**Output**
```text
Not Perfect Square
```
