# Decimal to Binary

## Description

<p>Given a positive integer N, convert it into its binary representation.</p>

## Input Format

<p>An integer N (0 &lt;= N &lt;= 10^9) representing the decimal number.</p>

## Output Format

<p>Print the binary representation of N.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
101
```


### Sample Case 2

**Input**
```text
10
```

**Output**
```text
1010
```


### Sample Case 3

**Input**
