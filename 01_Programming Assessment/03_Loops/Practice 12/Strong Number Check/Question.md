# Strong Number Check

## Description

Given a positive integer N, print whether the number is a strong number or not. A strong number is a number in which the sum of the factorial of its digits is equal to the number itself.

## Input Format

A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

Print 'Strong Number' if the number is a strong number, otherwise print 'Not Strong Number'.

## Sample Cases

### Sample Case 1

**Input**
```text
145
```

**Output**
```text
Strong Number
```

### Sample Case 2

**Input**
```text
123
```

**Output**
```text
Not Strong Number
```
