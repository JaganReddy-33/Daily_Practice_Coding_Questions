# Prime Digit Sum

## Description

Given a positive integer N, print the sum of all prime digits present in the number.

## Input Format

An integer N (1 <= N <= 10^9) representing the input number.

## Output Format

Print the sum of all prime digits present in N.

## Sample Cases

### Sample Case 1

**Input**
```text
24681357
```

**Output**
```text
17
```


### Sample Case 2

**Input**
```text
24682468
```

**Output**
```text
4
```
