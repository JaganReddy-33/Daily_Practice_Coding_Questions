# Power Calculation

## Description

Write a function that takes two integers, base n and exponent m, and calculates n raised to the power of m without using any built-in exponentiation functions or operators. Implement the solution using basic loops.

## Input Format

Two integers n and m (-10^9 <= n, m <= 10^9) representing the base number and the exponent.

## Output Format

Print the result of n raised to the power of m.

## Sample Cases

### Sample Case 1

**Input**
```text
2 5
```

**Output**
```text
32
```

### Sample Case 2

**Input**
```text
3 4
```

**Output**
```text
81
```
