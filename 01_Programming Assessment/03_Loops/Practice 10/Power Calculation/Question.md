# Power Calculation

## Description

<p>Write a function that takes two integers, base <code>n</code> and exponent <code>m</code>, and calculates <code>n</code> raised to the power of <code>m</code> without using any built-in exponentiation functions or operators. Implement the solution using basic loops.</p>

## Input Format

<p>Two integers n and m (-10^9 &lt;= n, m &lt;= 10^9) representing the base number and the exponent.</p>

## Output Format

<p>Print the result of n raised to the power of m.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
2 5
```

**Output**
```text
32
```

**Input**
