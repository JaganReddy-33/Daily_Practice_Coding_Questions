# Product of Digits

## Description

Given a positive integer N, print the product of all digits present in N.

## Input Format

- A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

- Print the product of all digits present in N.

## Sample Cases

### Sample Case 1

**Input**
```text
1234
```

**Output**
```text
24
```

### Sample Case 2

**Input**
```text
98765
```

**Output**
```text
15120
```
