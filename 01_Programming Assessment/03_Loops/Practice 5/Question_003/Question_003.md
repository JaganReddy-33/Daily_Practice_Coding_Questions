# Multiples of Both

**Question ID:** `661acfcbf51c6d596b089084`

## Description

Given four positive integers N1, N2, X, and Y, print all numbers from N1 to N2 which are multiples of both X and Y.

## Input Format

Four integers N1, N2, X, and Y (1 <= N1 <= 10^5, 1 <= N2 <= 10^5, 1 <= X, Y <= 10^5) representing the starting and ending natural numbers, and two base numbers.

## Output Format

Print all numbers from N1 to N2 which are multiples of both X and Y, each separated by a space.

## Sample Cases

**Input**
```text
5 30 3 5
```

**Output**
```text
15 30
```
