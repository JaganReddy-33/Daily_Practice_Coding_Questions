# Multiples of Both Descending

**Question ID:** `661acfdf5028dc4e9d17b957`

## Description

Given four positive integers N1, N2, X, and Y, print all numbers from N2 to N1 which are multiples of both X and Y.

## Input Format

Four integers N1, N2, X, and Y (1 <= N1 <= 10^5, 1 <= N2 <= 10^5, 1 <= X, Y <= 10^5) representing the starting and ending natural numbers, and two base numbers.

## Output Format

Print all numbers from N2 to N1 which are multiples of both X and Y, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5 30 3 5
```

**Output**
```text
30 15
```

### Sample Case 2

```text

```
