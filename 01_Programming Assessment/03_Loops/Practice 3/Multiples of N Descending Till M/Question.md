# Multiples of N Descending Till M

## Description

Print all multiples of N from M to 1 in descending order.

## Input Format

Two integers N and M (1 <= N <= 10^5, 1 <= M <= 10^5) representing the base number and the starting natural number.

## Output Format

Print all multiples of N from M to 1 in descending order, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
3 10
```

**Output**
```text
9 6 3
```


### Sample Case 2

**Input**
```text
5 15
```

**Output**
```text
15 10 5
```
