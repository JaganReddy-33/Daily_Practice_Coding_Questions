# First N Multiples of 3 Descending

## Description

Print the first N multiples of 3 in descending order.

## Input Format

A single integer N (1 <= N <= 10^5) representing the number of multiples to print.

## Output Format

Print the first N multiples of 3 in descending order, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
15 12 9 6 3
```


### Sample Case 2

**Input**
```text
3
```

**Output**
```text
9 6 3
```
