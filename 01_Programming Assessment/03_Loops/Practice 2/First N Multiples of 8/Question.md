# First N Multiples of 8

## Description

Print the first N multiples of 8.

## Input Format

A single integer N (1 <= N <= 10^5) representing the number of multiples to print.

## Output Format

Print the first N multiples of 8, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
8 16 24 32 40
```

### Sample Case 2

**Input**
```text
3
```

**Output**
```text
8 16 24
```
