# Armstrong Till N

## Description

Given a positive integer N, print all Armstrong numbers starting from 1 to N.

## Input Format

A single integer N (1 <= N <= 10^5) representing the maximum number.

## Output Format

Print all Armstrong numbers from 1 to N, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
1000
```

**Output**
```text
1 2 3 4 5 6 7 8 9 153 370 371 407
```
