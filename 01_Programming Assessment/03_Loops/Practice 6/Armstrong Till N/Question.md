# Armstrong Till N

## Description

<p>Given a positive integer N, print all Armstrong numbers starting from 1 to N.</p>

## Input Format

<p>A single integer N (1 &lt;= N &lt;= 10^5) representing the maximum number.</p>

## Output Format

<p>Print all Armstrong numbers from 1 to N, each separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
1000
```

**Output**
```text
1 2 3 4 5 6 7 8 9 153 370 371 407
```
