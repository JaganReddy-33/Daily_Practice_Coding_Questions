# Prime Product Digits

**Question ID:** `661ad106f51c6d596b08d6ef`

## Description

Given a positive integer N, print "Prime" if the product of all digits is prime, and print "Not Prime" if the product of all digits is not prime.

## Input Format

- A single integer N (1 <= N <= 10^9) representing the number.

## Output Format

- Print "Prime" if the product of all digits is prime, otherwise print "Not Prime".
