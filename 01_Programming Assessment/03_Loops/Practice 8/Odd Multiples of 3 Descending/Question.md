# Odd Multiples of 3 Descending

## Description

Given two positive integers N1 and N2, print all the odd multiples of 3 from N2 to N1 in descending order.

## Input Format

Two integers N1 and N2 (1 <= N1 <= 10^5, 1 <= N2 <= 10^5) representing the starting and ending natural numbers.

## Output Format

Print all the odd multiples of 3 between N2 and N1 in descending order, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5 20
```

**Output**
```text
15 9
```


### Sample Case 2

**Input**

