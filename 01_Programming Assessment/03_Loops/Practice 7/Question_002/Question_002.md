# Even Multiples of N

**Question ID:** `661ad022f51c6d596b089fca`

## Description

Given two positive integers N and M, print all the even multiples of N from 1 to M.

## Input Format

Two integers N and M (1 <= N, M <= 10^5) representing the base number and the maximum natural number.

## Output Format

Print all the even multiples of N from 1 to M, each separated by a space.

**Input**

```text
3 10
```
