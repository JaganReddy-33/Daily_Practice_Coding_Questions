# Multiples of 3 and 5 Till N

## Description

Print numbers from 1 to N which are multiples of both 3 and 5.

## Input Format

A single integer N (1 <= N <= 10^5) representing the maximum natural number.

## Output Format

Print all numbers from 1 to N which are multiples of both 3 and 5, each separated by a space. If no common multiples print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
20
```

**Output**
```text
15
```


### Sample Case 2

**Input**
```text
15
```

**Output**
```text
15
```
