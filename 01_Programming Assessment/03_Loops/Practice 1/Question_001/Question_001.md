# Natural Numbers Descending Order

**Question ID:** `661accc7f51c6d596b07d2cf`

## Description

Print natural numbers from N to 1 in descending order.

## Input Format

A single integer N (1 <= N <= 10^5) representing the starting natural number.

## Output Format

Print all natural numbers from N to 1 in descending order, each separated by a space.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
5 4 3 2 1
```
