# Multiples of 7 Till N

## Description

Print multiples of 7 from 1 to N.

## Input Format

A single integer N (1 <= N <= 10^5) representing the maximum natural number.

## Output Format

Print all multiples of 7 from 1 to N, each separated by a space. If no multiples found print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
20
```

**Output**
```text
7 14
```


### Sample Case 2

**Input**
```text
15
```

**Output**
```text
7 14
```
