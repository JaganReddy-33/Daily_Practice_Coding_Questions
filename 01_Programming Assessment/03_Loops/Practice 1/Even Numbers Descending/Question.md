# Even Numbers Descending

## Description

<p>Print even numbers from N to 1 in descending order.</p>

## Input Format

<p>A single integer N (1 &lt;= N &lt;= 10^5) representing the starting natural number.</p>

## Output Format

<p>Print all even numbers from N to 1 in descending order, each separated by a space. If no element to be printed, Print “None”.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
4 2
```


### Sample Case 2

**Input**
```text
10
```

**Output**
```text
10 8 6 4 2
```
