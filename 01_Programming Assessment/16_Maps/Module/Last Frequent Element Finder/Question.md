# Last Frequent Element Finder

## Description

<p>Develop a program that takes an array of N integer values as input and identifies the element that has occurred the most number of times.</p>

## Input Format

<p>The first line contains a single integer N, representing the number of elements in the array. The second line contains N space-separated integers, detailing the elements of the array.</p>

## Output Format

<p>Print a single integer representing the most frequently occurring element in the array. If there is a tie in frequency, print the element that appeared last among them.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
1 2 3 2 4 3 5
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text

```

**Output**
```text

```
