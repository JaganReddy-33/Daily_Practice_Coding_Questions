# Largest Frequent Element Finder

## Description

<p>Write a program that reads an array of N integer values and determines the element that has occurred the most number of times.</p>

## Input Format

<p>The first line contains a single integer N, the number of elements in the array. The second line contains N space-separated integers, the elements of the array.</p>

## Output Format

<p>Print a single integer representing the largest element among those that occur most frequently in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
1 2 3 2 4 3 5
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
10
4 5 9 11 9 4 8 15 8 6
```

**Output**
```text
9
```
