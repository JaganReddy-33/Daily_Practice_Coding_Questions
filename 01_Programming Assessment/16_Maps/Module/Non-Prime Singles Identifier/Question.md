# Non-Prime Singles Identifier

## Description

<p>Create a program that reads an array of integers and prints all the non-prime numbers that occur exactly once.</p>

## Input Format

<p>The first line contains a single integer N, the number of elements in the array. The second line contains N space-separated integers, the elements of the array.</p>

## Output Format

<p>Print the non-prime numbers that occur exactly once in the array, each on a new line. If a non-prime number is unique, it should be printed in the order it first appears.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
8
4 6 7 4 8 9 10 11
```

**Output**
```text
6
8
9
10
```


### Sample Case 2

**Input**
```text

```

**Output**
```text
22
```
