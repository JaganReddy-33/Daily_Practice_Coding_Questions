# Even Odd Frequency

## Description

<p>Develop a program that reads an array of integers and prints all the even elements that occur an odd number of times.</p>

## Input Format

<p>The first line contains a single integer N, the number of elements in the array. The second line contains N space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the even integers that occur an odd number of times in the array, each on a new line. If an even number is found to occur an odd number of times, it should be printed only once, in the order it first appears. If no even numbers repeating odd times print “No Repeating Elements”.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
10
12 14 12 14 16 18 18 16 16 20
```

**Output**
```text
16
20
```
