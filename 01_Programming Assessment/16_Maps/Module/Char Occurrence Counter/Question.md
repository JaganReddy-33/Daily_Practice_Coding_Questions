# Char Occurrence Counter

## Description

<p>Write a program that takes a single line of input, which is a string, and prints the occurrence of all characters in the given string.</p>

## Input Format

<p>A single line containing the string for which the character occurrences need to be counted.</p>

## Output Format

<p>For each unique character (case-insensitive) in the input string, print the character (in lowercase) followed by a colon and the number of occurrences of that character in the string. Each character and its count should be printed on a new line in the order that character first appears in the string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello world
```

**Output**
```text
h:1
e:1
l:3
o:2
w:1
r:1
d:1
```
