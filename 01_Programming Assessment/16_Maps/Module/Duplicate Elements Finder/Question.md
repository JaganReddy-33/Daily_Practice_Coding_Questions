# Duplicate Elements Finder

## Description

<p>Given an array of integers, Write a program to print all the duplicate elements present in the array by insertion order and each duplicate element should be printed in new line.</p>

## Input Format

<p>The first line consists of N, size of the array</p><p>Second line consists of N space separated integers which are the elements of the array</p>

## Output Format

<p>Print all the duplicate elements present in the array on new line.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
1 2 3 2 4 3 5
```

**Output**
```text
2
3
```


### Sample Case 2

**Input**
```text
10
4 5 9 11 9 4 8 15 8 6
```

**Output**
```text
4
9
8
```
