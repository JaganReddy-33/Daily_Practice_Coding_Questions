# Unique Elements Identifier

## Description

<p>Develop a program that reads an array of integers and prints all the elements that occur exactly once.</p>

## Input Format

<p>The first line contains a single integer N, the number of elements in the array. </p><p>The second line contains N space-separated integers, the elements of the array.</p>

## Output Format

<p>Print the elements that occur exactly once in the array, each on a new line. If no unique elements print “No Unique Elements”</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
1 2 3 2 4 3 5
```

**Output**
```text
1
4
5
```


### Sample Case 2

**Input**
```text

```

**Output**
```text

```
