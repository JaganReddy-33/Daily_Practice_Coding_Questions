# Lowercase Character Count

## Description

<p>Given a string, count the number of lowercase characters in it.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single integer representing the number of lowercase characters in the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello
```

**Output**
```text
5
```


### Sample Case 2

**Input**
```text
world
```

**Output**
```text
5
```
