# Index Character Printer

## Description

<p>Prints the character present at a given index in a string, and the index value should starts from 0.</p>

## Input Format

<p>The program takes two lines of input:</p><p> - The first line contains a string. </p><p>- The second line contains an integer representing the index value (k).</p>

## Output Format

<p>Print the character present at index k in the input string. </p><p>If the index is invalid or the string is empty, output "Invalid index".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TapAcademy
3
```

**Output**
```text
A
```


### Sample Case 2

**Input**
```text
Testing
7
```

**Output**
```text
Invalid index
```
