# Vowel Count in String

## Description

<p>Count the number of vowels in a given string.</p>

## Input Format

<p>The input consists of a single line containing the input string.</p>

## Output Format

<p>Output the count of vowels in the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello, World!
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
TapAcademy
```

**Output**
```text
4
```
