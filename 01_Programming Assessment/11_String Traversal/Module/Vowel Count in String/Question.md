# Vowel Count in String

## Description

Count the number of vowels in a given string.

## Input Format

The input consists of a single line containing the input string.

## Output Format

Output the count of vowels in the given string.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello, World!
```

**Output**
```text
3
```

### Sample Case 2

**Input**
```text
TapAcademy
```

**Output**

4
