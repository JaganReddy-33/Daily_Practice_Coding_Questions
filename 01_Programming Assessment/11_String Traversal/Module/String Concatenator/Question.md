# String Concatenator

## Description

Concatenates two strings into a single string while preserving their original order.

## Input Format

The program takes two lines of input, each containing a string.

## Output Format

Print the concatenation of the two input strings.

## Sample Cases

### Sample Case 1

**Input**
```text
Tap
Academy
```

**Output**
```text
TapAcademy
```

### Sample Case 2

**Input**
```text
Hello
123
```

**Output**
```text
Hello123
```
