# String Concatenator

## Description

<p>Concatenates two strings into a single string while preserving their original order.</p>

## Input Format

<p>The program takes two lines of input, each containing a string.</p>

## Output Format

<p>Print the concatenation of the two input strings.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Tap
Academy
```

**Output**
```text
TapAcademy
```


### Sample Case 2

**Input**
```text
Hello
123
```

**Output**
```text
Hello123
```
