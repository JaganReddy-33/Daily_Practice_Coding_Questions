# Alphanumeric Character Count

## Description

<p>Given a string, count the number of alphanumeric characters in it.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single integer representing the number of alphanumeric characters in the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
H33LL0
```

**Output**
```text
6
```


### Sample Case 2

**Input**
```text
AbCdEf123456
```

**Output**
```text
12
```
