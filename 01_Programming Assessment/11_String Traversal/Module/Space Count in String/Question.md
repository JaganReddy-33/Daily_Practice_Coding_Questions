# Space Count in String

## Description

<p>Count the number of spaces in a given string.</p>

## Input Format

<p>The input consists of a single line containing the input string.</p>

## Output Format

<p>Output the count of spaces in the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Tap Academy.
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
Programming is fun
```

**Output**
```text
2
```
