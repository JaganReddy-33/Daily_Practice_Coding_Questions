# Reverse String

## Description

<p>Reverses a given string.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output the reversed string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TapAcademy
```

**Output**
```text
ymedacApaT
```


### Sample Case 2

**Input**
```text
Racecar
```

**Output**
```text
racecaR
```
