# Characters After Given Character

## Description

<p>Given a string s and character ch. Print all characters from string s that occur after a given character ch. If the character ch occurs more than once in the string s, consider the first occurrence of the character ch.</p>

## Input Format

<p>A single string `s` containing characters. A single character `ch`.</p>

## Output Format

<p>Print all characters from the string `s` that come after `ch`. If no characters occur after `ch`, print an empty line.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello
e
```

**Output**
```text
llo
```


### Sample Case 2

**Input**
```text
python
o
```

**Output**
```text
n
```


### Sample Case 3

**Input**
```text

```

```text

```
