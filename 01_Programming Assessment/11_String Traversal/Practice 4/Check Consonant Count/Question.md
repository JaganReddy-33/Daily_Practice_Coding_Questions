# Check Consonant Count

## Description

Check if a given string contains more than 5 consonants.

## Input Format

A single string `s` containing characters.

## Output Format

Return `True` if the string contains more than 5 consonants, otherwise return `False`.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World
```

**Output**
```text
True
```
