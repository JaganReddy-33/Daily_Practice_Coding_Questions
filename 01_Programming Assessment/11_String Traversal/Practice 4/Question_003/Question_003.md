# Characters Before Given Character

**Question ID:** `662f330dc74ee9cf9f4dfb07`

## Description

Print all characters from a given string that occur before a given character.

## Input Format

A single string `s` containing characters. A single character `ch`.

## Output Format

Print all characters from the string `s` that come before `ch`. If no characters occur before `ch`, print an empty line.

## Sample Cases

### Sample Case 1

**Input**
```text
hello
o
```

**Output**
```text
hell
```

### Sample Case 2

**Input**
```text
python
z
```

**Output**
```text
python
```
