# Count Leading Spaces

## Description

<p>Count the number of spaces at the beginning of a given string.</p>

## Input Format

<p>A single string `s` containing characters.</p>

## Output Format

<p>Return an integer representing the count of spaces at the beginning of the string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
Python is fun!
```

**Output**
```text
0
```
