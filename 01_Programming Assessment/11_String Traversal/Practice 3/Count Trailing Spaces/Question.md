# Count Trailing Spaces

## Description

Count the number of spaces at the end of a given string.

## Input Format

A single string `s` containing characters.

## Output Format

Return an integer representing the count of spaces at the end of the string.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World
```

**Output**
```text
3
```

### Sample Case 2

**Input**
```text
Python is fun!
```

**Output**
```text
0
```
