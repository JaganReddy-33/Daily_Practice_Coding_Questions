# Sum of Odd Digits

## Description

<p>Calculate the sum of all odd digits present in a given string.</p>

## Input Format

<p>A single string `s` containing characters.</p>

## Output Format

<p>Return an integer representing the sum of all odd digits in the string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello12345
```

**Output**
```text
9
```


### Sample Case 2

**Input**
```text
9876543210
```

**Output**
```text
25
```
