# String Contains Consonants

## Description

Determine whether a given string contains only consonants or not.

## Input Format

The input consists of a single string.

## Output Format

Print "Yes" if the string contains only consonants, otherwise print "No".

## Sample Cases

### Sample Case 1

**Input**
```text
hello
```

**Output**
```text
No
```


### Sample Case 2

**Input**
```text
xyz
```

**Output**
```text
Yes
```
