# String Contains Vowels

## Description

Determine whether a given string contains only vowels or not.

## Input Format

The input consists of a single string.

## Output Format

Print "Yes" if the string contains only vowels, otherwise print "No".

## Sample Cases

### Sample Case 1

**Input**
```text
hello
```

**Output**
```text
No
```


### Sample Case 2

**Input**
```text
aeiou
```

**Output**
```text
Yes
```
