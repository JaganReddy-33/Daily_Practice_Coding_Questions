# Consonant Characters with Prime ASCII Values

## Description

Construct and return a new string containing only the consonant characters (non-vowel and non-space characters) whose ASCII values are prime numbers, if there are no consonant whose ascii value is prime print -1.

## Input Format

A single string `s` containing characters.

## Output Format

Return a new string containing consonant characters whose ASCII values are prime numbers, if there are no consonant whose ascii value is prime print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
CODING
```

**Output**
```text
CG
```


### Sample Case 2

**Input**
```text
a132a7d5d9:cbfe66e6847d6892edbc7399c129111f:5678e73a7bf4262f33b349108d9b7a61
```

**Output**
```text
dca2:98efa59fe95447678be479d47122a14c:9b795a3a443449df4118734a8d2df14d
```
