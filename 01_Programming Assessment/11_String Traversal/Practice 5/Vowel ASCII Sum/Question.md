# Vowel ASCII Sum

## Description

Calculate the sum of ASCII values of all vowels present in a given string.

## Input Format

A single string `s` containing characters.

## Output Format

Return an integer representing the sum of ASCII values of all vowels in the string.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World
```

**Output**
```text
323
```

### Sample Case 2

**Input**
```text
Python is fun!
```

**Output**
```text
333
```
