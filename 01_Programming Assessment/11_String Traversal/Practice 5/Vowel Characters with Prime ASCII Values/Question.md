# Vowel Characters with Prime ASCII Values

## Description

Construct and return a new string containing only the vowel characters ('a', 'e', 'i', 'o', 'u') whose ASCII values are prime numbers, if there are no vowels with prime numbers print -1.

## Input Format

A single string `s` containing characters.

## Output Format

Return a new string containing vowel characters ('a', 'e', 'i', 'o', 'u') whose ASCII values are prime numbers, if there are no vowels with prime numbers print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
Hello World!
```

**Output**
```text
e
```
