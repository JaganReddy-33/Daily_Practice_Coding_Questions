# Increasing Order Subarrays

**Question ID:** `661a03225028dc4e9db81468`

## Description

Given an array of integers, find and print all the subarrays where the elements are in strictly increasing order. Each qualifying subarray should be printed in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print each subarray with elements in strictly increasing order, in a new line as space-separated integers. If no such subarrays exist, print 'None'.
