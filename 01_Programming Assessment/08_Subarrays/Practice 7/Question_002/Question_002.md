# Perfect Square Length Subarrays

**Question ID:** `661a030a5028dc4e9db81459`

## Description

Given an array of integers, find and print all subarrays whose length is a perfect square. Each qualifying subarray should be printed in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print each subarray with a length that is a perfect square, in a new line as space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 2 3 4
```

**Output**
```text
1
2
3
4
1 2 3 4
```

### Sample Case 2

**Input**
```text
3
5 6 7
```

**Output**
```text
5
6
7
```
