# Longest Even Difference Subarray

**Question ID:** `6619f6c55028dc4e9db658b8`

## Description

Find the longest subarray with size greater than 1 having even difference between max and min element.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the longest subarray with size greater than 1 where the difference between the maximum and minimum element is an even number. The elements should be separated by space. If there are no such subarrays, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 7 9
```

**Output**
```text
1 3 5 7 9
```

### Sample Case 2

**Input**
```text
3
2 4 6
```

**Output**
```text
2 4 6
```
