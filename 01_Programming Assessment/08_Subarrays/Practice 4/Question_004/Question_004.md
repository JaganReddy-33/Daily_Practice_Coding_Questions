# Longest Odd Difference Subarray

**Question ID:** `6619f6edf51c6d596ba8c774`

## Description

Find the longest subarray with odd difference between max and min element.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the longest subarray where the difference between the maximum and minimum element is an odd number. The elements should be separated by space. If there are no such subarrays, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 4 5 8
```

**Output**
```text
1 4 5 8
```

### Sample Case 2

**Input**
```text
3
2 7 11
```

**Output**
```text
2 7 11
```
