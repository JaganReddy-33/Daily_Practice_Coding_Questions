# Smallest Even Difference Subarray

**Question ID:** `6619f6d8f51c6d596ba8c75e`

## Description

Find the smallest subarray with size greater than 1 having even difference between max and min element.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the smallest subarray whose size is greater than 1, where the difference between the maximum and minimum element in the subarray is an even number. The elements should be separated by space. If there are no such subarrays, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
4
2 4 5 6
```

**Output**
```text
2 4
```

### Sample Case 2

**Input**
```text
5
2 2 2 2 2
```

**Output**
```text
2 2
```
