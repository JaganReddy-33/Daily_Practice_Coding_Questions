# Odd Product Subarrays

**Question ID:** `661a02a7f51c6d596baa22b6`

## Description

Given an array of integers, find and print all possible subarrays whose elements' product is an odd number. A subarray is a contiguous part of the array with the same order as in the original array. Print each subarray as space-separated integers, or 'None' if no such subarrays exist.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print each odd product subarray in a new line as space-separated integers. Print 'None' if no such subarrays exist.
