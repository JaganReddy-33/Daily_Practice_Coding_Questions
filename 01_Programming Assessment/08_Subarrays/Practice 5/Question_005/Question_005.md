# K-Size Product Equals M

**Question ID:** `661a02b7f51c6d596baa2352`

## Description

Given an array of integers, a subarray size K, and a target product M, find and print all the subarrays of size K whose elements' product is exactly equal to M. Print each qualifying subarray as a sequence of space-separated integers, or 'None' if no such subarrays exist.

## Input Format

The first line contains two integers N and K, the size of the array and the subarray size respectively. The second line contains a single integer M, the target product. The third line contains N space-separated integers denoting the elements of the array.

## Output Format

Print each subarray of size K where the product of its elements is M, in a new line as space-separated integers. Print 'None' if no such subarrays exist.

## Sample Cases

### Sample Case 1

**Input**
```text
5 2
2
1 2 1 2 1
```

**Output**
```text
1 2
2 1
1 2
2 1
```

### Sample Case 2

**Input**
```text
4 3
24
2 3 4 6
```

**Output**
```text
2 3 4
```
