# Prime Product Subarrays

**Question ID:** `661a028af51c6d596baa226d`

## Description

Given an array of integers, find and print all possible subarrays whose elements' product is a prime number. A subarray is a contiguous part of the array with the same order as in the original array. Print each subarray as space-separated integers, or 'None' if no such subarrays exist.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print each prime product subarray in a new line as space-separated integers. Print 'None' if no such subarrays exist.

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 4 5 6
```

**Output**
```text
2
3
5
```

### Sample Case 2

**Input**
```text
4
6 8 10 12
```

**Output**
```text
None
```
