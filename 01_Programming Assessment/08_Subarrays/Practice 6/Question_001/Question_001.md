# Longest Prime Product Subarray

**Question ID:** `661a02c4f51c6d596baa246d`

## Description

Given an array of integers, find and print the longest subarray whose elements' product is a prime number. If multiple subarrays of the same maximum length have a prime product, print the first one. Print 'None' if no such subarray exists.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the longest subarray where the product of its elements is a prime number as space-separated integers. If no such subarrays exist, print 'None'. If there are multiple prime product subarrays of same size print the first occurring subarray.

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 4 5 6
```

**Output**
```text
2
```

### Sample Case 2

**Input**
```text
4
6 8 10 12
```

**Output**
```text
None
```
