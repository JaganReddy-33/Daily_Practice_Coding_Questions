# Smallest Even Product Subarray

**Question ID:** `661a02e6f51c6d596baa2949`

## Description

Given an array of integers, find and print the smallest subarray whose elements' product is an even number. If multiple subarrays of the same minimum length have an even product, print the first one. Print 'None' if no such subarray exists.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the smallest subarray where the product of its elements is an even number as space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
4
2 4 5 6
```

**Output**
```text
2
```

### Sample Case 2

**Input**
```text
5
2 2 2 2 2
```

**Output**
```text
2
```
