# Longest Odd Product Subarray

**Question ID:** `661a02f1f51c6d596baa2e04`

## Description

Given an array of integers, find and print the longest subarray whose elements' product is an odd number. If multiple subarrays of the same maximum length have an odd product, print the first one. Print 'None' if no such subarray exists.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the longest subarray where the product of its elements is an odd number as space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 7 9
```

**Output**
```text
1 3 5 7 9
```

### Sample Case 2

**Input**
```text
4
2 4 6 8
```

**Output**
```text
None
```
