# Longest Even Product Subarray

**Question ID:** `661a02dc5028dc4e9db8137b`

## Description

Given an array of integers, find and print the longest subarray whose elements' product is an even number. If multiple subarrays of the same maximum length have an even product, print the first one. Print 'None' if no such subarray exists.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the longest subarray where the product of its elements is an even number as space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 2 3 4 5
```

### Sample Case 2

**Input**
```text
3
3 5 7
```

**Output**
```text
None
```
