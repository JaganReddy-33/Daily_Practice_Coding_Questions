# Smallest Prime Product Subarray

**Question ID:** `661a02cf5028dc4e9db8131a`

## Description

Given an array of integers, find and print the smallest subarray whose elements' product is a prime number. If multiple subarrays of the same minimum length have a prime product, print the first one. Print 'None' if no such subarray exists.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the smallest subarray where the product of its elements is a prime number as space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 4 5 8
```

**Output**
```text
5
```

### Sample Case 2

**Input**
```text
3
2 7 11
```

**Output**
```text
2
```
