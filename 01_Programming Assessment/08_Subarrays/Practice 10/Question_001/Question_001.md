# Smallest K-Sum Subarray

**Question ID:** `661bc1fb5028dc4e9d48ac2e`

## Description

Given an array of integers, an integer K, and an integer M, your task is to find and print the smallest subarray whose length is greater than M and whose sum is exactly equal to K. A subarray is defined as a contiguous part of the array. If there are multiple subarrays that meet the criteria, print the one that appears first in the array. If no such subarray exists, print 'None'.

## Input Format

The first line contains three integers N, K, and M, representing the size of the array, the target sum K, and the integer M, respectively. The second line contains N space-separated integers, the elements of the array.

## Output Format

Print the smallest subarray with length greater than M whose sum is equal to K, as a sequence of space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
5 9 2
1 2 3 4 5
```

**Output**
```text
2 3 4
```

### Sample Case 2

**Input**
```text
5 15 1
5 5 5 5 5
```

**Output**
```text
5 5 5
```
