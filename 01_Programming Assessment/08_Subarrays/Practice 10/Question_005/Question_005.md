# Smallest Prime Sum Subarray

**Question ID:** `661bc241f51c6d596b3a60be`

## Description

Given an array of integers and an integer M, your task is to find and print the smallest subarray whose length is greater than M and whose sum is a prime number. A prime number is a natural number greater than 1 that has no positive divisors other than 1 and itself. A subarray is defined as a contiguous part of the array. If there are multiple subarrays that meet the criteria, print the one that appears first in the array. If no such subarray exists, print 'None'.

## Input Format

The first line contains two integers N and M, representing the size of the array and the integer M, respectively.

The second line contains N space-separated integers, the elements of the array.

## Output Format

Print the smallest subarray with length greater than M whose sum is a prime number, as a sequence of space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
6 3
2 3 1 1 4 6
```

**Output**
```text
2 3 1 1
```

### Sample Case 2

**Input**
```text
5 1
6 5 7 2 1
```

**Output**
```text
6 5
```
