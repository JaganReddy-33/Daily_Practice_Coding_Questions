# All K-Sum Subarrays

**Question ID:** `661bc21ff51c6d596b3a5c74`

## Description

Given an array of integers, an integer K, and an integer M, your task is to find and print all subarrays whose length is greater than M and whose sum is exactly equal to K. A subarray is defined as a contiguous part of the array. Print each qualifying subarray in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains three integers N, K, and M, representing the size of the array, the target sum K, and the integer M, respectively. The second line contains N space-separated integers, the elements of the array.

## Output Format

For each subarray with length greater than M whose sum is equal to K, print the subarray in a new line as a sequence of space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
5 9 2
1 2 3 4 5
```

**Output**
```text
2 3 4
```

### Sample Case 2

**Input**
```text
5 15 1
5 5 5 5 5
```

**Output**
```text
5 5 5
5 5 5
5 5 5
```
