# Smallest Even Sum Subarray

**Question ID:** `6619f5ec5028dc4e9db64d6a`

## Description

Find the smallest subarray with an even sum.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the smallest subarray with an even sum. The elements should be separated by space. If there are no such subarrays, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text

1 2 3 4
```

**Output**
```text
2
```
