# Longest Even Sum Subarray

**Question ID:** `6619f5d5f51c6d596ba8c0d5`

## Description

Find the longest subarray with an even sum.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the longest subarray with an even sum. The elements should be separated by space. If there are no such subarrays, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 2 3 4
```

