# Sum of Subarrays of Size K

## Description

<p>Calculate the sum of all subarrays of given size from a given array.</p>

## Input Format

<p>First line contain an integer size, representing size of the subarray</p><p>Second line contains the size of the array (integer) n</p><p>Third line contains elements of the array (space-separated integers)</p>

## Output Format

<p>The program should output the sum of all subarrays of given size, separated by spaces.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
5
1 2 3 4 5
```

**Output**
```text
6 9 12
```


### Sample Case 2

**Input**
```text

```

**Output**
```text

```
