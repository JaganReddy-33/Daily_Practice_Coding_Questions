# Prime Subarrays

## Description

<p>Print all possible subarrays whose sum is prime.</p>

## Input Format

<p>The first line contains a single integer n, representing the number of elements in the array. The second line contains n space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print all the possible subarrays whose sum is prime, separated by a space. If no such subarrays exist, print "None".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
2 
3 
5 
1 2 
2 3 
3 4
```


### Sample Case 2

**Input**
```text
4
-1 -2 -3 -4
```

**Output**
```text
None
```
