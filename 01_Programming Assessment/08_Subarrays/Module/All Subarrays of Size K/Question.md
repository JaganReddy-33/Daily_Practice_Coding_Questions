# All Subarrays of Size K

## Description

<p>Print all possible subarrays of size K from a given array.</p>

## Input Format

<p>First line contain an integer k, represents the number the subarray length.</p><p>The second line contains size of the array (integer)</p><p>Third line contains elements of the array (space-separated integers)</p>

## Output Format

<p>The program should output each subarray of size K on a new line.</p><p>Each subarray should be displayed as a space-separated sequence of elements.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
5
1 2 3 4 5
```

**Output**
```text
1 2 3
2 3 4
3 4 5
```


### Sample Case 2

**Input**
```text
2
4
10 20 30 40
```

**Output**
```text
10 20
20 30
30 40
```
