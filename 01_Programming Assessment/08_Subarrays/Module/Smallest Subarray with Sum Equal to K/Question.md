# Smallest Subarray with Sum Equal to K

## Description

<p>Find the smallest subarray in a given array whose sum is equal to a specified value K.</p>

## Input Format

<p>The program takes the following inputs:</p><p>- First line contain an integer k, represents the number the sum of subarray must be equal to.</p><p>- The size of the array (integer)</p><p>- The elements of the array (space-separated integers)</p>

## Output Format

<p>The program outputs the smallest subarray whose sum is equal to K.</p><p>If multiple subarrays with the same minimum length exist, it displays the first one found.</p><p>If no subarray with sum K exists, it outputs 'No subarray found.'</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
6
2 3 1 4 2 5
```

**Output**
```text
5
```
