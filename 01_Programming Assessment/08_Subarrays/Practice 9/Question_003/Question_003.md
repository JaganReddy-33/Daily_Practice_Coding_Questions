# Odd Numbers Subarrays

**Question ID:** `661a0395f51c6d596baa4538`

## Description

Find and print all subarrays where all elements are odd numbers. Each qualifying subarray should be printed in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, representing the size of the array. The second line contains N space-separated integers, the elements of the array.

## Output Format

For each subarray where all elements are odd numbers, print the subarray as space-separated integers. If no qualifying subarrays exist, print 'None'.
