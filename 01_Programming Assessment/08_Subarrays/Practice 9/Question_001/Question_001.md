# Prime Numbers Subarrays

**Question ID:** `661a037e5028dc4e9db81da2`

## Description

Find and print all subarrays where all elements are prime numbers. Each qualifying subarray should be printed in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, representing the size of the array. The second line contains N space-separated integers, the elements of the array.

## Output Format

For each subarray where all elements are prime numbers, print the subarray as space-separated integers. If no qualifying subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 4 5 6
```

**Output**
```text
2
3
5
2 3
```

### Sample Case 2

**Input**
```text
3
8 10 12
```

**Output**
```text
None
```
