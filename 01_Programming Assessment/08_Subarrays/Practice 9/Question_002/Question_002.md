# Even Numbers Subarrays

**Question ID:** `661a038af51c6d596baa44c7`

## Description

Find and print all subarrays where all elements are even numbers. Each qualifying subarray should be printed in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, representing the size of the array. The second line contains N space-separated integers, the elements of the array.

## Output Format

For each subarray where all elements are even numbers, print the subarray as space-separated integers. If no qualifying subarrays exist, print 'None'.
