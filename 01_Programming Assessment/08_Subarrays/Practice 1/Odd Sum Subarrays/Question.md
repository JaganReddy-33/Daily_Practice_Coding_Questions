# Odd Sum Subarrays

## Description

<p>Find and print all possible subarrays whose sum is odd.</p>

## Input Format

<p>The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.</p>

## Output Format

<p>Print each subarray with an odd sum in a new line. Each element of the subarray should be separated by a space. If there are no such subarrays, print "None".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
1 2 3
```

**Output**
```text
1 
3 
1 2 
2 3
```


### Sample Case 2

**Input**
```text
5
4 3 5 7 2
```

**Output**
```text

5 
7 
4 3 
7 2 
3 5 7 
4 3 5 7 
3 5 7 2 
4 3 5 7 2
```
