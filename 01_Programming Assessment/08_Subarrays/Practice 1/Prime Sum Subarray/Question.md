# Prime Sum Subarray

## Description

<p>Find the longest subarray with a prime sum.</p>

## Input Format

<p>The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.</p>

## Output Format

<p>Print the longest subarray with a prime sum. The elements should be separated by space. If there are no such subarrays, print "None".</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 5 7 4
```

**Output**
```text
2 3 5 7
```


### Sample Case 2

**Input**
```text
4
6 10 15 7
```

**Output**
```text
6 10 15
```
