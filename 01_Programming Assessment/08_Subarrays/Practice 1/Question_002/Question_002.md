# Odd Sum Subarrays

**Question ID:** `6619f5895028dc4e9db63abc`

## Description

Find and print all possible subarrays whose sum is odd.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print each subarray with an odd sum in a new line. Each element of the subarray should be separated by a space. If there are no such subarrays, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
3
1 2 3
```

**Output**
```text
1
3
1 2
2 3
```

### Sample Case 2

**Input**
```text
5
4 3 5 7 2
```

**Output**
```text
3
5
7
4 3
7 2
3 5 7
4 3 5 7
3 5 7 2
4 3 5 7 2
```
