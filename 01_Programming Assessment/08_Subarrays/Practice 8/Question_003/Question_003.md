# Palindrome Sequence Subarrays

**Question ID:** `661a035d5028dc4e9db81804`

## Description

Given an array of integers, find and print all the subarrays whose elements form a palindrome sequence. Each qualifying subarray should be printed in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, the size of the array.

The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print each subarray with elements in a palindrome sequence, in a new line as space-separated integers. If no such subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 2 1
```

**Output**
```text
1
2
3
2
1
2 3 2
1 2 3 2 1
```

### Sample Case 2

**Input**
```text
4
4 5 5 4
```

**Output**
```text
4
5
5
4
5 5
4 5 5 4
```
