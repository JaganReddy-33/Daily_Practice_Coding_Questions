# Consecutive Extremes Subarrays

**Question ID:** `661a0373f51c6d596baa3996`

## Description

Find and print all subarrays where the maximum and minimum elements are consecutive numbers. Print each qualifying subarray in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, representing the size of the array. The second line contains N space-separated integers, the elements of the array.

## Output Format

For each subarray where the maximum and minimum elements are consecutive numbers, print the subarray as space-separated integers. If no qualifying subarrays exist, print 'None'.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 5 6
```

**Output**
```text
1 2
2 3
5 6
```

### Sample Case 2

**Input**
```text
4
4 3 2 1
```

**Output**
```text
4 3
3 2
2 1
```
