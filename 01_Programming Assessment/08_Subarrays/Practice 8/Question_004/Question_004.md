# Prime Extremes Subarrays

**Question ID:** `661a03685028dc4e9db81960`

## Description

Find and print all subarrays where both the minimum and maximum elements are prime numbers. Print each qualifying subarray in a new line as a sequence of space-separated integers. If there are no such subarrays, print 'None'.

## Input Format

The first line contains a single integer N, representing the size of the array. The second line contains N space-separated integers, the elements of the array.

## Output Format

For each subarray where the minimum and maximum elements are prime, print the subarray as space-separated integers. Print 'None' if no qualifying subarrays exist.

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 5 1 4
```

**Output**
```text
2
3
5
2 3
3 5
2 3 5
```

### Sample Case 2

**Input**
```text
4
6 10 15 7
```

**Output**
```text
7
```
