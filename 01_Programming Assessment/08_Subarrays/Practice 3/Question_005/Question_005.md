# Longest Prime Difference Subarray

**Question ID:** `6619f6a4f51c6d596ba8c5ac`

## Description

Find the longest subarray with prime difference between max and min element.

## Input Format

The first line contains a single integer N, the size of the array. The second line contains N space-separated integers denoting the elements of the array.

## Output Format

Print the longest subarray where the difference between the maximum and minimum element is a prime number. The elements should be separated by space. If there are no such subarrays, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
5
2 3 5 7 11
```

**Output**
```text
2 3 5 7
```

### Sample Case 2

**Input**
```text
4
6 9 12 15
```

**Output**
```text
6 9
```
