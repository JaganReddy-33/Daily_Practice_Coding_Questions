# Non-Repeated Elements

## Description

<p>Find and print the elements that are not repeated in two sorted arrays. Print the result in sorted array</p>

## Input Format

<p>The input consists of four lines:</p><p>The first line contains an integer N, representing the number of elements in array A.</p><p>The second line contains N space-separated integers, denoting the elements of array A.</p><p>The third line contains an integer M, representing the number of elements in array B.</p><p>The fourth line contains M space-separated integers, denoting the elements of array B.</p>

## Output Format

<p>Print the elements that are not repeated in either array A or B, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
6
2 4 6 8 10 12
```

**Output**
```text
1 3 5 6 8 10 12
```


### Sample Case 2

**Input**
