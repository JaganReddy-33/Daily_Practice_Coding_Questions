# Merge Primes

**Question ID:** `662a067aae2286cdf8de2537`

## Description

Merge two arrays such that the merged array contains prime numbers. Print the all the prime numbers of the first array followed by the second array.

## Input Format

The first line contains two space-separated integers n and m, the size of both arrays A and B.

The second line contains n space-separated integers A[i]. The third line contains m space-separated integers B[i].

## Output Format

A single line containing space-separated integers representing the merged array with prime elements, if there are no prime elements print None.

## Sample Cases

### Sample Case 1

**Input**
```text
3 3
2 3 4
5 6 7
```

**Output**
```text
2 3 5 7
```

### Sample Case 2

**Input**
```text
4 3
3 4 5 6
7 8 9
```

**Output**
```text
3 5 7
```
