# Zigzag Merge

**Question ID:** `662a06aac74ee9cf9f391bae`

## Description

Merge two sorted arrays into a zigzag pattern.

## Input Format

The first line contains two space-separated integers n and m, the size of both arrays A and B. The second line contains n space-separated integers A[i]. The third line contains m space-separated integers B[i].

## Output Format

A single line containing space-separated integers representing the merged array in zigzag pattern.

## Sample Cases

### Sample Case 1

**Input**
```text
3 3
1 3 5
2 4 6
```

**Output**
```text
1 2 3 4 5 6
```

### Sample Case 2

**Input**

```text
2 4 6
1 3 5
```
