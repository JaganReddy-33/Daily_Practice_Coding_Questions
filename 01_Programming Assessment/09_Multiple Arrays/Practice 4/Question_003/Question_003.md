# Prime Sum Elements

**Question ID:** `662a0686c74ee9cf9f38fdd3`

## Description

Print the sum of prime elements from two arrays.

## Input Format

The first line contains two space-separated integers n and m, the size of both arrays A and B. The second line contains n space-separated integers A[i]. The third line contains m space-separated integers B[i].

## Output Format

Print single integer which is sum of prime numbers present in an array.
