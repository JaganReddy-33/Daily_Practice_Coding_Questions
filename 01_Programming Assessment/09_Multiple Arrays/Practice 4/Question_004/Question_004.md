# Merge Inplace

**Question ID:** `662a069bc74ee9cf9f39121c`

## Description

Merge two sorted arrays without using extra space.

## Input Format

First line contains two integer values representing size of array 1 and array 2

The second line contains space-separated integers representing sorted array 1.

The third line contains space-separated integers representing sorted array 2.

## Output Format

A single line containing space-separated integers representing the merged sorted array.
