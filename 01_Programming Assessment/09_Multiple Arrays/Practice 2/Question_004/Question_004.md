# Merge Sorted Arrays Even

**Question ID:** `662a058fc74ee9cf9f37f2f5`

## Description

Given two sorted arrays, first array in ascending order and second array in descending order, merge these arrays such that even elements from first array followed by even elements of the second array.

## Input Format

The input consists of two lines.

The first line contains space-separated integers representing the elements of the array sorted in ascending order.

The second line contains space-separated integers representing the elements of the array sorted in descending order.

## Output Format

Print space-separated integers representing the merged array containing only even elements.

## Sample Cases

### Sample Case 1

**Input**
```text
3 3
1 3 5
6 4 2
```

**Output**
```text
6 4 2
```

### Sample Case 2

**Input**
```text
3 3
-5 -3 2
7 4 1
```

**Output**
```text
2 4
```
