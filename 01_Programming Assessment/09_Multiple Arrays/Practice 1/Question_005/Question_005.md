# Merge Sorted Arrays Descending

**Question ID:** `662a054aae2286cdf8dcfa20`

## Description

Given two sorted arrays, merge them into a single sorted array in descending order.

## Input Format

The first line contains two space-separated integers n and m, the sizes of arrays A and B. The second line contains n space-separated integers representing the elements of array A. The third line contains m space-separated integers representing the elements of array B.

## Output Format

Print space-separated integers representing the merged sorted array in descending order.

## Sample Cases

### Sample Case 1

**Input**
```text
3 3
1 3 5
6 4 2
```

**Output**
```text
6 5 4 3 2 1
```

### Sample Case 2

**Input**
```text
3 3
-5 -3 0
7 4 1
```

**Output**
```text
7 4 1 0 -3 -5
```
