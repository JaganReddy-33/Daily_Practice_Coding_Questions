# Merge Sorted Arrays

**Question ID:** `662a0529c74ee9cf9f377171`

## Description

Given two sorted arrays, one in ascending order and the other in descending order, merge them into a single sorted array in ascending order.

## Input Format

The first line contains two space-separated integers n and m, the sizes of arrays A and B. The second line contains n space-separated integers representing the elements of array A. The third line contains m space-separated integers representing the elements of array B.

## Output Format

Print space-separated integers representing the merged sorted array.

## Sample Cases

### Sample Case 1

**Input**
```text
3 3
1 3 5
6 4 2
```

**Output**
```text
1 2 3 4 5 6
```

### Sample Case 2

**Input**
```text
3 3
-5 -3 0
7 4 1
```

**Output**
```text
-5 -3 0 1 4 7
```
