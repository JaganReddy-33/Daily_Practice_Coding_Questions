# Reverse Consonants String

**Question ID:** `663c6c3b7adf493676286b56`

## Description

Given a string, reverse only the consonants present in it and return the resulting string. Consonants are all the alphabets except 'a', 'e', 'i', 'o', and 'u', both uppercase and lowercase.

## Input Format

A string containing only alphabetical characters.

## Output Format

A string with consonants reversed.

## Sample Cases

### Sample Case 1

**Input**
```text
hello
```

**Output**
```text
lelho
```

### Sample Case 2

**Input**
```text
leetcode
```

**Output**
