# Merge Alternately

**Question ID:** `663c6c237adf4936762860ff`

## Description

You are given two strings str1 and str2. Your task is to write a Java program to merge these two strings alternatively, starting with the first character of str1.

## Input Format

The first line contains the string str1.
The second line contains the string str2.

## Output Format

Print the merged string formed by alternating characters from str1 and str2.
