# String Insertion

**Question ID:** `663c6c0e7adf493676285a90`

## Description

You are given a string s and one integer index and targetIndex. Your task is to insert another string target into the string s at the specified targetIndex.

## Input Format

The first line contains the string s. The second line contains the string target. The third line contains one integer value which is the targetIndex.

## Output Format

Print the string s after inserting the string target at the specified targetIndex.

## Sample Cases

### Sample Case 1

**Input**
```text
hello world
beautiful
5
```

**Output**
```text
hellobeautiful world
```

