# Valid Palindrome (Ignore Numerics)

## Description

Given a string, check if it is a valid palindrome ignoring numeric characters.

## Input Format

A single string containing lowercase alphabets, numbers.

## Output Format

True if the string is a valid palindrome after ignoring numeric characters, otherwise False.

## Sample Cases

### Sample Case 1

**Input**
```text
amana1plan0a7canal5Panama
```

**Output**
```text
True
```

### Sample Case 2

**Input**
```text
racecar12321
```

**Output**
```text
True
```
