# Valid Palindrome (Ignore Numerics)

## Description

<p>Given a string, check if it is a valid palindrome ignoring numeric characters.</p>

## Input Format

<p>A single string containing lowercase alphabets, numbers.</p>

## Output Format

<p>True if the string is a valid palindrome after ignoring numeric characters, otherwise False.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
amana1plan0a7canal5Panama
```

**Output**
```text
True
```


### Sample Case 2

**Input**
```text
racecar12321
```

**Output**
```text
True
```
