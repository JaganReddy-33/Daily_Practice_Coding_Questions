# Replace Characters

## Description

<p>Given a string and two characters ch1 and ch2, replace all occurrences of ch1 with ch2.</p>

## Input Format

<p>Three inputs - a string containing alphabets, numbers, and special characters, and two single characters.</p>

## Output Format

<p>A string with all occurrences of ch1 replaced by ch2.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello world
o *
```

**Output**
```text
hell* w*rld
```


### Sample Case 2

**Input**
```text
programming is fun
i @
```

**Output**
```text
programm@ng @s fun
```
