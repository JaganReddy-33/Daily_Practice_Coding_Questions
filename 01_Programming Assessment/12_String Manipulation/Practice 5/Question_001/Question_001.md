# Reverse Digits String

**Question ID:** `663c6cdabc427c696eda45f3`

## Description

Given a string consisting of digits and other characters, reverse only the digits present in it and return the resulting string. Other characters should remain in their original positions.

## Input Format

A string containing alphanumeric characters.

## Output Format

A string with digits reversed.
