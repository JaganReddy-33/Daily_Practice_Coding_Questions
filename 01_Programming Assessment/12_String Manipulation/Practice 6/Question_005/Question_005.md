**Question ID:** `663c6e267adf49367628c984`

## Description

You are given a string. Your task is to print each character in the string along with its consecutive occurrence count.

## Input Format

The input consists of a single string S (1 ≤ |S| ≤ 1000), where |S| denotes the length of the string.

## Output Format

Print each character in the string followed by the count of its consecutive occurrences.
