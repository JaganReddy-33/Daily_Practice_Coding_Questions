# Insert Asterisks Before Numeric Characters

## Description

<p>Insert an asterisk (*) before each numeric character (0-9) in a given string.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output a single line containing the modified string with asterisks inserted before numeric characters.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TAP123ACADEMY456
```

**Output**
```text
TAP*1*2*3ACADEMY*4*5*6
```


### Sample Case 2

**Input**
```text
CODE@123TAP
```

**Output**
```text
CODE@*1*2*3TAP
```
