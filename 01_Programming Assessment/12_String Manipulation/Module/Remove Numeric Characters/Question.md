# Remove Numeric Characters

## Description

<p>Remove all numeric characters from a given string.</p>

## Input Format

<p>The input consists of a single line containing a string that may contain numerical characters.</p>

## Output Format

<p>Output a single line containing the modified string after removing all numerical characters.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Tap123Academy456
```

**Output**
```text
TapAcademy
```


### Sample Case 2

**Input**
```text
P1r2o3g4r5a6m7m8i9n10g!
```

**Output**
```text
Programming!
```
