# String to ASCII Converter

## Description

<p>Converts a given string to its corresponding ASCII values.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output the ASCII values separated by spaces.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello, World!
```

**Output**
```text
72 101 108 108 111 44 32 87 111 114 108 100 33
```


### Sample Case 2

**Input**
```text
TapAcademy
```

**Output**
```text
84 97 112 65 99 97 100 101 109 121
```
