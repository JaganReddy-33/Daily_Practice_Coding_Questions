# String Sort

## Description

<p>Given a string, sort it in ascending order.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single string representing the sorted characters of the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TAPACADEMY
```

**Output**
```text
AAACDEMPTY
```


### Sample Case 2

**Input**
```text
HelloWorld
```

**Output**
```text
HWdellloor
```
