# Remove Vowels

## Description

<p>Remove all vowels from a given string.</p>

## Input Format

<p>The input consists of a single line containing a string that may contain vowels.</p>

## Output Format

<p>Output a single line containing the modified string after removing all vowels.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TapAcademyBTM
```

**Output**
```text
TpcdmyBTM
```


### Sample Case 2

**Input**
```text
Coding
```

**Output**
```text
Cdng
```
