# Insert Asterisks Before 'a' Characters

## Description

<p>Insert an asterisk (*) before each occurrence of the character 'a' in a given string.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output a single line containing the modified string with asterisks inserted before 'a' characters.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Tapacademy
```

**Output**
```text
T*ap*ac*ademy
```


### Sample Case 2

**Input**
```text
progr*amming
```

**Output**
```text
progr**amming
```
