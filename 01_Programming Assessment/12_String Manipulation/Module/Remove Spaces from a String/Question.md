# Remove Spaces from a String

## Description

<p>Write a Java program that removes all leading and trailing spaces from a given string.</p>

## Input Format

<p>A single line containing a string.</p>

## Output Format

<p>Print the input string after removing any leading and trailing spaces.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello, World!
```

**Output**
```text
Hello, World!
```


### Sample Case 2

**Input**
```text
TAP ACADEMY
```

**Output**
```text
TAP ACADEMY
```
