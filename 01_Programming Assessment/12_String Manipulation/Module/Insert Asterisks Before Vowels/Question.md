# Insert Asterisks Before Vowels

## Description

<p>Insert an asterisk (*) before each vowel (a, e, i, o, u) in a given string.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output a single line containing the modified string with asterisks inserted before vowels.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
d8f3b59212685e037d7794:0d84f60495a99b21ff7e967a1ff82d78:1cc48d473884af104fea403dc62f117c
```

**Output**
```text
83a7a8a78b2b0c0f8157786bd53c:1a02e9e0d27fe11533b40775d78d57f5:387e5daa48c2f62ce50badb049091535
```


### Sample Case 2

**Input**
```text
programming
```

**Output**
```text
pr*ogr*amm*ing
```


### Sample Case 3

**Input**
```text

```

**Output**
```text

```
