# Move Special Characters to the End

## Description

<p>Move all special characters to the end of a given string.</p>

## Input Format

<p>The input consists of a single line containing a string that may contain special characters.</p>

## Output Format

<p>Output a single line containing the modified string after moving all special characters to the end.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
HelloTapAcademy@123World!
```

**Output**
```text
HelloTapAcademy123World@!
```


### Sample Case 2

**Input**
```text
I love $coding$! @Programming is fun
```

**Output**
```text
I love coding Programming is fun$$!@
```
