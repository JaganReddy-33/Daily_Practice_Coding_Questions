# Trim Whitespaces

## Description

<p>Given a string, trim the leading and trailing whitespaces.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single string with no leading and trailing whitespaces.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Hello
```

**Output**
```text
Hello
```


### Sample Case 2

**Input**
```text
Trim
```

**Output**
```text
Trim
```
