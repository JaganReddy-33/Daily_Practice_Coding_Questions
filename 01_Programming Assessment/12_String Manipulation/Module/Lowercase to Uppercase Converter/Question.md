# Lowercase to Uppercase Converter

## Description

<p>Converts a given string from lowercase to uppercase.</p>

## Input Format

<p>The input consists of a single line containing a string.</p>

## Output Format

<p>Output the converted string in uppercase.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello world!
```

**Output**
```text
HELLO WORLD!
```


### Sample Case 2

**Input**
```text
TapACADemy
```

**Output**
```text
TAPACADEMY
```
