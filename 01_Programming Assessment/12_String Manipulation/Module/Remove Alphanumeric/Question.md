# Remove Alphanumeric

## Description

<p>Given a string, remove all alphanumeric characters and return the modified string.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Output a single string after removing all the alphanumeric characters.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
tap@123#
```

**Output**
```text
@#
```


### Sample Case 2

**Input**
```text
H3ll0 W0rld!
```

**Output**
```text
!
```
