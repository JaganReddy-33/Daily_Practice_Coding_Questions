# Remove Duplicate Characters

## Description

<p>Given a lowercase string, remove duplicate characters from it.</p>

## Input Format

<p>The input consists of a single line containing a lowercase string, S.</p>

## Output Format

<p>Print the string after removing duplicate characters from the given string.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
hello
```

**Output**
```text
helo
```


### Sample Case 2

**Input**
```text
programming
```

**Output**
```text
progamin
```

**Input**
```text
7dc7b6a2d7:7b18f388f8135722985a13e1b1e21ecc:a147bf53c990d038cd6789cc46f4671e
```
