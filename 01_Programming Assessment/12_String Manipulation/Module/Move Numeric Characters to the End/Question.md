# Move Numeric Characters to the End

## Description

<p>Move all numeric characters to the end of a given string.</p>

## Input Format

<p>The input consists of a single line containing a string that may contain numeric characters.</p>

## Output Format

<p>Output a single line containing the modified string after moving all numeric characters to the end.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TAP123ACADEMY
```

**Output**
```text
TAPACADEMY123
```


### Sample Case 2

**Input**
```text
PROG888RAM
```

**Output**
```text
PROGRAM888
```
