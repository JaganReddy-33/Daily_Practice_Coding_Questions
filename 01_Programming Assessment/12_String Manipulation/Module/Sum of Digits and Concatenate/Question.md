# Sum of Digits and Concatenate

## Description

<p>Given a string, calculate the sum of all the digits in the string and concatenate the sum at the end.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single string with the sum of digits concatenated at the end.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
1One 2Two 3Three
```

**Output**
```text
One Two Three6
```


### Sample Case 2

**Input**
```text
Hello123World
```

**Output**
```text
HelloWorld6
```
