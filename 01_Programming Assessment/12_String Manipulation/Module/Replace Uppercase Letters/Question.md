# Replace Uppercase Letters

## Description

<p>Given a string, replace all uppercase letters with '#' characters.</p>

## Input Format

<p>The input consists of a single line containing a string, S.</p>

## Output Format

<p>Print a single string with all uppercase letters replaced by '#'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
I lOve CODING
```

**Output**
```text
# l#ve ######
```


### Sample Case 2

**Input**
```text
Hello World
```

**Output**
```text
#ello #orld
```
