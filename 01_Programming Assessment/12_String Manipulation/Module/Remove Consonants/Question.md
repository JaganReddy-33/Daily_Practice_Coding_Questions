# Remove Consonants

## Description

<p>Remove all consonants from a given string.</p>

## Input Format

<p>The input consists of a single line containing a string that may contain consonants.</p>

## Output Format

<p>Output a single line containing the modified string after removing all consonants.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
TapAcademy123
```

**Output**
```text
aAae123
```


### Sample Case 2

**Input**
```text
I love coding in JAVA.
```

**Output**
```text
I oe oi i AA.
```
