# Replace 'a' with '@'

## Description

Given a string, replace all 'a' with '@'.

## Input Format

A single string containing alphabets.

## Output Format

A string with all 'a' replaced by '@'.

## Sample Cases

### Sample Case 1

**Input**
```text
banana
```

**Output**
```text
b@n@n@
```

### Sample Case 2

**Input**
```text
apple
```

**Output**
```text
@pple
```
