# URL Friendly String

## Description

<p>Given a string, replace all spaces with '%20' to create a URL-friendly string.</p>

## Input Format

<p>A single string containing alphabets and spaces.</p>

## Output Format

<p>A string with spaces replaced by '%20'.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
Mr John Smith
```

**Output**
```text
Mr%20John%20Smith
```


### Sample Case 2

**Input**
```text
Hello World
```

**Output**
```text
Hello%20World
```
