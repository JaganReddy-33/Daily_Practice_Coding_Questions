# Multiples of 5

**Question ID:** `662a0ef7c74ee9cf9f3c7f7e`

## Description

Given a sorted array of integers, print the elements of the array that are multiples of 5.

## Input Format

First line contains an integer n representing the size of the array The second line contains space-separated integers representing the sorted array.

## Output Format

Print the elements of the array that are multiples of 5, separated by space. If there are no such elements, print "-1".
