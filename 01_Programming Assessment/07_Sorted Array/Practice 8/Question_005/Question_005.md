# Longest Consecutive Subsequence

**Question ID:** `662a0f21c74ee9cf9f3c9101`

## Description

## Input Format

First line contains an integer n representing the size of the array The second line contains space-separated integers representing the sorted array.

## Output Format

Print the length of the longest consecutive subsequence.
