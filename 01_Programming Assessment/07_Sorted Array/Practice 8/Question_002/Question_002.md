# Largest Element Smaller Than Target

**Question ID:** `662a0ee6ae2286cdf8e1ddc8`

## Description

Given a sorted array of integers, find the largest element in the array that is smaller than a given target.

## Input Format

The input consists of three lines:
First line contains an integer n representing the size of the array
- The second line contains space-separated integers representing the sorted array.
- The third line contains a single integer representing the target element.

## Output Format

Print the largest element in the array that is smaller than the target element. If there is no such element, print "None".

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
3
```

**Output**
```text
2
```

### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
0
```

**Output**
```text
-1
```
