# Smallest Element Greater Than Target

**Question ID:** `662a0ed4ae2286cdf8e1d7d0`

## Description

Given a sorted array of integers, find the smallest element in the array that is greater than a given target.

## Input Format

The input consists of three lines:
First line contains an integer n representing the size of the array
- The second line contains space-separated integers representing the sorted array.
- The third line contains a single integer representing the target element.

## Output Format

Print the smallest element in the array that is greater than the target element. If there is no such element, print "-1".

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
3
```

**Output**
```text
4
```

### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
0
```

**Output**
```text
1
```
