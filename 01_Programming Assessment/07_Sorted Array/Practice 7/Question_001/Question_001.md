# Elements Greater Than Index

**Question ID:** `662a0e8dc74ee9cf9f3c581a`

## Description

Given a sorted array of integers, print the elements of the array that are greater than their index.

## Input Format

First line contains an integer n representing the size of the array
The second line contains space-separated integers representing the sorted array.

## Output Format

Print the elements of the array that are greater than their index, separated by space. If there are no such elements, print "-1".

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1 2 3 4 5
```

### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
```

**Output**
```text
-1
```
