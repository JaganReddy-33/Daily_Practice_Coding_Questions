# First Occurrence Index

**Question ID:** `662a0ea5c74ee9cf9f3c5c19`

## Description

Given a sorted array of integers, find the index of the first occurrence of a target element.

## Input Format

The input consists of three lines:
First line contains an integer n representing the size of the array
- The second line contains space-separated integers representing the sorted array.
- The third line contains a single integer representing the target element.

## Output Format

Print the index of the first occurrence of the target element in the array. If the target element is not found, print "-1".

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
3
```

**Output**
```text
3
```

### Sample Case 2

**Input**
```text
7
-3 -2 -1 0 1 2 3
0
```

**Output**
```text
3
```
