# Palindromic Elements

**Question ID:** `662a0fe8c74ee9cf9f3d0cdf`

## Description

Given a sorted array of integers, print the elements of the array that are palindromic.

## Input Format

First line contains an integer n representing the size of the array The second line contains space-separated integers representing the sorted array.

## Output Format

Print the elements of the array that are palindromic, separated by space. If there are no such elements, print "-1".

## Sample Cases

### Sample Case 1

**Input**
```text
7
121 131 141 151 161 171 181
```

**Output**
```text
121 131 141 151 161 171 181
```

### Sample Case 2

**Input**
```text
7
-121 -131 101 202 303 48 50
```

**Output**
```text
-121 -131 101 202 303
```
