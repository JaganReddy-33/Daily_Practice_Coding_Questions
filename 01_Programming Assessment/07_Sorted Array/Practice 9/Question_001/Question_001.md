# Elements Equal to Index

**Question ID:** `662a0f3bc74ee9cf9f3c9e24`

## Description

Given a sorted array of integers, print the number of elements equal to their index in the array.

## Input Format

First line contains an integer n representing the size of the array
The second line contains space-separated integers representing the sorted array.

## Output Format

Print the number of elements in the array that are equal to their index.

## Sample Cases

### Sample Case 1

**Input**


**Output**
```text
4
```
