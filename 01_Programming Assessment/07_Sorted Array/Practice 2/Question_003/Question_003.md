# Most Repeated Element

**Question ID:** `662a0d30ae2286cdf8e16062`

## Description

Given a sorted array of integers, print the element that is repeated the maximum number of times.

## Input Format

First line contains an integer n representing the size of the array. Second line contains n space separated integers values.

## Output Format

Print the element that is repeated the maximum number of times. If there are no repeating elements, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
10
1 2 2 3 3 4 5 5 5 6
```

**Output**
```text
5
```

### Sample Case 2

**Input**
```text
10
-3 -3 -3 -2 -1 -1 0 0 1 1
```

**Output**
```text
-3
```
