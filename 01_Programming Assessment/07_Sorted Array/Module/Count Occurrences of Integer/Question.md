# Count Occurrences of Integer

## Description

<p>Find the number of times a given integer is repeated in a sorted array.</p>

## Input Format

<p>The input consists of three lines:</p><p>The first line contains a single integer, N, representing the size of the array (1 ≤ N ≤ 10^5).</p><p>The second line contains N space-separated integers, A[1], A[2], ..., A[N], representing the elements of the array (-10^9 ≤ A[i] ≤ 10^9).</p><p>The third line contains a single integer, k, representing the integer to be counted.</p>

## Output Format

<p>Print a single integer, the number of times the integer k is repeated in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
8
1 2 3 3 4 4 4 5
4
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
6

```

**Output**
```text

```
