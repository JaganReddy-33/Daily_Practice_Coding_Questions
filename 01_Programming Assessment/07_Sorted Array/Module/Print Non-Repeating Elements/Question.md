# Print Non-Repeating Elements

## Description

<p>Print the elements that occur only once in a sorted array.</p>

## Input Format

<p>The input consists of two lines:</p><p>The first line contains a single integer N, representing the size of the array (1 ≤ N ≤ 10^5).</p><p>The second line contains N space-separated integers, A[1], A[2], ..., A[N], representing the elements of the array (-10^9 ≤ A[i] ≤ 10^9).</p>

## Output Format

<p>Print the non-repeating elements in a single line, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
8
1 2 3 3 4 4 4 5
```

**Output**
```text
1 2 5
```


### Sample Case 2

**Input**
```text
6
1 2 3 4 5 6
```

**Output**
```text
1 2 3 4 5 6
```
