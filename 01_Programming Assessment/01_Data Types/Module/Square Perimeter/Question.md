# Square Perimeter

## Description

Write a program to find the perimeter of the square. Formula: Perimeter = 4 * side

## Input Format

First line contains an Integer, side of a square

## Output Format

Print the perimeter of the square

## Sample Cases

**Input**
```text
6
```

**Output**
```text
24
```
