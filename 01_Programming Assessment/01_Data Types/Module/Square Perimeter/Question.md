# Square Perimeter

## Description

<p>Write a program to find the perimeter of the square. Formula: Perimeter = 4 * side</p>

## Input Format

<p>First line contains an Integer, side of a square</p>

## Output Format

<p>Print the perimeter of the square</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
```

**Output**
```text
24
```
