# Add 2 Integers

## Description

<p>Write a program to add two integer numbers.</p>

## Input Format

<p>First Line contain single integer m Second line contain single integer n</p>

## Output Format

<p>Print sum of both the integers m and n</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10
```

**Output**
```text
15
```


### Sample Case 2

**Input**
```text
20
30
```

**Output**
```text
50
```
