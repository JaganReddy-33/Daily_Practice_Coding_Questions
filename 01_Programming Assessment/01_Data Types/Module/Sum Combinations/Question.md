# Sum Combinations

## Description

<p>Write a program to print all sum combination of three numbers by taking two numbers at a time.</p>

## Input Format

<p>First Line contain single integer m Second line contain single integer n Third line contain single integer k</p>

## Output Format

<p>Print all sum combination of three numbers</p>

## Sample Cases

### Sample Case 1

**Input**
```text
2
4
6
```

**Output**
```text
6
8
10
```


### Sample Case 2

**Input**
