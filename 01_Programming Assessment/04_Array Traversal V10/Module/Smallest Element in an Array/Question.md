# Smallest Element in an Array

## Description

<p>Given an array of integers of size N, find and display the smallest element present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array.</p><p>The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the smallest element present in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 5 7 3 2
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
6
0 -1 -2 -3 -4 -5
```

**Output**
```text
-5
```


### Sample Case 3

**Input**
```text
98e4810808f0869c3621cb25e2:2f8fcc712cfb7c4212008cceda40932d:7cca3fdca3b44609113d6a84993ad005
```

```text
7d:f959c6699c0a6de5fb7967e0d8a1f666:bdc2272b4a6bc65d557cbf79e4f8b7aa
```
