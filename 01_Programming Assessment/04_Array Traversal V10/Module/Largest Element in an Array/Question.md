# Largest Element in an Array

## Description

<p>Write a program to find the largest element in a given array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print largest element in an array</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 5 7 3 2
```

**Output**
```text
7
```


### Sample Case 2

**Input**
```text
6
0 -1 -2 -3 -4 -5
```

**Output**
```text
0
```


### Sample Case 3


```text
4ba6:d59a2533a92b31143cc7e37870877fe7:2ba5818d23e1a968b6844dce628ee0e8
```
