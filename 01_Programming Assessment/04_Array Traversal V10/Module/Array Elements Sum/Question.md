# Array Elements Sum

## Description

Write a program to find the sum of all elements present in an array.

## Input Format

First line contains a single integer N. Next line contains N space separated integer values.

## Output Format

Print sum of all elements in an array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
24
```

### Sample Case 2

**Input**
```text
6
1 2 3 4 5 6
```

**Output**
```text
21
```
