# Absolute Sum Array

## Description

<p>Write a program to find the absolute sum of all elements present in an array.</p>

## Input Format

<p>First line contains a single integer N.</p><p>Second line contains N space separated integer values.</p>

## Output Format

<p>Print Absolute sum of all elements in an array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 -4 -6 3 10 -20
```

**Output**
```text
44
```


### Sample Case 2

**Input**
```text
5
5 -10 -15 20 -25
```

**Output**
```text
75
```
