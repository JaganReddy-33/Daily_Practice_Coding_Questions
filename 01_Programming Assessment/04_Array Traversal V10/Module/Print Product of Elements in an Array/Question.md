# Print Product of Elements in an Array

## Description

<p>Calculate and print the product of all elements in the array.</p>

## Input Format

<p>The function should prompt the user to enter the size of the array and the array elements.</p>

## Output Format

<p>Print a single integer, representing the product of all elements in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
0 1 2
```

**Output**
```text
0
```


### Sample Case 2

**Input**
```text
2
-10 10
```

**Output**
```text

```
