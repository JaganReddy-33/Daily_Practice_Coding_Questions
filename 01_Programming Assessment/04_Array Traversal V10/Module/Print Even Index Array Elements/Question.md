# Print Even Index Array Elements

## Description

<p>Take the size of an array and its elements as input from the user and print the elements of the array that are located at even indices.</p>

## Input Format

<p>The function interacts with the user through standard input (console).</p>

## Output Format

<p>Print the even-indexed array elements on a single line, each element separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
20 40 60
```

**Output**
```text
20 60
```


### Sample Case 2

**Input**
```text
5
2 4 6 8 10
```

**Output**
```text
2 6 10
```
