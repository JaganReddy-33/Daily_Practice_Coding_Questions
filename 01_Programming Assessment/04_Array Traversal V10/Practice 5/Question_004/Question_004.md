# Product of Odd Index Elements from Middle to End

**Question ID:** `661d6814f51c6d596ba58baf`

## Description

Given an array of integers of size N, print the product of all the elements present in the odd indices of the array from the middle to the end of the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the product of all the elements present in the odd indices of the array from the middle to the end of the array. If no elements found print “None"

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
4
```

### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 9
```

**Output**
```text
54
```
