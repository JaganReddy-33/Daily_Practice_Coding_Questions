# Product of Odd Index Elements from Start to Middle

## Description

Given an array of integers of size N, print the product of all the elements present in the odd indices of the array from the start to the middle of the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the product of all the elements present in the odd indices of the array from the start to the middle of the array. If no elements found print “None"

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
2
```

### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 9
```

**Output**
```text
0
```
