# Odd Index Elements

## Description

<p>Given an array of integers of size N, print all the elements present at odd indices.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print all the elements present at odd indices of the array, separated by a space. If no elements found print “None”</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
2 4
```


### Sample Case 2

**Input**
```text
4
-2 0 3 6
```

**Output**
```text
0 6
```
