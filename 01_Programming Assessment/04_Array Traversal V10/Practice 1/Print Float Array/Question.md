# Print Float Array

## Description

Given an array of float values with a size of N, write a program to display all the elements contained within the array.

## Input Format

The first line contains an integer N, representing the size of the array.
The second line contains N space-separated float values, representing the elements of the array.

## Output Format

Display N float values, representing the elements of the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1.5 2.3 3.7 4.2 5.0
```

**Output**
```text
1.5 2.3 3.7 4.2 5.0
```


### Sample Case 2

**Input**
```text
3
10.6 -20.8 30.4
```

**Output**
```text
10.6 -20.8 30.4
```
