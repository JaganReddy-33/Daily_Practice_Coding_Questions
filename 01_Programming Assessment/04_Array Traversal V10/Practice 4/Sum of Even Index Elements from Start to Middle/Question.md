# Sum of Even Index Elements from Start to Middle

## Description

Given an array of integers of size N, print the sum of all the elements present in the even indices of the array from the start to the middle of the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the sum of all the elements present in the even indices of the array from the start to the middle of the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
4
```

### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 9
```

**Output**
```text
1
```

### Sample Case 3

**Input**
```text
7
-5 -2 1 3 7 9 11
```

**Output**
```text
-4
```

### Sample Case 4

**Input**
```text
8
-2 -1 0 2 4 6 7 9
```

**Output**
```text
2
```

### Sample Case 5

**Input**
```text
3
1000000000 1000000000 1000000000
```

**Output**
```text
1000000000
```

### Sample Case 6

**Input**
```text
1
-1000000000
```

**Output**
```text
-1000000000
```

### Sample Case 7

**Input**
```text
7
-1000000000 1000000000 -1000000000 1000000000 -1000000000 1000000000 -1000000000
```

```text
-2000000000
```
