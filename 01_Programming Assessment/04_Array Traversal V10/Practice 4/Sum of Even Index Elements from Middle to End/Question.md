# Sum of Even Index Elements from Middle to End

## Description

Given an array of integers of size N, print the sum of all the elements present in the even indices of the array from the middle to the end of the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the sum of all the elements present in the even indices of the array from the middle to the end of the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
8
```

### Sample Case 2

**Input**
```text
6
-2 0 3 6 8 9
```

**Output**
```text
8
```
