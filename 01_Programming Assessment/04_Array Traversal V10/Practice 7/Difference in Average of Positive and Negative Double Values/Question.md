# Difference in Average of Positive and Negative Double Values

## Description

<p>Given an array of double values of size N, print the difference between the average of all positive real number values and the average of all negative real number values present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array.</p><p>The second line contains N space-separated real number values representing the double array elements.</p>

## Output Format

<p>Print the difference between the average of all positive real number values and the average of all negative real number values present in the array. Print the result rounded to two decimal places.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1.5 -2.0 3.5 -4.2 5.3
```

**Output**
```text
6.53
```


### Sample Case 2

**Input**
```text
6

```

**Output**
```text

```
