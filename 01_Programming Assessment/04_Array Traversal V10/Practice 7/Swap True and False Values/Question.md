# Swap True and False Values

## Description

<p>Given an array of boolean values of size N, swap all true values with false and swap false values with true.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated boolean values (true or false) representing the array elements.</p>

## Output Format

<p>Print the array after swapping true and false values, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
true false true false true
```

**Output**
```text
false true false true false
```


### Sample Case 2

**Input**
```text
7
false false true true false true true
```

**Output**
```text
true true false false true false false
```
