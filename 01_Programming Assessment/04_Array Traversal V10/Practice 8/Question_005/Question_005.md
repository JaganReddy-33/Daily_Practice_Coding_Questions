**Question ID:** `661d6937f51c6d596ba5c27e`

## Description

Given an array of integers of size N, print the product of all prime elements of the array.

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the product of all prime elements of the array.
