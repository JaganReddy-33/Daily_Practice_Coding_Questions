# Sum of Prime Elements

## Description

<p>Given an array of integers of size N, print the sum of all prime elements of the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the sum of all prime elements of the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
10
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
0
```

