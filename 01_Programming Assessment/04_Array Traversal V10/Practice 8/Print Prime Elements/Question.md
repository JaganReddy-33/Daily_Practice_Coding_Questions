# Print Prime Elements

## Description

Given an array of integers of size N, print all elements which are prime.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print all prime elements of the array, separated by a space. If no prime element is found, print 'No prime elements found'.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
2 3 5
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
No prime elements found
```
