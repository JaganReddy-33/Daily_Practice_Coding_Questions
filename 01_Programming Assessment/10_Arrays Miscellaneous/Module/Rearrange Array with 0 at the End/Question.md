# Rearrange Array with 0 at the End

## Description

<p>Rearrange the array by moving 0 elements to the end while maintaining the relative order of positive integers.</p>

## Input Format

<p>First line contains size of the array n.</p><p>Second line contains n space separated integer values.</p>

## Output Format

<p>A line containing space-separated integers representing the rearranged array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
3 0 4 0 2 0 8
```

**Output**
```text
3 4 2 8 0 0 0
```


### Sample Case 2

**Input**
```text
7
0 5 0 1 0 3 0
```

**Output**
```text
5 1 3 0 0 0 0
```
