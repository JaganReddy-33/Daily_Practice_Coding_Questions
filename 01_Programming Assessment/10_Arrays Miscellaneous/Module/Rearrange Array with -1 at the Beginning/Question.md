# Rearrange Array with -1 at the Beginning

## Description

<p>Rearrange the array by moving all -1 elements to the beginning while maintaining the relative order of positive integers.</p>

## Input Format

<p>The input consists of a single line containing space-separated integers, representing the array elements.</p>

## Output Format

<p>A line containing space-separated integers representing the rearranged array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
3 5 -1 2 8 -1 7
```

**Output**
```text
-1 -1 3 5 2 8 7
```


### Sample Case 2

**Input**
```text
8
1 4 -1 6 -1 9 2 -1
```

**Output**
```text
-1 -1 -1 1 4 6 9 2
```
