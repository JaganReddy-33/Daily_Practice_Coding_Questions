# Rearrange Array with Negative Integers at the Beginning and Positive Integers at the End

## Description

<p>Rearrange the array by moving negative integers to the beginning and positive integers to the end while maintaining their relative order.</p>

## Input Format

<p>First line contains size of the array n.</p><p>Next line contains n space separated integer values.</p>

## Output Format

<p>A line containing space-separated integers representing the rearranged array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
-3 5 -1 2 -8 -7
```

**Output**
```text
-3 -1 -8 -7 5 2
```


### Sample Case 2

**Input**
```text
7
2 -1 -4 6 -3 0 8
```

**Output**
```text
-1 -4 -3 2 6 0 8
```
