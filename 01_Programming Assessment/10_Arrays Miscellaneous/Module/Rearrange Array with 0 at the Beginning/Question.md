# Rearrange Array with 0 at the Beginning

## Description

<p>Rearrange the array by moving all 0 elements to the beginning while maintaining the relative order of positive integers.</p>

## Input Format

<p>The input consists of a single line containing space-separated integers, representing the array elements.</p><p>The array can have duplicates and may contain a variable number of elements.</p>

## Output Format

<p>A line containing space-separated integers representing the rearranged array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
7
3 0 4 0 2 0 8
```

**Output**
```text
0 0 0 3 4 2 8
```


### Sample Case 2

**Input**
```text
8
5 0 2 0 1 0 3 0
```

**Output**
```text
0 0 0 0 5 2 1 3
```
