# Rearrange Array with Positive Integers at the Beginning and Negative Integers at the End

## Description

<p>Rearrange the array by moving positive integers to the beginning and negative integers to the end while maintaining their relative order.</p>

## Input Format

<p>The input consists of a single line containing space-separated integers, representing the array elements.</p><p>The array can have duplicates and may contain a variable number of elements.</p>

## Output Format

<p>A line containing space-separated integers representing the rearranged array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
-3 5 -1 2 -8 -7
```

**Output**
```text
5 2 -3 -1 -8 -7
```


### Sample Case 2

**Input**
```text
7
4 -2 1 -5 0 -3 2
```

**Output**
```text
4 1 0 2 -2 -5 -3
```
