# Min Pair Product

## Description

<p>Given an array of integers, find and display the minimum product of pairs of elements in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the minimum product of pairs of elements in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 2 4
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
4
-2 -1 -3 -4
```

**Output**
```text
2
```
