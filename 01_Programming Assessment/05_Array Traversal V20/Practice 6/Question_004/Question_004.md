# Minimum Pair Sum

**Question ID:** `661e081c5028dc4e9dc43f60`

## Description

Given an array of integers of size N, find and display the minimum pair sum of the elements present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the minimum pair sum of the elements present in the array.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 2 4
```

**Output**
```text
3
```

### Sample Case 2

**Input**
```text

-2 -1 -3 -4
```
