# Average of Pair Sum

## Description

<p>Given an array of integers of size N, find and display the average of the minimum and maximum pair sum of the elements present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the average of the minimum and maximum pair sum of the elements present in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 3 5 2 4
```

**Output**
```text
6.0
```


### Sample Case 2

**Input**
```text
4
-2 -1 -3 -4
```

**Output**
```text
-5.0
```
