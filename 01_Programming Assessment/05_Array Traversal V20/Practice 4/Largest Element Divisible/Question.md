# Largest Element Divisible

## Description

<p>Given an array of integers, find and display the largest element present in the array that is divisible by k.</p>

## Input Format

<p>The first line contains two integers N and k separated by a space, where N is the size of the array and k is the number to be checked for divisibility. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the largest element present in the array that is divisible by k. If no such element exists, print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6 3
2 4 6 8 9 12
```

**Output**
```text
12
```


### Sample Case 2

**Input**
```text
5 4
1 2 3 5 6
```

**Output**
```text
-1
```
