# Positive and Negative Elements Separation

## Description

<p>Given an array of integers, separate and display the positive and negative elements present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print two lines. The first line should contain all the positive elements present in the array, separated by a space. The second line should contain all the negative elements present in the array, separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
-2 3 -5 7 -8
```

**Output**
```text
3 7
-2 -5 -8
```


### Sample Case 2

**Input**
```text
4
-1 2 -3 4
```

**Output**
```text
2 4
-1 -3
```
