# Count Lesser Than K Prime

## Description

<p>Given an array of integers, count the number of elements which are lesser than k and prime.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer k.</p>

## Output Format

<p>Print a single integer representing the count of elements lesser than k and prime.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 5 20 7 12
10
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
6
2 3 6 7 11 12
5
```

**Output**
```text
2
```
