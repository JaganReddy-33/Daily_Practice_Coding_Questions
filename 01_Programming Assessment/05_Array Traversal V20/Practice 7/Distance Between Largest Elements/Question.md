# Distance Between Largest Elements

## Description

<p>Given an array of integers of size N, find and display the distance between the first largest and second-largest elements present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. </p><p>The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the distance between the first largest and second-largest elements present in the array. The distance is the absolute difference in indices.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
7
4 6 14 8 10 12 16
```

**Output**
```text
4
```


### Sample Case 3

**Input**
```text
4926725d26ec79687f770966690c:dbe418740a8bed94a3ac752bb21b76c1:2dad28154882c5e7886f6ce7c43ceb68
```

**Output**
```text
55:8e45c159916179c725a0dab02e0b5720:c1fea0f61e6516f5e7d592ee611d5c7b
```
