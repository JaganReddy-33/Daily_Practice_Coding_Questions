# Distance Between Largest Elements

**Question ID:** `661e07d95028dc4e9dc42995`

## Description

Given an array of integers of size N, find and display the distance between the first largest and second-largest elements present in the array.

## Input Format

The first line contains an integer N, the size of the array.

The second line contains N space-separated integers representing the array elements.

## Output Format

Print the distance between the first largest and second-largest elements present in the array. The distance is the absolute difference in indices.

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1
```

### Sample Case 2

**Input**
```text
7
4 6 14 8 10 12 16
```

**Output**
```text
4
```
