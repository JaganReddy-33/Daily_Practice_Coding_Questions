# Sum of Divisible Elements

## Description

<p>Given an array of integers of size N, find and display the sum of all elements that are divisible by M.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer M.</p>

## Output Format

<p>Print the sum of all elements in the array that are divisible by M.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 20 30 40 50
10
```

**Output**
```text
150
```


### Sample Case 2

**Input**
```text
7
15 25 35 45 55 65 75
5
```

**Output**
```text
315
```
