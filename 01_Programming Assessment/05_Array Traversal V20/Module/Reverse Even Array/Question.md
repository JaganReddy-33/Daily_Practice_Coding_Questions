# Reverse Even Array

## Description

<p>Write a program to print even numbers present in an array in reverse order.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print space separated even integer values stored in an array in reverse order.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
10 6 4
```


### Sample Case 2

**Input**
```text
6
2 3 4 5 6 7
```

**Output**
```text
6 4 2
```
