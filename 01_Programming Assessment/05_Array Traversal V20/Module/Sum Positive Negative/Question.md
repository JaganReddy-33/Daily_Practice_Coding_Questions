# Sum Positive Negative

## Description

<p>Write a program to find the sum of positive elements and negative elements separately in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>First line print sum of positive elements in an array. Second line print sum of negative elements in an array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 -4 -6 3 10 -20
```

**Output**
```text
14
-30
```


### Sample Case 2

**Input**
```text
5
5 -10 -15 20 25
```

**Output**
```text
50
-25
```
