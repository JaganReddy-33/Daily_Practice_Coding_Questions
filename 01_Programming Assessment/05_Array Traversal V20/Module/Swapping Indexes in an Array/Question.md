# Swapping Indexes in an Array

## Description

<p>Write a program to swap all the even index elements with odd index elements.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print the required output</p>

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 2 3 4
```

**Output**
```text
Before Swapping:
1 2 3 4
After Swapping:
2 1 4 3
```


### Sample Case 2

**Input**
```text
7
1 2 3 4 5 6 7
```

**Output**
```text
Before Swapping:
1 2 3 4 5 6 7
After Swapping:
2 1 4 3 6 5 7
```
