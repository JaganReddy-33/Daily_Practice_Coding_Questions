# Occurrence of Smallest Element in an Array

## Description

<p>Write a program to find the occurrence of the smallest element in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print the occurrence of smallest element</p>

## Sample Cases

### Sample Case 1

**Input**
```text
4
1 2 3 1
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
7
1 2 3 4 5 6 1
```

**Output**
```text
2
```


### Sample Case 3

**Input**
```text
6d3104aa86798dfa85ddb23b074e35:24aacdabc0f8583309b72708888597a7:35ea6c2a64fa6b9849566f71fba4cd15
```

**Output**
```text
f0:4036ab77f58f0c31f59310f8b5d40a2b:b4e8cdf49730bad17cdfbca413a83759
```


### Sample Case 4

**Input**
```text
9dc2dd65a7172b98a95ad5:e4d553a6a141f38f46885c8143edf12c:8d9a2a7b8b2326121c2f680e19a79992
```

**Output**
```text
45:885f878a78e11862a26d159363fb4bad:af00d1e5d5ab7f5e0d4837626da4f5e6
```
