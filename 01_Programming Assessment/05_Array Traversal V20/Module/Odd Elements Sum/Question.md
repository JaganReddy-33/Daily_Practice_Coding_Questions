# Odd Elements Sum

## Description

<p>Write a program to find the sum of all odd elements present in an array.</p>

## Input Format

<p>First line contains a single integer N. Next line contains N space separated integer values.</p>

## Output Format

<p>Print sum of all odd elements in an array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 4 6 3 10
```

**Output**
```text
4
```


### Sample Case 2

**Input**
```text
6
1 2 3 4 5 6
```

**Output**
```text
9
```
