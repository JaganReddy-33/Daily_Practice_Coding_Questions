# Index of Smallest Element

## Description

<p>Find the index of the smallest element in an array.</p>

## Input Format

<p>The first line contains an integer 'n' (1 &lt;= n &lt;= 100), representing the size of the array.</p><p>The second line contains 'n' space-separated integers, representing the elements of the array.</p>

## Output Format

<p>Print the index of the smallest element in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 7 15 4 8
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
4
1 8 3 9
```

**Output**
```text
0
```

```

0c:8cbdd25c5ac790c0894e2d07541dfa85:febfe71b1fa7876d4c8ff6d186ca4132
```
