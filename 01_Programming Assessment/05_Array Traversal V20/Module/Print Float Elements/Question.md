# Print Float Elements

## Description

<p>Write a program that creates an array to store float numbers and prints all the float elements by taking inputs individually using a loop.</p>

## Input Format

<p>The first line contains an integer value N, the number of elements.</p><p>The second line contains N space separated decimal values.</p>

## Output Format

<p>Print each float element on a new line.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
3
2.4 4.7 6.1
```

**Output**
```text
2.4
4.7
6.1
```


### Sample Case 2

**Input**
```text
2
8.9 9.2
```

**Output**
```text

```
