# Index of Second-Largest Element

## Description

<p>Given an array of integers, find and display the index of the second-largest element in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the index of the second-largest element present in the array. If multiple occurrences of the second-largest element exist, print the index of the first occurrence. If there is no second largest element print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
3
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
5
```


```text
b1:2d51f7924694bf9357721edf8253b145:574aeaeba5c9f82b09ca7fa9c1186149
```
