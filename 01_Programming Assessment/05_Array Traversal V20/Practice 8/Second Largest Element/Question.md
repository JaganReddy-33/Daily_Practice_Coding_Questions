# Second Largest Element

## Description

<p>Given an array of integers of size N, find and display the second largest element present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the second largest element present in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
4
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 16
```

**Output**
```text
14
```


### Sample Case 3

**Input**
```text
c65bfa73903875180ef8c02fcb69:f1c4012b95c1ec4f51eede65e0a3720b:3ce79fee0ac41a458983db5e3af2ed34
```

**Output**
```text
24:8616f8ae85ccf99e81d2a2e512f0d353:e3d86b79ae372773bd30e88b1a6f3715
```


### Sample Case 4
