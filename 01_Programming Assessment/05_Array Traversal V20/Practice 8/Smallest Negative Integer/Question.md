# Smallest Negative Integer

## Description

<p>Given an array of integers of size N, find and display the smallest negative integer present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the smallest negative integer present in the array. If there are no negative integers, print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
-1
```


### Sample Case 2

**Input**
```text
7
4 6 8 10 12 14 -16
```

**Output**
```text
-16
```

```text
dc20:59cfeabd187154602f04d8285897bd57:fa0a7c2cd0e1b42a08d2032222ce1824
```
