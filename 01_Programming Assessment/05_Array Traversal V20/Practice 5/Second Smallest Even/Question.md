# Second Smallest Even

## Description

<p>Given an array of integers, find and display the second-smallest even number present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the second-smallest even number present in the array. If less than two even numbers are present, print -1.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 3 5 6 9 11
```

**Output**
```text
-1
```


### Sample Case 2

**Input**
```text
7
1 2 3 4 5 6 7
```

**Output**
```text
4
```


**Output**
```text
58:b8ca1c12156250ecf4463046325c93ba:df76105400adb4bc83141392ba3f8ce2
```
