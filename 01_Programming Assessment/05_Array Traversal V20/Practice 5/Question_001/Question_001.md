# Second Smallest Even

**Question ID:** `661e08a2f51c6d596bb7c2d1`

## Description

Given an array of integers, find and display the second-smallest even number present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the second-smallest even number present in the array. If less than two even numbers are present, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 3 5 6 9 11
```

**Output**
```text
-1
```

### Sample Case 2

**Input**
```text
7
1 2 3 4 5 6 7
```

**Output**
```text
4
```
