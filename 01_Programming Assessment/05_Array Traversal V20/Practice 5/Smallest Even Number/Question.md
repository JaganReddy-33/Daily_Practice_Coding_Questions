# Smallest Even Number

## Description

Given an array of integers, find and display the smallest even number present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the smallest even number present in the array. If no even number is present, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
6
1 3 5 6 9 11
```

**Output**
```text
6
```

### Sample Case 2

**Input**
```text
5
1 3 5 7 9
```

**Output**
```text
-1
```
