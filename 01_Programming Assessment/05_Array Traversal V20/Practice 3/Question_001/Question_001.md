# Count Greater Than K

**Question ID:** `661e091df51c6d596bb7e71c`

## Description

Given an array of integers, count the number of elements which are greater than k.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer k.

## Output Format

Print a single integer representing the count of elements greater than k.

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 5 20 7 12
8
```

**Output**
```text
3
```

**Input**
