# Count Lesser Than K

## Description

<p>Given an array of integers, count the number of elements which are lesser than k.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer k.</p>

## Output Format

<p>Print a single integer representing the count of elements lesser than k.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 5 20 7 12
8
```

**Output**
```text
2
```


### Sample Case 2

**Input**
```text
6
-12 24 15 10 -20 36
6
```

**Output**
```text
2
```
