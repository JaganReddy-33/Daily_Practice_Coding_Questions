# Count Greater Than K Even

## Description

<p>Given an array of integers, count the number of elements which are greater than k and even.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer k.</p>

## Output Format

<p>Print a single integer representing the count of elements greater than k and even.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 5 20 7 12
15
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
6
-12 24 15 10 -20 36
5
```

**Output**
```text
3
```


```text
4a:167c3225eabc681a06377e845a0d006a:a6531877eb210bcb6af566173c07c948
```
