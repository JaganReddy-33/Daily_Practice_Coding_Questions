# Count Greater Than K Odd

## Description

Given an array of integers, count the number of elements which are greater than k and odd.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements. The third line contains an integer k.

## Output Format

Print a single integer representing the count of elements greater than k and odd.

## Sample Cases

### Sample Case 1

**Input**
```text
5
10 5 20 7 12
6
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
6
-12 24 15 10 -20 36
5
```

**Output**
```text
1
```
