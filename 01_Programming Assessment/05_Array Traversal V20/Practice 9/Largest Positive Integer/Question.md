# Largest Positive Integer

## Description

Given an array of integers of size N, find and display the largest positive integer present in the array.

## Input Format

The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.

## Output Format

Print the largest positive integer present in the array. If there are no positive integers, print -1.

## Sample Cases

### Sample Case 1

**Input**
```text
5
-1 -2 -3 -4 -5
```

**Output**
```text
-1
```

### Sample Case 2

**Input**
```text
7
-4 -6 -8 -10 -12 -14 -16
```

**Output**
```text
-1
```
