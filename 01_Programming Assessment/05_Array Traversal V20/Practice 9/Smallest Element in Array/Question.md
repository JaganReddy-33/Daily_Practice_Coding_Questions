# Smallest Element in Array

## Description

<p>Given an array of integers of size N, find and display the smallest element present in the array.</p>

## Input Format

<p>The first line contains an integer N, the size of the array. The second line contains N space-separated integers representing the array elements.</p>

## Output Format

<p>Print the smallest element present in the array.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
1 2 3 4 5
```

**Output**
```text
1
```


### Sample Case 2

**Input**
```text
7
12 14 16 4 6 8 10
```

**Output**
```text
4
```


### Sample Case 3

**Input**
```text
91619c88499fc6c5f9b4da8d4e96:221e87fedd037691fa8353dcccccbcb1:443299e82e2330cae5cf4e792e21ffae
```

**Output**
```text
75:62e1040a98d608338cb3499684c3ebec:ecdec0399de08b8d00e60945b7257033
```
