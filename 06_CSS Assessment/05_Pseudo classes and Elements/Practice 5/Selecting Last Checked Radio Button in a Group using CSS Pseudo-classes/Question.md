## Question

Which pseudo-class is used to select the last checked radio button in a group?

## Answer choices

- ⬜ **A.** A) :last-checked
- ⬜ **B.** B) :radio:last-checked
- ✅ **C. C) :checked:last-of-type** — Correct answer
- ⬜ **D.** D) :checked:last-child
