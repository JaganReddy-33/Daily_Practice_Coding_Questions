# Selecting Last Three List Items in CSS

> ✅ Solved

## Question

How do you select the last three list items in an unordered list with the class 'menu'?

## Answer choices

- ⬜ **A.** A) ul.menu li:last-child(-n+3)
- ✅ **B. B) ul.menu li:nth-last-child(-n+3)** — Correct answer
- ⬜ **C.** C) ul.menu li:last-three
- ⬜ **D.** D) ul.menu li:nth-last(3)

## Submission

- **Correct answer:** B) ul.menu li:nth-last-child(-n+3)
