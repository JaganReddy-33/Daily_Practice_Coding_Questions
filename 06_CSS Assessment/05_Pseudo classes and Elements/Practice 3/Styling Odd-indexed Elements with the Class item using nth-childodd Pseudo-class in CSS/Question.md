# Styling Odd-indexed Elements with the Class 'item' using :nth-child(odd) Pseudo-class in CSS

> ✅ Solved

## Question

How do you select and style every odd-indexed element with the class 'item' in a list using a pseudo-class?

## Answer choices

- ⬜ **A.** A) .item:odd
- ✅ **B. B) .item:nth-child(odd)** — Correct answer
- ⬜ **C.** C) :item(odd)
- ⬜ **D.** D) :nth-child(odd).item
