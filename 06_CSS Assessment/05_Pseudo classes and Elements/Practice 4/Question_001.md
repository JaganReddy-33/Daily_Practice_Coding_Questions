## Question

What happens if a pseudo-element like ::first-line or ::first-letter is applied to an inline element?

## Answer choices

- ⬜ **A.** A) It will apply to the first line or letter of the entire document.
- ⬜ **B.** B) It will apply to the first line or letter of the inline element's content.
- ✅ **C. C) It will not apply since pseudo-elements cannot be applied to inline elements.** — Correct answer
- ⬜ **D.** D) It will cause a syntax error in the CSS.
