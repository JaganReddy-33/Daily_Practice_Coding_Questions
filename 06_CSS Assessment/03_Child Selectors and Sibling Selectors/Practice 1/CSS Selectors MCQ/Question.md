## Question

<p>Which CSS selector would you use to style all <code>&lt;h2&gt;</code> elements that are children of the <code>&lt;div class="container"&gt;</code> element?</p>

## Answer choices

- ✅ **A. <p>.container &gt; h2</p>** — Correct answer
- ⬜ **B.** <p>.container h2</p>
- ⬜ **C.** <p>.container + h2</p>
- ⬜ **D.** <p>.container ~ h2</p>
