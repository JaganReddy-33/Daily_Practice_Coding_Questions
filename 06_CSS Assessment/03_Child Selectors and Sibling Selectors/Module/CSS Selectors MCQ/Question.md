## Question

<p>Which of the following CSS selectors targets all <code>&lt;p&gt;</code> elements immediately following an <code>&lt;h1&gt;</code> element?</p>

## Answer choices

- ⬜ **A.** <p>h1 + p</p>
- ✅ **B. <p>h1 ~ p</p>** — Correct answer
- ⬜ **C.** <p>h1 &gt; p</p>
- ⬜ **D.** <p>h1 p</p>

## Submission

- **Correct answer:** <p>h1 ~ p</p>
