## Question

<p>How can you define multiple authors for a web page using the <code>&lt;meta&gt;</code> tag?</p>

## Answer choices

- ✅ **A. <p><code>&lt;meta name="authors" content="Author1, Author2"&gt;</code></p>** — Correct answer
- ⬜ **B.** <p>&lt;meta name="author" content="Author1, Author2"&gt;</p>
- ⬜ **C.** <p><code>&lt;meta name="author" content="Author1; Author2"&gt;</code></p>
- ⬜ **D.** <p>&lt;meta name="author" content="Author1 | Author2"&gt;</p>
