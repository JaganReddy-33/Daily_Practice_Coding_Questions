## Question

How can you refresh the web page automatically every 30 seconds using the <meta> tag?

## Answer choices

- ✅ **B. <meta http-equiv="refresh" content="30">** — Correct answer
- ⬜ **C.** <meta charset="refresh" content="30">
- ⬜ **D.** <meta http-equiv="refresh" content="30 seconds">
