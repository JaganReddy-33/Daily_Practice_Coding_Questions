# Generate a Square Pattern

## Description

Write a program that takes an integer n as input and generates a square pattern of n x n size.

## Input Format

The input consists of a single integer n, where 1 <= n <= 100.

## Output Format

The output is a square pattern of size n x n, where each row consists of n asterisks (*).

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
*****
*****
*****
*****
*****
```
