# Generate a Square Pattern

## Description

<p>Write a program that takes an integer n as input and generates a square pattern of n x n size.</p>

## Input Format

<p>The input consists of a single integer n, where 1 &lt;= n &lt;= 100.</p>

## Output Format

<p>The output is a square pattern of size n x n, where each row consists of n asterisks (*).</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
*****
*****
*****
*****
*****
```
