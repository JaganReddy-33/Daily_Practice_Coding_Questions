# Generate Mirrored Triangle

## Description

<p>Write a program to generate a mirrored right angle triangle pattern with the number of rows equal to the input number. Each row contains '*' symbols equal to its row number. Spaces are added before the '*' symbols to make it mirrored.</p>

## Input Format

<p>A single integer 'n' (1 ≤ n ≤ 100) - the number of rows in the triangle.</p>

## Output Format

<p>Print Mirrored Triangle</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
*
   **
  ***
 ****
*****
```
