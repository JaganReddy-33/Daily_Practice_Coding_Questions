# Hollow Square Pattern

## Description

Write a program to generate a Hollow square pattern. The size of the square (n) will be provided as input, and your program should print out a square pattern with '*' as the border and space ' ' as the interior.

## Input Format

A single integer, n (1 <= n <= 100), which represents the size of the square.

## Output Format

Print n lines each containing n characters. The border of the square should be '*', and the interior should be ' '.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
* * * * *
* *
* *
* *
* * * * *
```
