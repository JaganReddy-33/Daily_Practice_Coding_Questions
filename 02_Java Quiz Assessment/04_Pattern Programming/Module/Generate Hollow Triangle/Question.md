# Generate Hollow Triangle

## Description

<p>Write a program to generate a hollow equilateral triangle pattern with the number of rows equal to the input number. Each row contains '*' symbols at the start, end and at the bottom of the triangle, separated by a space. Spaces are added before the '*' symbols to align the triangle in the center.</p>

## Input Format

<p>A single integer 'n' (1 ≤ n ≤ 100) - the number of rows in the triangle.</p>

## Output Format

<p>n lines each containing n - row_number spaces followed by '*' symbols separated by a space at the start, end and at the bottom of the triangle.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
*
   * *
  *   *
 *     *
* * * * *
```
