# Generate Mirrored Triangle

**Question ID:** `64664f448ddbb5b1f39fcb41`

## Description

Write a program to generate a mirrored right angle triangle pattern with the number of rows equal to the input number. Each row contains '*' symbols equal to its row number. Spaces are added before the '*' symbols to make it mirrored.

## Input Format

A single integer 'n' (1 ≤ n ≤ 100) - the number of rows in the triangle.

## Output Format

Print Mirrored Triangle

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
*
**
***
****
*****
```
