# Square Pattern 2

## Description

Write a program to generate a square pattern with the number of rows and columns equal to the input number.

## Input Format

A single integer 'n' (1 ≤ n ≤ 100) - the size of the square.

## Output Format

n lines each containing n space-separated integers - the generated square pattern.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
01 02 03 04 05
02 04 06 08 10
03 06 09 12 15
04 08 12 16 20
05 10 15 20 25
```
