# Generate Equilateral Triangle

## Description

<p>Write a program to generate an equilateral triangle pattern with the number of rows equal to the input number. Each row contains '*' symbols equal to its row number, separated by a space. Spaces are added before the '*' symbols to align the triangle in the center.</p>

## Input Format

<p>A single integer 'n' (1 ≤ n ≤ 100) - the number of rows in the triangle.</p>

## Output Format

<p>n lines each containing n - row_number spaces followed by row_number '*' symbols separated by a space.</p>

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
*
   * *
  * * *
 * * * *
* * * * *
```
