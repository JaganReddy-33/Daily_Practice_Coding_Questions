# Number square pattern

**Question ID:** `64607d62ee62d4b157a4b883`

## Description

Write a program that takes an integer n as input and generates a square pattern of n x n size.

## Input Format

The input consists of a single integer n, where 1 <= n <= 100.

## Output Format

The output is a square pattern of size n x n, with numbers as given in the output.

## Sample Cases

**Input**
```text
5
```

**Output**
