# Triangle Pattern

**Question ID:** `64664d518ddbb5b1f39fc9d9`

## Description

Write a program to generate a right angle triangle pattern with the number of rows equal to the input number. Each row contains '*' symbols equal to its row number.

## Input Format

A single integer 'n' (1 ≤ n ≤ 100) - the number of rows in the triangle.

## Output Format

n lines each containing '*' symbols equal to its row number.

## Sample Cases

### Sample Case 1

**Input**
```text
5
```

**Output**
```text
*
**
***
****
*****
```
